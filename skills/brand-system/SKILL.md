# 品牌基建手册

品牌规范的目的：让任何人在没有设计资源时，也能产出一眼「是我们家」的物料。产出物是一份可执行的 `docs/品牌规范.md`，不是审美论文。

## 规范骨架（五节，缺一不可）

### 1. 一句话定位

「我们为 <谁> 提供 <什么>，让他们 <获得什么>」。必须能印在名片上；写不出来说明定位还没收敛。

### 2. 语气（Voice）与示例

- 三条语气原则，每条给「该说 / 不该说」对照：
  - 例：**朴素具体** → 该说「三天上线」，不该说「极速赋能」。
- 禁用词清单（行业黑话 / 夸大词），写进规范供全员对照。

### 3. 色彩

| 角色 | 用法 | 值 |
| --- | --- | --- |
| 主色 | 封面 / 主按钮，60% 权重 | `#______` |
| 辅色 | 分区 / 图表系列 | `#______` |
| 中性 | 底 / 文字 / 分割线 | `#______` / `#______` |
| 语义色 | 成功 / 警告 / 危险 | `#______` … |

- 每色给出深浅两档（底色 / 前景）与对比度要求（正文 ≥ 4.5:1）。
- 禁止：渐变堆叠、超过 3 个强调色同屏。

### 4. 字体与层级

- 中文 / 英文各一个主字体（含系统回退），标题与正文最多两个家族。
- 层级表：H1 / H2 / 正文 / 注释 的字号与字重；正文行宽 ≤ 80 字符。

### 5. logo 与应用

- 最小尺寸、安全边距、深浅背景两版；禁止拉伸 / 改色 / 加阴影 / 叠图案。
- 给 3 个典型应用示例（deck 封面 / 公众号头图 / 名片），用 `::: cols` 并排「Do / Don't」。

## 应用既有规范

1. 先读 `docs/品牌规范.md`；没有规范时，先起草规范再产出物料（顺序不能反）。
2. 物料落地时逐项对照：色彩取规范值、语气对禁用词清单、logo 用法合规。
3. 发现规范缺失的场景（如新渠道规格）：先补规范一节，再使用。

## 检查清单

- [ ] 定位一句话可独立成立，无形容词堆砌
- [ ] 语气原则含「不该说」对照；禁用词清单非空
- [ ] 色值全部给出 hex 与用途；对比度达标
- [ ] 字体含系统回退；层级表可直接照做
- [ ] logo 有安全边距与禁区；Do / Don't 示例 ≥ 3 组
- [ ] 新物料逐项对照规范（色彩 / 语气 / logo）

## 工具用法

- `write_file` 落盘规范；物料类交付交给 `visual-design`（视觉稿）与 `deck-authoring`（演示）执行。
- `web_search` / `web_fetch` 仅用于行业参考，禁止直接复制他人品牌资产（logo / 色板整体照搬）。
- 图样示意用内联 SVG 或 CSS 绘制（单文件、无外链）。

## 输出约定

- 规范：`docs/品牌规范.md`（五节骨架齐全，含版本表）。
- 物料：`docs/brand/<物料名>-<日期>.html` 或 `.md`，文首注明「基于品牌规范 vX」。
