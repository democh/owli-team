# 客户成功手册

客户成功的工作对象是**信号**：健康度掉下去之前，一定先有行为变化。等客户提出退订再动作，已经晚了。

## 健康度模型（五维，各自给分）

| 维度 | 观察什么 | 数据来源 |
| --- | --- | --- |
| 使用 | 登录频次、核心功能采用率 | 产品数据 / 客户反馈 |
| 支持 | 工单量与情绪、未解决时长 | 支持记录 |
| 商务 | 逾期付款、降配询问 | 财务 / 销售记录 |
| 关系 | 关键人是否变动、回信速度变化 | 沟通记录 |
| 结果 | 客户自己的目标是否达成 | 回顾会议 |

每维 1–5 分，加权得总分；分档：绿（≥ 4）维护 / 黄（2.5–4）主动干预 / 红（< 2.5）一周内行动。评分与依据同屏展示，不黑箱。

## 流失预警信号（出现即建动作）

- 使用量连续两周下滑 > 30%，或核心功能采用停滞。
- 对接人离职 / 换人；对方回信显著变慢。
- 提出「评估是否继续 / 降配 / 对比竞品」类问题。
- 连续两次拒绝回顾会议邀请。

干预动作模板：`信号 → 假设（为什么）→ 动作（谁在几天内做什么）→ 验证指标`。

## QBR（季度业务回顾）议程

1. 回顾上次目标：承诺 vs 实际（用客户自己的指标口径）。
2. 价值证明：本季客户侧收益数据（省了多少 / 赚了多少 / 效率提升）。
3. 风险与阻塞：由谁解决、时限。
4. 下季计划：聚焦 2–3 件事 + 客户需要的配合。
5. 收尾：确认续费节奏或扩购机会的下一步。

纪律：以客户的目标为主语（「你们的目标是…」）；不把 QBR 开成产品发布会。

## 客户周报 / 月报模板

    本期进展：<按客户关心的目标分组，2-4 条>
    关键指标：<表格或 ::: kpi>
    待办与依赖：<我方动作 + 需要客户配合项，均带日期>
    下期计划：<一句话>

## 检查清单

- [ ] 每个在管客户有健康度评分与依据
- [ ] 红色 / 黄色客户有干预动作与责任人
- [ ] QBR 目标与客户对齐，用客户口径复述
- [ ] 周报含「需要客户配合项」且带日期
- [ ] 续费 / 扩购机会在到期前 ≥ 60 天进入计划

## 工具用法

- `csv_analyze` 汇总客户使用数据 / 工单数据（如可用）；`calc` 算使用变化率。
- 周报落盘 `docs/客户周报-<客户名>-<日期>.md`；`::: kpi`（指标）、`::: timeline`（续费节奏）。
- `template_fill`（如可用）批量生成周报框架，关键段落逐客户改写。

## 输出约定

- 交付：`data/客户健康度.csv`（五维评分表）+ `docs/客户周报-<客户名>-<日期>.md`；QBR 材料单独存档。
