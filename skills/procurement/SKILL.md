# 采购手册

采购的对手不是供应商，是**信息不对称**：比价用统一矩阵，交期用数据监控，评估留痕。

## 采购需求单（开口先写清楚）

    物品 / 服务：<名称 + 规格（型号 / 参数 / 数量）>
    用途与场景：<为什么要买，用在什么场景>
    交期：<最晚到货日 + 可分批说明（date_calc 核算，如可用）>
    预算：<单价上限 / 总额；含税口径>
    验收标准：<怎么算合格（功能 / 外观 / 附带文档）>

规格写「要求」不写「品牌型号」——除确有必要指定兼容件时，注明理由。

## 询价与比价（RFP 结构）

1. **背景与范围**：要什么、多少、多久要。
2. **交付要求**：时间表、包装、质保、付款条件。
3. **评分标准**：价格 / 交期 / 质量 / 服务 / 风险的权重（事先公布，事后不调）。
4. **报价格式**：统一表格报价（防口径不一：含税否 / 运费否 / 有效期）。

**比价矩阵**（每家一列）：

    维度（权重）：价格 40% | 交期 20% | 质量 20% | 服务 10% | 风险 10%
    每家逐维打分（1-5）→ 加权总分 → 排序 → 推荐结论

- 至少询 3 家；少于 3 家注明原因（唯一供应商 / 紧急）。
- 推荐结论写「选谁 + 为什么 + 放弃谁 + 为什么」，并注明风险（如单一供应依赖）。

## 供应商评估与维护

- 新供应商准入：资质、样品 / 试单、付款条件三项过一遍再入名录。
- 供应商记分卡（季度）：交付准时率、质量问题数、响应速度、价格稳定性——各给分与数据来源。
- 连续两季度跌落阈值的供应商：给整改通知（附具体要求与期限），不直接拉黑。

## 交期与库存监控

- **再订货点** = 日均消耗 × 提前期 + 安全库存（安全库存按最大波动周量）。
- 逾期预警：距承诺交期 T-3 天未发货即跟进；T-1 天未到预警升级。
- 台账落盘 CSV：物品 | 供应商 | 数量 | 单价 | 承诺交期 | 实际到货 | 状态；用 `csv_analyze` 汇总（逾期 groupby 供应商）。

## 检查清单

- [ ] 需求单含规格 / 交期 / 预算 / 验收标准
- [ ] 询价 ≥ 3 家（或注明原因）；报价口径已统一
- [ ] 比价矩阵权重事先写定；推荐结论含风险
- [ ] 台账已更新；逾期项有跟进记录
- [ ] 大额 / 长期合同已转 legal 审阅

## 工具用法

- 台账与比价表落盘 `data/`，`csv_analyze` 汇总统计；`calc` 算加权分与再订货点。
- `template_fill` 生成询价函（占位 `{{供应商.名称}}`、`{{需求.交期}}`）。
- 合同条款风险走 `contract-review`（legal）；时间节点用 `date_calc`（如可用）。

## 输出约定

- 交付：`docs/采购-<物品>-比价报告.md` + `data/采购台账.csv`（含逾期状态列）。
