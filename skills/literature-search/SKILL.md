# 学术文献检索与综述

文献工作的目标不是「找到很多论文」，而是**说清一个领域已经知道什么、还不知道什么**。三条纪律：检索式可复现、每篇纳入有理由、结论可回溯到原文。

## 检索源与路径

- **OpenAlex**（免 Key，覆盖 2.5 亿+ 作品）：`web_fetch` 直接调 REST API，如
  `https://api.openalex.org/works?search=<关键词>&per-page=25&sort=relevance_score:desc`；
  字段口径：`title / publication_year / doi / cited_by_count / abstract_inverted_index`（摘要为倒排索引，需还原）。
- **arXiv**（预印本，理工优先）：`http://export.arxiv.org/api/query?search_query=all:<关键词>&max_results=20`（Atom XML，解析时取 `entry → title/summary/published`）。
- **Semantic Scholar**：`https://api.semanticscholar.org/graph/v1/paper/search?query=<关键词>`（免 Key 有速率限制，失败退避）。
- **中文文献**：多数库无开放 API——用 `web_search` 检索题录信息，获得正式来源后逐条登记，不编造卷期页码。
- 若已绑定 arXiv MCP（`arxiv` 服务器），可改用其 `search_papers / get_paper` 工具；未绑定时一律走上面的 API 路径。

## 检索式构建（可复现）

1. **拆概念块**：把课题拆成 2–4 个概念块（如「间歇性断食 × 代谢综合征 × 随机对照」），每块列同义词、缩写、上下位词；
2. **组合与截断**：概念块内 `OR`、块间 `AND`；收录范围先宽后窄，记录每轮检索的「式 + 日期 + 命中数」；
3. **双路径纪律**：每个核心概念至少两种路径（关键词 + 引文滚雪球），避免单一角度漏检；
4. **引文滚雪球**：选 2–3 篇高相关种子文献——向前（它的参考文献）与向后（引用它的文献，OpenAlex 的 `cited_by_api_url`）各扩一轮；
5. **时间窗**：领域经典不限年份；现状类限定近 5 年，并在综述中说明。

## 纳入与分级

- 纳入/排除标准先写后筛（主题相关性、方法质量、样本、语言），筛选过程留痕（每篇一句话理由）。
- 证据分级：**系统综述 / Meta > 随机对照 > 队列 > 病例对照 > 病例报告 > 专家观点 > 预印本**（预印本标注「未经同行评审」）。
- 去重以 DOI 为准；无 DOI 用「标题归一化 + 年份 + 第一作者」判重。
- 撤稿核查：正式引用前对关键文献做一次「标题 + retracted」检索。

## 单篇精读笔记（结构化）

每篇记六项：**问题**（解决什么）/ **方法**（设计、样本、干预/暴露）/ **结果**（带数字，含效应量与置信区间）/ **局限**（作者自述 + 你的判断）/ **与课题关系**（支持/反对/方法可借鉴）/ **可引用点**（页码或章节）。

## 文献矩阵与综述结构

- 文献矩阵用表格沉淀（`csv_analyze` 汇总统计，如按年份/方法计数）：
  `| 文献(年份) | 方法 | 样本 | 核心结论 | 局限 | 与课题关系 |`；
- 综述正文按「共识 → 分歧 → 空白」组织，不按文献逐篇报账；每个论断至少挂一个来源编号；
- 分歧处理：并列呈现并分析来源（口径 / 样本 / 时效），不平均、不擅自择一；
- 收尾给出**研究空白与方法建议**（下一步做什么最值得）。

## 交付约定

- 综述稿落 `docs/文献综述-<课题>.md`；来源清单汇入 `docs/来源清单.md`（标题 / URL 或 DOI / 日期 / 要点 / 可信度）；
- 完成定义：检索式可复现（含日期与命中数）；矩阵覆盖全部纳入文献；每个结论可回溯到原文编号。

## 检索记录模板

```markdown
## 检索记录（<课题>）
| 轮次 | 日期 | 来源 | 检索式 | 命中 | 纳入 | 备注 |
|---|---|---|---|---|---|---|
| 1 | YYYY-MM-DD | OpenAlex | ... | 137 | 12 | ... |

## 纳入/排除标准
- 纳入：...
- 排除：...（逐条给理由）
```

## 何时停下来

- **饱和信号**：新增一轮检索不再带来新的纳入文献、新的分歧点或新的方法类型；
- **覆盖信号**：每个子问题的证据类型齐了（经典 + 最新 + 反面证据），且已有 1–2 篇系统综述可对照；
- **预算信号**：时间预算用尽时明确写「检索截至 YYYY-MM-DD，可能遗漏 X 类文献」，不硬凑结论。

## 检查清单与反模式

- 交付前核对：检索式与命中数已记录？纳入/排除理由齐全？关键结论有一手来源？撤稿核查做过？矩阵与正文编号一致？
- 反模式：只搜一轮就动笔；用二手报道冒充原文；把预印本当同行评审结论；编造不存在的文献或页码；只报支持性证据。
