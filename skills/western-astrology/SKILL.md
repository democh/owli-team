# 西方占星手册

角色定位：**盘面为据，语言克制**。占星的产出不是「命定结论」，而是「一张可复查的自我参照地图 + 时机参考」。

## 排盘工具用法

按用途选工具（延迟加载：先 `tool_search` 检索「排盘 / 命盘 / 星盘」激活）：

| 用途 | 工具 | 输入要点 | 输出要点 |
| --- | --- | --- | --- |
| 本命盘 | `natal_pan` | 出生时间（分钟级）、时区（**必须显式**）、经纬度、宫位制（默认 Placidus） | 行星落座落宫 / 逆行 / 宫头 / 四轴 / 相位矩阵 |
| 行运盘 | `transit_pan` | 本命数据 + 行运时刻（at）；传 scanFrom / scanTo 扫描时点 | 行运行星 / 行运→本命 cross-aspects（orb ≤ 6°，工具计算）/ 精确时点 + 影响窗 |
| 合盘 / 组合盘 | `synastry_pan` | 双方出生数据（a / b；知情同意）；mode=composite 出组合盘 | 双侧行星 / 双盘 cross-aspects（orb ≤ 8°，对称去重）/ 元素互补 / 组合盘中点 |
| 卜卦 / 择时盘 | `natal_pan` | 起盘时刻 + 问题 | 象征星与问事宫结构 |

高纬（|φ|>66°）自动降级等宫制并给出告警——如实展示，不隐藏口径变化。
行运 cross-aspects 与合盘交角**必须出自工具**（禁止手工对照两盘估相位）；扫描时点为参考区间，不作事件断言。

## 盘面结构速览

1. **行星与星座**：落座 = 表达风格，落宫 = 发生领域，逆行 = 内化与反复；
2. **相位矩阵**：合 / 冲 / 刑 / 拱 / 六合为主；关注 orb（偏差度）——口径在报告中注明；
3. **元素与模式平衡**：火土风水 × 基本固定变动——看「缺什么、什么过载」；
4. **四轴与宫位**：上升 / 天顶对时间最敏感——时间不确定时优先标注敏感性、给边界备选。

## 表述纪律（红线）

- 不承诺预测准确、不断言宿命；结论给「参考区间」不给「必然」；
- 医疗 / 投资 / 法律 / 婚育 / 生死：不做结论性建议；
- 挑战性相位表述为「课题与成长点」，禁止灾祸恐吓与付费化解暗示；
- 合盘需双方知情；不做关系走向断言、不劝分合；
- 行运描述倾向不断言事件、不制造焦虑。

## 时间精度与口径

- 出生时间分钟级优先；不确定时说明「上升与宫位敏感」并给边界备选；
- 仅知日期：可先做不依赖宫位的行星图层解读；
- 相位 orb / 宫位制 / 近似方法（如七政四余近似）在报告中显式注明。

## 检查清单

- [ ] 时区与经纬度显式、排盘参数完整
- [ ] 相位 orb 与宫位制口径已注明
- [ ] 时间不确定处已标注敏感性
- [ ] 术语附白话释义、挑战相位表述为课题
- [ ] 结论为参考区间、无禁忌领域的结论性建议
- [ ] 合盘知情声明（如适用）

## 输出约定

- 落盘：`docs/本命盘报告-<主题>.md` / `docs/行运报告-<主题>.md` / `docs/合盘报告-<主题>.md` / `docs/择时报告-<主题>.md`；
- 盘面结构化输出用 `::: pan <type>` 容器（先盘后论，容器在前、解读在后）；
- 结尾固定声明：自我参照与时机参考性质 + 参考区间口径。

## 常见的坑

- **心算排盘**：凭印象给行星落座——数据一律来自 `natal_pan`；
- **口径不明**：不注明 orb 与宫位制——解读不可复核；
- **时间不敏感处理**：出生时间不确定仍给上升与宫位结论——先标敏感性；
- **挑战相位渲染为凶险**：把刑冲说成灾祸——表述为「课题与成长点」；
- **宿命化表达**：给「必然发生」类断言——只给倾向与参考区间；
- **合盘无知情声明**：未经双方知情排合盘——先声明再分析。
