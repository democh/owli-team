# 3D 空间表现手册

主线：**场景核对 → 视角规划 → 快照 → 图生图 → 迭代**；效果图是示意，不是承诺（声明固定）。

## 场景契约（DesignScene v1）

- 单位 **mm**；房间多边形顶点、门窗洞口挂墙、家具实例（kind 封闭枚举：床 / 沙发 / 餐桌 / 茶几 / 椅 / 柜 / 书桌 / 电视柜 / 衣柜 / 绿植 / 灯 / 地毯 / 自定义体块）。
- 落盘 `design/*.scene.json`；3D 工作台读写；「::: layout」容器「方案源」行指向该文件。
- 核对先行：打开场景逐项核对房间 / 家具 / 材质；差异列清单回交空间规划方；scene 文件缺失（未落盘 / 路径不符）时拒绝进入出图链路，给出缺失路径并明确回交（@规方 补落盘后再接棒），不留在描述层。

## 出图 prompt 六要素（缺一不生成）

| 要素 | 写法 | 例 |
| --- | --- | --- |
| 空间 | 类型 + 面积 + 朝向 | 18㎡ 南向客厅 |
| 视角 | 相机位 + 焦距感 | 45° 俯视沙发墙，24mm |
| 风格 | 与 styleboard 同词 | 原木日式（低饱和，留白） |
| 材质 | 与色材基调同源 | 浅橡木地板、米白乳胶漆、亚麻布艺 |
| 光照 | 时刻 + 氛围 | 午后侧光，暖调，柔和阴影 |
| 负面 | 不期望项 | 深色、杂乱、过曝、畸变、水印、文字 |

## 快照 → 图生图工作流

1. 工作台固定视角拍快照（PNG）→ 作为 image2image 输入（优先快照保结构；现场照做改造）。
2. 重绘幅度：快照输入中低重绘（保布局）；照片输入中高重绘（换风格）。
3. 保结构进阶：连接侧配置 ControlNet depth/canny 类工作流模板（`workflow_id`），深度图锁定布局。
4. `media_generate` 创建即返回（异步不空等）；产物落交付件 + 画布；核对布局后方可写入 render 容器。

## 标准视角清单（按需取用）

1. 主视角：入口或沙发墙 45°，交代整体风格与布局（首选）。
2. 反向视角：从内向外看，交代动线去向与玄关关系。
3. 俯视平面：工作台俯视模式直接出图，交代格局与尺度。
4. 细节视角：收纳区 / 餐厨区 / 灯光墙各选一面，交代做法细节。
5. 改造对比：同机位拍改造前（照片输入）与改造后（快照输入），成对交付（改造项目必出）。

## 迭代控制（变量法）

- 一轮只改 1-2 个要素；seed 默认沿用，换 seed 必须记录（复现依据）。
- 每轮记录：改了什么 / 保留什么 / 为什么；出图说明同步更新。

## 常见问题与修正

| 症状 | 修正 |
| --- | --- |
| 布局走样（墙 / 门位漂移） | 降重绘幅度；启用 ControlNet 深度模板；负面词加「perspective distortion」 |
| 比例失真（家具过大 / 过小） | prompt 补尺度锚点（如「1.8m 沙发，3.2m 层高」） |
| 光照错乱（过曝 / 死黑） | 光照要素写具体（时刻 + 方向 + 氛围）；负面词加「harsh flash」 |
| 风格漂移 | 风格词与 styleboard 逐字对齐；同段不混入第二风格词 |

## 声明纪律（固定）

- 效果图为示意表现（材质 / 光照 / 色差以实物为准）。
- 生成失败不写 render 容器；转述原因并给替代方案（改 prompt / 降级视觉稿）。
