# 策略研究与回测

## 从想法到规则（规格表先行）

| 字段 | 说明 |
| --- | --- |
| 信号 | 入场条件（指标 / 价格 / 基本面因子），必须可判定 |
| 频率 | 日频 / 周频 / 事件驱动 |
| 持仓周期 | 预期持有时间，与信号衰减节奏匹配 |
| 风控 | 止损 / 止盈 / 仓位上限 / 单票上限 |

任何模糊词（「趋势好」「估值低」）必须翻译成参数化条件后才允许回测。

## 回测口径七要素（`fin_backtest`）

1. 区间：时间范围 + 市场阶段说明（牛 / 熊 / 震荡各覆盖）；
2. 复权：前复权 / 后复权 / 不复权——统一并注明；
3. 费用：佣金 + 印花税；
4. 滑点：按流动性设定；
5. 信号延迟：收盘信号 → 次日开盘执行（防未来函数）；
6. 样本切分：样本内寻参 + 样本外验证；
7. 基准：相对基准（指数）比较，不只报绝对收益。

## 评估指标五件套

- 收益（区间 / 年化）、最大回撤、夏普（或卡玛）、胜率、换手率。
- 解读纪律：高收益 + 高回撤 ≠ 好策略；胜率低但盈亏比高可以接受；高换手策略对费用敏感。

## 参数敏感性

- 关键参数做邻域扫描（如均线周期 ±20%）；
- 好结果 = 参数平原（邻近参数都可用）；坏信号 = 参数尖峰（只有单点好看 = 过拟合）。
- 多参数组合时控制扫描规模，避免「搜出来的历史最优」。

## 实施计划（条件触发式）

- 触发条件（什么信号做什么动作）、仓位上限、止损线、监控清单（看什么、多久看一次）、复盘节奏（周 / 月复盘）。
- 只给条件与纪律，不给下单指令。

## 失效条件与反模式

- 每个策略必须写「什么情况下策略不再有效」（市场结构变化 / 因子拥挤 / 波动率环境切换）。
- 反模式清单：只挑好看区间；忽略交易成本；样本内调参当业绩；把回测曲线当未来收益。

## 输出模板

```markdown
# 策略方案：<主题>
## 规格表
- 信号 / 频率 / 持仓周期 / 风控
## 回测口径与五件套
- 七要素逐项 + 收益 · 回撤 · 夏普 · 胜率 · 换手
## 参数敏感性
- 邻域扫描图景（参数平原 / 尖峰）+ 结论
## 样本外验证
- 切分方式与样本外表现
## 实施计划（条件触发）
- 触发条件 / 仓位上限 / 止损线 / 监控清单 / 复盘节奏
## 失效条件
- 什么情况下策略不再有效
## 数据附录与免责声明
```

## 常见的坑

- **未来函数**：用收盘后才知道的数据回填当日信号——信号延迟必须显式设定；
- **忽略成本**：佣金滑点不算或低估——高换手策略直接失真；
- **样本内当业绩**：调参区间表现当结论——没有样本外验证的曲线不算证据；
- **只报成功**：失败参数组合不报告——全面性比结果好看重要；
- **口径不齐**：复权方式混用导致收益不可比——七要素逐项写清；
- **实施无纪律**：把策略写成「看情况操作」——条件触发式才有可执行性。

## 工具接入口径

- 数据与回测：`fin_kline` / `fin_indicator` / `fin_backtest` / `fin_screen`（先 `tool_search` 激活）；服务端确定性计算，禁止手搓近似；
- 资金与仓位算术用 `calc`；候选池表格用 `csv_analyze`；
- 结果落 `docs/策略方案-<主题>.md`，快照路径与随机种子进数据附录。
