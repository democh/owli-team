# 深度研究方法

研究的目标是**产出可复核的结论**，不是收集一堆材料。三条纪律：结论挂证据、冲突不抹平、未决不隐藏。

## 研究流程

1. **问题树**（lead）：把课题拆成 ≤5 个子问题，标注每个子问题需要的证据类型。
2. **检索归档**（scout）：每个来源记录「标题 / URL 或路径 / 日期 / 关键要点 / 可信度初判」，汇总到 `docs/来源清单.md`。
3. **交叉分析**（analyst）：同一论断至少两个独立来源；冲突处并列呈现，不做平均、不擅自择一。
4. **核查**（verifier）：对影响结论的关键论断逐条核查，给出反面证据与置信度。
5. **汇总**（lead）：结论 + 置信度 + 证据链 + 未决问题与下一步。

## 检索策略

- **双路径纪律**：每个子问题至少两条不同检索路径（关键词变体 / 不同来源类型），避免单一角度取证；
- **证据类型对应**：数据类问题找原始统计，制度类问题找官方文件，实践类问题找案例与访谈；
- **抓取纪律**：先拿到候选列表再对具体页面取正文；抓取失败或被风控拦截如实记录，不编造内容；
- **关联纪律**：每条来源关联到具体子问题；与子问题无关的「有趣材料」进附录备选，不进主清单。

## 证据分级

- 一手（原始数据 / 官方文档 / 代码实证）> 二手（综述 / 报道）> 观点（评论 / 预测）。
- 时效敏感课题标注来源日期；过期来源注明「可能已过时」。
- 观点类材料不得冒充事实进入主清单；引用保留上下文，不截断曲解。

## 交叉验证方法

- **论断 × 来源矩阵**：论断为行、来源为列，用「支持 / 反对 / 未提及」填充——先处理冲突再谈一致；
- **冲突处理**：弄清分歧来源（口径 / 样本 / 时效），给条件化结论（「在 A 条件下成立，在 B 条件下不成立」）；
- **偏见标注**：检查来源立场（利益相关方 / 单一视角 / 时效过期 / 样本偏差），在结论旁标注影响方向；
- **反面证据**：核心结论至少主动构造或搜集 1 条反面证据，验证抗打击能力。

## 置信度口径

- **高**：多来源一致且有一手证据。
- **中**：来源一致但无一手证据，或存在未解释的小冲突。
- **低**：单一来源或推理链较长；必须写明「提升置信度所需的证据」。

## 报告模板

```markdown
# 研究报告：<课题>
## 方法与限制
- 检索路径 / 抓取限制（是否被风控拦截 / 网络不可用）/ 明显局限
## 研究问题树
- 子问题 → 证据类型 → 状态
## 结论与置信度
| 结论 | 置信度 | 依据（来源编号） | 反面证据 |
## 证据链
- 论断 → 来源（事实 / 推断 / 观点三分标注）
## 未决问题与下一步
```

## 常见的坑

- **单一来源下结论**：只找到一篇报道就写「研究表明」——至少两源交叉；
- **无日期来源**：时效敏感课题引用不带日期，结论可能建立在过期数据上；
- **观点当一手**：把评论员预测写成「数据显示」——分级标注必须诚实；
- **矛盾平均**：两个来源冲突时取「大概一致」——冲突要么解决要么并列，不折中；
- **结论无溯源**：报告里的数字找不到对应来源编号——复盘时无法复核；
- **范围蔓延**：研究越做越宽，超出原始问题——范围边界先写死，超纲进「下一步」。

## 工具接入口径

- 检索与取证：`web_search` 找候选来源，`web_fetch` 对来源页面取正文（被风控拦截或抓取失败时如实说明并降级）；
- 数字复核：统计数字与比例用 `calc` 复算；跨期数据表用 `csv_analyze` 汇总；
- 归档落盘：来源清单 `docs/来源清单.md`、报告 `docs/研究报告-<课题>.md`；长周期课题可挂 `schedule_task` 做周期性补检索（先 `tool_search` 激活）。

## 红线

- 不编造来源；抓取失败如实说明并降级（基于工作区材料研究 / 标注未核实）。
- 「事实 / 推断 / 观点」三分标注不可省略。
- 存疑不拦稿但必须留痕：存疑清单交给汇总方按置信度处理，不擅自删改他人结论。
