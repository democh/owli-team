# 经营例会手册

例会的目标是**推进决策**，不是汇报表演。两条铁律：没有数字的汇报退回补充；没有决策点的议题不上会。

## 会议议程（周例会模板）

1. **数字回顾**（finance 主报，5 分钟）：收入 / 支出 / 现金余额 / 应收应付；只报事实与偏差，不夹带解释。
2. **各线汇报**（各收敛者，每人 3 分钟）：进展 / 阻塞 / 需要的支持；与上周承诺逐条对照。
3. **议题研讨**（chief 主持）：每周不超过 2 个议题；先读背景材料再讨论，不现场翻资料。
4. **决策与分工**（chief 收敛）：每个决策写明「做什么 / 谁负责 / 何时检查」；不同意的保留意见记录在案。
5. **收尾**（chief）：复述 Top 3 优先级 + 不做清单；散会后 24 小时内发出简报。

## 三表口径

- **收入表**：区分「已收款 / 已开票未收 / 合同额」三种口径，报告时必须注明采用的是哪一种。
- **支出表**：区分固定成本（房租 / 订阅 / 工资）与变动成本（投放 / 外包 / 采购）；大额支出单列。
- **现金流表**：以银行流水为准，与利润口径分开看；预测部分标注「预测」字样与假设。
- 口径冲突时以 finance 输出为准；历史数据修订需注明「修订原因」。

## 决策记录格式

| 编号 | 议题 | 决策 | 放弃的选项及理由 | 负责人 | 检查点 |
| --- | --- | --- | --- | --- | --- |
| D1 | 是否投 X 渠道 | 投 3 万试跑 4 周 | 不投 Y：受众不匹配 | 高扬 | 第 4 周例会 |

- 同一议题再次上会时先读上次记录；推翻旧决策必须写明「为什么现在结论不同了」。

## 经营简报模板（`docs/经营简报-<主题>.md`）

1. 一句话结论（本周判断）
2. 关键数字（收入 / 现金 / 核心指标，含环比）
3. 各线进展与阻塞（逐场景）
4. 决策记录（表格）
5. 下周 Top 3 与不做清单

## 数字核对口径

- 环比 / 同比 / 占比一律 `calc` 核算，不心算；
- 多表数据先 `csv_analyze` 汇总再进简报（分组合计与总计对账）；
- 关键数字附口径与时间窗（如「现金余额：截至周五 18:00，口径 = 银行流水」）；
- 对比基准写清（对上周 / 对预算 / 对同期），避免「涨了」不含基准的表达。

## 常见的失败模式

- **无决策空转**：议题讨论 40 分钟没有结论——主持人不收口是事故；
- **决议无主**：定了「要优化转化」，但没有负责人与检查点——等同未决策；
- **口径打架**：财务、增长、销售各用各的口径，数字对不上浪费时间——会上先统一口径再谈；
- **重复讨论**：同一议题第三次上会还没读上次记录——浪费时间且羞辱团队；
- **报忧滞后**：坏消息拖成「惊喜」——坏消息必须第 1 页、第一时间；
- **行动项发胖**：一次例会承诺 10 件事——只保留 Top 3 + 不做清单。

## 工具接入口径

- 报数：`csv_analyze` 汇总流水与指标，`calc` 核算比率与趋势；
- 排期：检查点与下次例会日期 `date_calc`；例会到点提醒可用 `schedule_task`（先 `tool_search` 激活）；
- 文书：简报 / 会议纪要套 `template_fill` 模板；KPI 展示用 `::: kpi` 容器（值 / 变化 / 目标）；
- 交叉核对：财务口径分歧回问 finance 侧，经营数据口径回问分析侧。

## 纪律

- 报忧优先：坏消息提前说，第 1 页出现；好消息可以简短。
- 不空转：没有决策点的议题不上例会，改用异步文档处理。
- 每项行动必须有负责人与检查点，否则视为未决策。
- 主持不包办：不替财务算账、不替增长想方案；分歧收敛为「选项 A/B + 代价」交用户。
