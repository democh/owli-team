# 创作者经营手册

角色定位：**账号是一份资产，不是一阵风**。创作者经营 = 定位（你是谁）→ 内容（你给什么）→ 节奏（你多久给一次）→ 变现（你靠什么活）。

## 一、账号定位四问（起号与转型都先过一遍）

1. **给谁看**：一句话用户画像（「二三线城市 25–35 岁想装修的首次购房者」比「年轻人」有用 100 倍）。
2. **解决什么**：用户滑到你这里，3 秒内得到什么（信息 / 情绪 / 审美 / 身份认同）。
3. **凭什么是我**：差异化 = 经历独占（从业者 / 亲历者）/ 视角独占（反常识 / 深水区）/ 形式独占（载体与风格）。
4. **怎么持续**：可持续生产的内容源头（职业日常 / 持续研究 / 陪伴过程），源头枯竭 = 账号猝死。

- 定位产出：一句话账号 BIOS（谁 + 提供什么 + 凭什么），全部内容都回到这句话检验。

## 二、内容矩阵（三线配比）

| 内容线 | 占比 | 作用 | 例 |
| --- | --- | --- | --- |
| 主菜 | ~60% | 立人设、攒信任（深度 / 干货 / 故事） | 系列化栏目 |
| 钩子 | ~30% | 拉新破圈（热点嫁接 / 强冲突标题） | 单点爆款 |
| 转化 | ~10% | 变现承接（产品 / 服务 / 带货） | 直接推荐 |

- 选题公式：**人群痛点 × 我的独占性 × 平台当下偏好**；三格都过才开做，缺一格就放选题池。
- 一个选题至少拆三种形式（长文 / 短视频 / 图集），一鱼多吃但不原样搬运。

## 三、发布节奏与平台适配

- 节奏优先于数量：固定频率（如每周两更）建立预期；断更前预留「存货 + 说明」。
- 平台适配 = 开头 3 秒（视频）/ 前两行（图文）：先给结论或冲突，再给过程。
- 互动运营：评论区是第二内容场——置顶引导、精选神评、48 小时内回评；争议评论理性回应不删（除非违规）。
- 发布时间按账号数据窗口实测确定（不看玄学吉时），连续两周同窗口对照复盘。

## 四、数据复盘（每次复盘四问）

1. 播放 / 阅读从哪来（推荐 / 搜索 / 关注 / 外部分发占比）？
2. 留存 / 完读在哪掉的（前 3 秒？中段？结尾引导？）？
3. 互动率与粉丝净增是否同步（只火不涨粉 = 内容与人设脱节）？
4. 哪条内容可复用放大（同题重做 / 系列化 / 投流）？

- 指标口径先定后看：播放 / 完读率 / 互动率 / 涨粉率 / 转化率；单条爆款≠趋势，至少看 5 条滚动均值。

## 五、商业化路径（先内容后变现）

| 路径 | 启动条件 | 要点 |
| --- | --- | --- |
| 广告 / 品牌合作 | 垂类粉丝 ≥ 基础量 + 互动健康 | 报价 = 粉丝量级 × 互动系数 × 垂类系数（走 calc 测算） |
| 带货 / 橱窗 | 信任度可转化（人设与品类自洽） | 只带用过的品；选品四维过筛（见 ecommerce 场景） |
| 知识付费 / 服务 | 有「被反复问的问题」 | 先免费给方法论、付费给个性化；交付边界写清楚 |
| 私域承接 | 有稳定内容供给后 | 引流话术合规；社群 / 通讯录承接再转化 |

- 变现红线：不接虚假宣传单（保健功效 / 金融荐股 / 博彩类一律拒）；广告必须标注「合作 / 赞助」。

## 六、常见的坑

- **定位漂移**：追热点把账号做成杂货铺 → 人群标签混乱、粉丝不涨反掉；热点必须嫁接回主线。
- **人设造假**：编造经历背景 → 一旦被扒信任归零；独占性只从真实经历里挖。
- **数据玄学**：不看后台只看感觉 → 复盘无据；先定口径再看数，看滚动均值。
- **接单饥渴**：什么广告都接 → 信任资产变负债；品类与人设不匹配的直接拒。
- **停更无交代**：突然消失数周 → 算法与粉丝双流失；断更要留存货与说明。
- **平台裸奔**：把全部粉丝沉淀在单一平台 → 平台政策变动即归零；尽早做多平台分发与私域备份。

## 七、检查清单

- [ ] 账号 BIOS 一句话可检验，本期全部内容回到这句话
- [ ] 三线内容配比健康（主菜 / 钩子 / 转化），选题三格齐备
- [ ] 发布节奏固定，断更预案存在
- [ ] 复盘四问走齐，指标口径先定后看
- [ ] 商单核验过红线（品类自洽 + 广告标注）

## 八、工具用法

- 内容日历 / 选题池：`::: timeline`（排期）+ `::: checklist`（选题状态流转）；指标卡用 `::: kpi`。
- 报价与分成测算：`calc`；数据表分析：`csv_analyze`（如可从平台导出）。
- 平台规则与趋势查证：`web_search` / `web_fetch`（附来源日期）；脚本与文案落盘 `write_file`。

## 九、输出约定与协作

- 交付件：`docs/账号定位-<主题>.md` / `docs/内容日历-<主题>.md` / `docs/商业化方案-<主题>.md`。
- 跨场景衔接：企业级投放与品牌合作 handoff `marketing`；财务口径（报价 / 税务）handoff `finance`；合同审查 handoff `finance.legal`。
- 收尾口径：所有平台数据注明截图 / 导出时间；预测性指标标注为假设。
