# 内容战役手册

内容营销的目标是**用内容换业务结果**，不是「发了很多篇」。一切内容都要能回答：给谁看、解决什么问题、看完做什么、怎么衡量。

## 战役五步

1. **定目标**：数量目标（发几篇）之外必须绑定效果目标（线索 / 转化 / 复购），写清衡量口径。
2. **选题**：来源三优先级——用户原话（评论 / 工单）> 搜索词（seo 提供）> 热点；每个选题写明人群与内容承诺。
3. **日历**：按渠道节奏排出期数，每篇含发布日期、负责人、依赖（设计 / 审核）；跨周内容标注「发布前 1 天定稿」审查点。
4. **渠道适配**：一支内容多形态分发——长文（公众号）、短文案（社媒）、脚本（短视频）；每种形态单独写钩子与 CTA。
5. **复盘**：发布后 7 天看数据，结论区分为「继续 / 调整 / 停掉」三类动作。

## 内容日历模板

```markdown
| 日期 | 渠道 | 标题（≥3 版本） | 人群 | 承诺（看完做什么） | 形态 | 负责人 | 依赖 | 状态 |
```

- 同主题内容沿用同一主题词，方便归因时合并计算；
- 排期日期一律 `date_calc` 核算（含工作日与节假日）。

## 选题检查清单

- [ ] 目标人群是谁？他们要解决什么问题？
- [ ] 标题 3 个版本，各自适合谁？
- [ ] 读者看完能做什么（一个明确动作）？
- [ ] 素材是否有真实来源（不编案例 / 数据）？
- [ ] 能否拆出 2 个以上可复用片段（金句 / 图卡 / 短视频）？

## KPI 口径

- **触达类**：阅读 / 播放量（区分自然与投放）。
- **互动类**：完读率、收藏 / 转发率（互动 ÷ 触达）。
- **转化类**：内容带来的线索数、留资率（留资 ÷ 触达的点击）、最终转化数。
- **内容效率**：单个线索成本 = 内容制作成本 ÷ 线索数；同一主题跨渠道合并计算。
- 对比必须同期同渠道；口径改动需在复盘开头说明。

## 复盘方法

- 先对基准（上期 / 同期），再谈变化；单次波动不下结论。
- 每篇内容回答三问：哪里好（保留）、哪里差（改什么）、下次押注什么。
- 失败内容同样进复盘：写清「学到了什么」，避免同类选题重复踩坑。

## 常见的坑

- **自嗨表达**：只说产品多好，不说读者的处境与收益——读者不为产品的努力买单；
- **标题党**：标题与内容不符，短期点击换长期信任损耗；
- **单次波动下结论**：一篇爆了就想复制、一篇冷了就想放弃——至少看 3–5 期的趋势；
- **搬运式分发**：同一文案直接发所有渠道，不做钩子与 CTA 的渠道改写；
- **数据无口径**：把平台口径混用（不同平台「阅读量」定义不同），对比失真；
- **虚构证据**：编造用户评价 / 案例数字——一次翻车全盘皆输。

## 工具接入口径

- 排期与截止：`date_calc`（含工作日顺延）；定稿/发布节点可挂 `schedule_task` 到点提醒（先 `tool_search` 激活）；
- 数据复盘：投放/内容数据表用 `csv_analyze` 汇总，比率与成本用 `calc`；
- 物料生产：通知/邀请类物料用 `template_fill` 渲染；图表用 `chart` 块、流程用 `mermaid`；
- 外部素材与平台规则：先 `web_search` 核实再引用，标注来源与时效。

## 协作衔接

- 关键词与投放对齐交 seo / ads 同伴；视觉物料交品牌侧；素材事实核对向产品/用户求证；
- 产出统一落 `docs/内容日历-<主题>.md`（选题表 / 排期 / 文案库 / 复用拆解 / 发布检查清单）；
- 与 `seo-optimizer` 配合关键词承接、与 `brand-system` 配合口径一致、与 `data-visualization` 配合图表呈现。
