# 基本面分析

## 数据底座

- 财务数据与比率：`fin_fundamental`（单标的财务快照）；`fin_fund`（基金 / 公司资料类）。
- 行情与估值快照：`fin_quote`（price / pe / pb / marketCap）。
- 计算：`calc`（比率 / 增速 / 占比）；跨期表格汇总：`csv_analyze`。

## 三表精读

- 利润表：收入结构（主营 vs 非经常）、毛利率与净利率趋势、费用率变化（销售 / 管理 / 研发）。
- 资产负债表：负债结构（有息 vs 无息）、流动比率 / 速动比率、商誉与无形资产占比、应收与存货规模。
- 现金流量表：经营现金流 / 净利润（长期 > 1 为优，持续 < 1 警惕）；投资与筹资现金流与战略阶段匹配。

## 财务比率（ROE 杜邦）

ROE = 净利率 × 总资产周转率 × 权益乘数——拆解定位「靠什么赚钱」：高利润率（品牌 / 技术）、高周转（渠道 / 效率）或高杠杆（金融 / 地产）。

- 常用组：毛利率 / 净利率 / ROE / ROA / 资产负债率 / 经营现金流净额 / 应收周转天数 / 存货周转天数。
- 口径纪律：每个比率注明计算口径（如「归母口径」「TTM」）；跨公司对比前先对齐口径。

## 估值三口径

| 口径 | 方法 | 适用与注意 |
| --- | --- | --- |
| 相对估值 | PE / PB / PEG + 同业分位 | 盈利稳定的成熟公司；周期股盈利高点时 PE 反而低 |
| 绝对估值 | DCF（自由现金流折现） | 现金流可预测；对折现率与永续增长率敏感，必须做敏感性表 |
| 分部估值 | SOTP 各业务分别估值加总 | 多元化公司；避免单一倍数掩盖亏损业务 |

输出统一为「区间 + 假设」：乐观 / 中性 / 悲观三情景，各附关键假设。

## 行业对比与分位

对比维度：增速、毛利率、ROE、应收周转、研发强度；标注分位（高 / 中 / 低），并区分「行业性变化」与「公司特有变化」。

## 护城河评估（五维）

定价权 / 成本优势 / 转换成本 / 网络效应 / 牌照壁垒——每维给「强 / 中 / 弱 + 证据」，证据来自财报与公告，不来自印象。

## 排雷清单

- 应收激增 vs 收入增速（是否放宽信用换收入？）
- 存货堆积 vs 收入（是否滞销？）
- 商誉占净资产比例（减值风险）
- 关联交易与非经常损益（利润质量）
- 大股东质押 / 减持 / 频繁更换审计
- 检查路径：`fin_fundamental` 指标 + `fin_news` 公告交叉验证。

## 输出纪律

- 事实（数字）与判断（结论）分列；判断附置信度与补证路径。
- 不预测股价；不给「买入 / 卖出」结论。缺数据写「暂无数据」。

## 常见的坑

- **单口径定估值**：只用一个 PE 就下「贵 / 便宜」——三口径互相印证，偏差须解释；
- **口径混用**：同比 / 环比 / 单季 / TTM 混着算——每个比率标注计算口径；
- **拿行业均值当结论**：不对照分位与结构差异——分位 + 分布才是参照；
- **记忆数字充数**：数据缺位时用印象里的旧数字——缺数据写「暂无数据」；
- **把财报当真相**：不排雷直接采信——排雷清单逐项过；
- **预测当分析**：报告里出现「预计明年增长 X%」——不预测，给条件与情景。
