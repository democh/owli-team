# 家装设计手册

主线：**需求研判 → 风格定位 → 空间规划 → 视觉呈现**；每一步的产物是下一步的输入，跳步即返工。

## 第一步：需求研判（四问 + 三级）

1. 四问：居住画像（几口人 / 年龄结构）/ 生活习惯（在家办公 / 做饭频率 / 待客）/ 收纳量级（衣物 / 杂物 / 器材）/ 预算档位（简装 / 舒适 / 品质）。
2. 三级分类：**必须满足**（一票否决）/ **尽量满足**（加分项）/ **可以放弃**（冲突时牺牲）——所有取舍按级裁决，放弃项显式记录。

## 第二步：风格定位（四要素）

- 风格 = 色 + 材 + 形 + 光 的协同，不是标签词：
  - 色：主色（60%）/ 辅色（30%）/ 点缀（10%）；低饱和打底、点缀提气。
  - 材：主材三件套（地面 / 墙面 / 木作），质感关键词 ≤4 个（哑光 / 原木 / 微水泥 / 亚麻…）。
  - 形：直线 or 圆角；家具线条与空间性格一致。
  - 光：见灯光三层（下文）。
- 方向锚点（起点而非模板）：原木日式（低饱和 + 木 + 留白）/ 现代简约（白灰 + 直线 + 金属点）/ 侘寂（微水泥 + 手作感）/ 奶油风（暖白 + 弧线）——**按居住场景定，不按流行度定**。

## 第三步：空间规划（尺度合规）

| 项 | 区间 |
| --- | --- |
| 主通道 | ≥ 900mm |
| 次通道 | ≥ 600mm |
| 沙发 - 茶几 | 300–450mm |
| 餐桌 - 柜体 | ≥ 750mm |
| 床侧通道 | ≥ 500mm |
| 玄关换鞋区 | ≥ 900mm 回转 |

- 三态标注：实测 / 估读（标注）/ 存疑（列清单核实，不猜）。
- 动线：家务动线（买菜 → 收纳 → 洗切炒）与访客动线分离；隐私区不被穿越。

## 第四步：灯光三层

- 基础照明（顶面均匀）/ 重点照明（阅读 / 操作台）/ 氛围照明（灯带 / 落地灯）。
- 色温：起居 3000K 暖 / 工作 4000K / 厨卫 4000K+；显色指数（Ra）≥ 90 用于梳妆与烹饪区。

## 第五步：材质选择（触感加实物验证）

- 主材三件套优先级：地面（脚感与耐磨）> 墙面（可维护性）> 木作（色差容忍度）。
- 常见组合：原木（浅橡木 / 白蜡木）+ 哑光乳胶漆 + 哑光地砖；微水泥用于侘寂系（需专业施工与养护）。
- 验收口径：木地板平整度 ≤ 2mm/2m、地砖空鼓率 ≤ 5%、乳胶漆无流坠与明显色差（1.5m 目测）。
- 样品先行：所有主材要求样板 / 小样到现场，在自然光下比对色差后再批量下单。

## 常用尺寸速查（mm）

| 项 | 参考值 |
| --- | --- |
| 卧室开间 | 床宽 + 两侧通道（1500/1800 床 + 500×2） |
| 橱柜台面高 | 800（按身高 780–850 微调） |
| 玄关柜进深 | 350–400（鞋柜）/ 550+（挂衣） |
| 衣柜进深 | 600（平开）/ 650（推拉） |
| 书桌高 / 座高 | 750 / 450 |
| 电视观看距离 | 屏幕对角线 × 2.5–3 倍 |

## 场景数据骨架（DesignScene v1，落 design/<名>.scene.json）

单位 **mm**；坐标面 = 俯视投影（x 向右 / y 向上）；房间多边形、门窗挂墙、家具实例、材质按名引用。最小可用示例（照此扩展）：

```json
{
  "version": 1,
  "name": "三室两厅 · 方案 A",
  "unit": "mm",
  "rooms": [
    { "id": "living", "name": "客厅", "polygon": [[0, 0], [4200, 0], [4200, 3600], [0, 3600]], "height": 2800, "floor": "地板", "wall": "墙面" }
  ],
  "openings": [
    { "id": "o1", "roomId": "living", "wallIndex": 0, "type": "window", "offset": 600, "width": 2400, "height": 1500, "sill": 900 }
  ],
  "furniture": [
    { "id": "f1", "kind": "sofa", "x": 1200, "y": 1000, "rotation": 0 }
  ],
  "materials": {
    "地板": { "color": "#e7ddcd", "roughness": 0.75, "texture": "wood" },
    "墙面": { "color": "#f2efe9", "roughness": 0.9, "texture": "wall" }
  },
  "lights": { "sunAzimuth": 210, "sunElevation": 45, "intensity": 1.4, "ambient": 0.55 }
}
```

- 家具 `kind` 封闭枚举：bed / sofa / table-dining / table-coffee / chair / cabinet / desk / tv-stand / wardrobe / plant / lamp / rug / custom-box；
- 墙序号 = polygon 相邻顶点 i → i+1 为墙 i；门窗 offset 沿墙从起点计；
- 材质引用：房间 floor / wall 与家具 material 均按名引用 materials（缺省回退默认色）；
- 落盘后必须复读验证（read_file 或再次确认写入回执），确保文件真实存在再在容器中声明。

## 交付纪律

- 容器约定：风格板 `::: styleboard`、布局 `::: layout`（含「方案源」行）、效果图 `::: render`。
- 落盘先行：`::: layout` 的「方案源」行必须指向已 `write_file` 落盘的文件——先落盘再声明，容器与文件逐项一致（空头引用 = 返工）。
- 声明固定：效果图为示意表现（以实物为准）；预算回交装修规划方（本域不做测算）。
- 反模式：无布局先出图；估读当实测；颜色中途静默变更；收纳 / 动线 / 照明缺项交付；只发容器不落盘（空头引用）。
