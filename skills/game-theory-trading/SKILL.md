# 博弈论交易应用

## 数据与工具

- 建模与推演：`fin_game`（matrix / sequence / evolve / simulate 四模型；输出含 stats 与 narrative；默认落盘 charts/ 快照）。
- 随机种子：任何推演必须记录种子（可复现）；噪声大时多种子重复看分布，不迷信单次结果。
- 输出（界面与报告内）固定标注「模型推演，非预测」。

## 模型映射与识别

| 市场结构 | 博弈类型 | fin_game 模型 |
| --- | --- | --- |
| 多空对峙、谁先撤退 | 懦夫博弈 | matrix |
| 先手行动、跟随反应 | 序贯博弈 | sequence |
| 群体行为演化（情绪 / 风格） | 演化博弈 | evolve |
| 多主体连续竞价、级联 | ABM 蒙特卡洛 | simulate |

识别入口三问：参与方是谁、策略空间是什么、收益结构（对抗 / 协调 / 混合）。

## 纳什均衡速算与解读

- 2×2 快速法：对每列找行的最优反应，双方互为最优的格 = 纯策略纳什。
- 混合均衡：无纯均衡时按「使对手无差异」求概率（如懦夫博弈的进退概率）。
- 解读纪律：均衡 = 「无人愿单独偏离」的稳定态，不等于「对谁有利」；多均衡时看协调机制（惯例 / 焦点 / 威慑）。

## 复制动态与 ESS（evolve）

- 适用：群体中策略占比随时间演化；`feedback=linear`（线性）或 `logistic`（饱和）。
- 看三件事：收敛态（哪个策略存活）、收敛速度（多久）、路径依赖（初值不同结局是否不同，见 `initialValues`）。
- ESS（演化稳定策略）：能抵抗少数突变者入侵的策略组合。

## ABM 参数化（simulate）

- 主体：多头 / 空头 / 套利 / 做市 / 散户（longWeight / shortWeight / arbWeight / mmLiquidity / retailNoise）；
- 冲击：级联阈值与流量（cascadeThreshold / cascadeFlow）、动量强度（momentumWindow / momentumScale）；
- 规模：轮次（rounds）与路径数（paths）——路径数决定分布稳定性，噪声大时必须提高。
- 解读：看 P5 / P50 / P95 分位带与事件概率（squeeze / crash / stalemate），不看单条路径。

## 结果解读与反模式

- 假设先行：参与方 / 策略空间 / 收益口径 / 参数来源——假设不清楚，结果无意义。
- 反模式：把推演当预测；参数过拟合（为想要的结果调参）；单路径叙事（只挑好看的一条）；忽略均衡稳定性讨论。
- 进报告要求五件齐全：模型 + 假设清单 + 参数 + 随机种子 + 快照路径。
