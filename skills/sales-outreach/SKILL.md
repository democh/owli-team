# 销售外联手册

销售外联的唯一失败模式是「群发感」。每条消息、每次通话，都要证明三件事：**我们知道你是谁、我们知道你的问题、我们有一个低门槛的下一步**。

## 账户研究（外联前必做）

产出 5 行画像：客户在做什么（业务现状）→ 最近发生了什么（触发事件：融资 / 招聘 / 产品发布）→ 谁相关（决策人 / 影响者 / 把关人）→ 我们的切入角度（与其处境的连接点）→ 可能异议。

- 资料来自公开信息（官网 / 新闻 / 社交），标注来源与日期。
- 找不到触发事件就先别发——无触发的外联转化为零。

## 外联邮件三段式

1. **相关性**（凭什么是你）：引用对方的具体事实（一两个，含时间）。
2. **价值**（对他们意味着什么）：同类客户的具体结果（数字 + 条件），不吹功能。
3. **低门槛 CTA**：请求 < 15 分钟的具体时间或一个简单回复（「值得看 3 分钟的资料么？」），不写「有机会合作」。

- 长度 ≤ 150 字；主题行写具体事由；不发附件轰炸。
- 语言分寸：称呼用对方惯用称谓；不假装熟人（「上次聊到」必须是真聊过）。

## 跟进节奏

- 首触后：第 3 天（补充新信息，不催命）、第 7 天（换角度）、第 14 天（最后一封，明确「不再打扰」）。仍无回应则转长期培育，不第五封。
- 每封跟进必须带**新信息**（案例 / 数据 / 文章），只换措辞的重发一次就够。

## 通话准备卡（每次通话前 10 分钟写）

    目标：本次通话要推进到哪一步（唯一目标）
    开场：一句相关性 + 一句「你希望我先讲什么」
    问题清单：3-5 个业务问题（越具体越好，先问现状再问痛点）
    异议预案：定价 / 时机 / 竞品 各一句回应（证据 + 下一步）
    下一步：通话结束前必须约定的动作（谁做什么、什么时候）

## 竞争战卡

每个主要竞品一页：定位 / 价格带 / 强项（诚实写）/ 短板（只写可验证的）/ 我们赢面场景一句 / 对方攻击话术与回应。**不贬损竞品**，只讲事实与差异。

## 管线表（CSV 维护）

列：客户 | 阶段（线索 / 接触 / 演示 / 报价 / 成交 / 流失）| 金额（万元）| 赢率 | 下一步动作 + 日期 | 负责人。
每周更新；赢率按同阶段历史均值给；停滞 > 14 天的条目标红并写「复活动作或放弃」。

## 检查清单

- [ ] 外联前完成账户画像与触发事件核实
- [ ] 邮件三段式齐全、≤ 150 字、CTA 门槛低
- [ ] 跟进带新信息；间隔按节奏表
- [ ] 通话前有准备卡；结束前约定了下一步
- [ ] 战卡事实有出处；不贬损竞品
- [ ] 管线表已更新；停滞项有处置

## 工具用法

- 管线 / 战卡表格落盘 `data/管线表.csv`，用 `csv_analyze` 汇总（groupby 阶段、sort 金额）。
- `template_fill` 批量生成同类外联邮件（模板占位 `{{客户.名称}}` 等）；发送前逐封核对相关性段。
- 时间节奏用 `date_calc` 排跟进日程。

## 输出约定

- 交付：`data/管线表.csv` + `docs/销售-<客户名>-作战简报.md`（画像 + 邮件 + 准备卡 + 战卡引用）。
