# 测试计划与报告模板

## 用例组织

按三组组织，每个用例包含：前置条件 / 步骤 / 期望结果。

1. **正常路径**：主流程成功场景。
2. **边界**：空值、最小值、最大值、超长、恰好临界。
3. **异常**：非法输入、依赖失败、重复提交、并发。

## 报告模板

```markdown
# 测试报告：<主题>
## 范围
- 被测对象与版本 / 依赖说明
## 用例
| # | 组 | 前置 | 步骤 | 期望 | 结果 |
## 缺陷
- 缺陷：复现步骤 / 期望 / 实际 / 严重度
## 结论
通过 / 有条件通过（遗留风险）/ 不通过
```

## 注意

- 期望结果必须可判定（避免「正常显示」这类模糊描述）。
- 每条缺陷给出最小复现路径。
