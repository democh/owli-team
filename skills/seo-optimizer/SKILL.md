# SEO 优化手册

SEO = 让搜索引擎**找得到**（技术面） + 让用户**点进来**（内容面）。两件事分开做，分开验证。

## 关键词分层

| 层 | 特征 | 用法 |
| --- | --- | --- |
| 核心词 | 头部、竞争大、意图泛 | 首页 / 栏目页承接，长期做 |
| 长尾词 | 具体、竞争小、意图明确 | 单篇文章一篇打一词 |
| 品牌词 | 含自家产品名 | 官网 / 帮助中心守住即可 |

- 定词三看：**搜索意图**（信息 / 比较 / 交易）、**竞争度**（看前排内容质量）、**我们能否写出更好答案**——三缺一不立项。
- 产出关键词表（CSV）：词 | 层 | 意图 | 目标页 | 优先级 | 备注。用 `csv_analyze` 排序与分组。

## 页面优化清单（逐项过）

- **Title**：主关键词前置 + 差异点；≤ 60 字符；不做关键词拼接。
- **Meta description**：写出「点击理由」（给读者价值承诺），≤ 120 字符。
- **标题结构**：H1 唯一且含主词；H2 覆盖子问题；层级不跳级。
- **首段**：前 100 字直答标题承诺的问题（提升停留与摘要抓取）。
- **内链**：新文链向 2–3 篇相关旧文（用描述性锚文本）；旧文回链新文。
- **图片**：文件名语义化、alt 写内容而不是堆词；压缩体积。
- **结构化**：FAQ / HowTo 类内容可加对应结构化数据标记（如站点支持）。

## 技术面检查

- 可索引：目标页无 noindex、不被 robots 拦截；sitemap 收录。
- 性能：首屏加载 ≤ 2.5s；移动端可用。
- 重复内容：多路径同页需 canonical；分页序列正确。
- 抓取预算：无大面积低质页面浪费抓取。

## 选题与内容纪律

- 一篇内容只打一个主词 + 2–3 个相关长尾；主词写进 title、H1、首段。
- 不堆砌：主词密度自然（读起来不别扭即合格），不做隐藏文字、不做门户站式关键词堆叠。
- E-E-A-T：作者身份可见、数据给来源、引用权威资料——经验性内容（实操细节）是差异化来源。
- 更新优于新增：已有排名 5–15 名的页面先改（加数据 / 补子问题 / 优化 title），再开新坑。

## 效果追踪口径

- 核心指标：目标词排名、收录数、自然点击量、点击率（CTR）。
- 对比口径固定：同词 / 同期 / 同设备；算法更新波动单独标注。
- 复盘节奏：内容发布后 14 天与 60 天各看一次，区分「未收录 / 有收录无排名 / 有排名无点击」三种问题分别处理。

## 检查清单

- [ ] 关键词表含意图与目标页；优先级有依据
- [ ] 页面清单逐项过（title / meta / H 结构 / 内链 / 图片）
- [ ] 一篇一词；无堆砌与隐藏文字
- [ ] 技术面（索引 / 速度 / canonical）已核
- [ ] 追踪口径固定，复盘节奏已排

## 工具用法

- 关键词表与效果数据用 `csv_analyze`（groupby / sort / filter）；指标计算用 `calc`。
- 竞品与 SERP 调研用 `web_search` / `web_fetch`，记录日期与来源。
- 排期用 `::: timeline`，日期核算用 `date_calc`（如可用）；关键词表落盘 `data/关键词表.csv`。

## 输出约定

- 交付：`data/关键词表.csv` + `docs/seo-<主题>-优化方案.md`（页面清单 + 改动项 + 预期与追踪口径）。
