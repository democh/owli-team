# 财务测算手册

## 常用公式与 calc 函数

| 指标 | 公式 | calc 调用示例 |
| --- | --- | --- |
| 毛利 / 毛利率 | (收入 − 成本) ÷ 收入 | `gross_margin(revenue, cost)` |
| 加价率 | (售价 − 成本) ÷ 成本 | `markup(cost, price)` |
| 复合增长 | (期末 ÷ 期初)^(1/n) − 1 | `cagr(begin, end, years)` |
| 复利终值 | 本金 × (1 + 利率)^期数 | `compound(principal, rate, periods)` |
| 月供 | 等额本息公式 | `loan_payment(principal, annual_rate, months)` |
| 净现值 | Σ 现金流 ÷ (1 + r)^t − 初始投入 | `npv(rate, cashflows)` |
| 内部收益率 | NPV = 0 时的折现率 | `irr(cashflows)` |
| 投资回报率 | (收益 − 投入) ÷ 投入 | `roi(gain, cost)` |
| 广告回报 | 广告收入 ÷ 广告花费 | `roas(revenue, spend)` |
| 获客成本 | 花费 ÷ 新增客户数 | `cac(spend, customers)` |
| 客户终身价值 | 客单价 × 毛利率 × 复购次数 | `ltv(arpu, margin, times)` |
| 盈亏平衡点 | 固定成本 ÷ (单价 − 单位变动成本) | `breakeven(fixed, price, variable)` |
| 税后净额 | 金额 × (1 − 税率) | `net_after_tax(amount, rate)` |
| 环比变化 | (本期 − 上期) ÷ 上期 | `pct_change(prev, curr)` |

- 多个数求和 / 平均用 `sum(...)`、`avg(...)`；取整 `round(x, n)`；括号与乘方 `^` 均支持。
- 所有金额写清单位（元 / 万元）与币种；比例统一用小数（0.25）或写 `%`，同一交付件不得混用。

## 建模纪律

1. **先假设后计算**：模型开头列假设清单（单价 / 转化率 / 周期 / 口径），每条假设标注来源（实测 / 行业参考 / 用户给出）。
2. **三档情景**：保守 / 基准 / 乐观各算一遍，说明每档的前置假设差异；只给单点数字视为不完整。
3. **计算留痕**：全部走 calc 工具，交付件中保留公式与代入值，禁止心算与「大概」。
4. **口径一致**：含税 / 不含税、权责 / 收付在模型开头声明；跨交付件引用同一数字时标注出处。

## 现金流要点

- 以银行流水口径为准；利润 ≠ 现金流，两者分开列示。
- 预测部分标注「预测」；至少覆盖未来 6 个月，标注「现金见底月」（如有）。
- 大额一次性支出单列，不摊进月度均值里掩盖波动。

## 敏感性分析

- 选 2–3 个最关键变量（如转化率、客单价、留存），单变量 ±20% 看结果变化幅度。
- 输出格式：变量 × 档位 → 关键指标矩阵；标注「结果对该变量高度敏感」的结论。
- 敏感性高的假设必须给验证计划（先用什么小实验验证）。

## 免责口径

- 交付件结尾注明：本测算为辅助参考，不构成审计 / 税务 / 投资意见。

## 常见的坑

- **单点数字**：只给一个数不给三档情景——决策无从下手；
- **口径混用**：含税与不含税、月与年在同一张表里混着算——模型开头先声明口径；
- **无假设清单**：直接出数，假设藏在脑子里——每条假设必须标注来源（实测 / 参考 / 用户给出）；
- **心算替代工具**：口算比率与复利——全部走 `calc`，交付件保留公式与代入值；
- **大额摊平**：把一次性支出摊进月度均值——波动被掩盖，现金流判断失真；
- **预测不标注**：实际数据与预测数据混排——预测必须显式标注。
