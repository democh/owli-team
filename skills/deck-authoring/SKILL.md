# 演示材料手册

本环境不产出二进制 .pptx；演示稿以两种形态交付，二者配套使用：

| 形态 | 文件 | 用途 |
| --- | --- | --- |
| 演示页 | `docs/<主题>-decks.html`（自包含单文件 HTML） | 浏览器全屏投屏（← → 翻页），"打印 → 另存为 PDF"即得 PDF 版 |
| 讲者稿 | `docs/<主题>-讲稿.md` | 大纲 + 每页讲稿备注 + 数据出处 |

## 制作流程

1. **先定一句话主张**：整份 deck 想让听众记住的一件事，写在第一页。
2. **定结构**：开场（主张）→ 3–5 个支撑段（每段一个问题一个结论）→ 结论与请求。页数 = 每段 2–3 页，总 10–15 页为宜。
3. **选主题色板**：从下表按题材选一套，全局只用一个色系；明暗 sandwich（标题/结论深色、内容浅色）。
4. **写每页骨架**：标题（即结论句）+ 一个视觉元素 + 不超过 6 行要点。
5. **生成 HTML**：写单文件 HTML（内嵌 CSS，CSS 变量绑定色板；无外部依赖；← → / 空格翻页，打印样式每页一版）。
6. **配讲者稿**：每页 3–5 句口语化备注 + 引用数据出处。
7. **QA**：对照下方清单逐条过一遍再交付。

## 主题色板（选一套）

| 题材 | 主色 | 辅色 | 点缀 |
| --- | --- | --- | --- |
| 经营 / 董事会 | `#1E2761` 藏青 | `#CADCFC` 冰蓝 | `#FFFFFF` |
| 财务 / 稳健 | `#028090` 青 | `#00A896` 海沫 | `#02C39A` 薄荷 |
| 增长 / 营销 | `#F96167` 珊瑚 | `#F9E795` 暖金 | `#2F3C7E` 深蓝 |
| 品牌 / 人文 | `#B85042` 陶土 | `#E7E8D1` 沙 | `#A7BEAE` 鼠尾草 |
| 科技 / 产品 | `#065A82` 深蓝 | `#1C7293` 青蓝 | `#21295C` 午夜 |
| 极简 / 通用 | `#36454F` 炭 | `#F2F2F2` 米白 | `#212121` 黑 |

一色主导（60–70% 视觉权重），一套 deck 只用一套色板。

## 每页要有视觉元素

纯文字页留不住人。至少选一种：大数字（60pt+ 数字 + 小标签）、对比两栏、时间线 / 步骤流、图（mermaid 或占位图片）、图标 + 文字行。版式逐页变化：左右分栏、2×2 网格、整幅配图。

## 字号与间距

| 元素 | 字号 |
| --- | --- |
| 页标题 | 36–44pt 加粗 |
| 小节标题 | 20–24pt |
| 正文 | 14–16pt |
| 注释 / 出处 | 10–12pt 弱化色 |

页面留边不小于 5%，内容块间距 0.3–0.5（相对单位）统一即可，不要随机。

## 禁忌清单

- 不给标题加装饰性下划线、页眉彩条、卡片描边条纹——典型的「模板味」。
- 不居中正文；正文左对齐，只居中标题。
- 不做「标题 + 项目符号」的纯文字页。
- 不用低对比配色（浅底浅字、深底深字）；不用奶油底色当默认背景。
- 字号层级要有对比（标题至少为正文 2 倍）；同页板式不要重复三次以上。
- 不堆长句：每行 ≤ 20 字，要点 ≤ 6 行。

## QA 清单（交付前逐条过）

- [ ] 文字没有溢出容器或被裁切（最常见的用户可见缺陷）
- [ ] 无元素重叠；注释 / 出处不与内容相撞
- [ ] 每页都有视觉元素；版式有变化
- [ ] 颜色来源同一色板；对比度可读
- [ ] 无占位符残留（TODO / lorem / xxx）
- [ ] 讲稿每页都有；每个数字都有出处
- [ ] HTML 在浏览器打开可翻页、可打印（打印预览每页一版）

## 工具用法

- `write_file` 落盘 HTML 与讲稿；改版用 `edit_file` 局部改，避免整篇重写。
- 页内数据图优先用 Markdown 讲稿里的 mermaid / chart 代码块表达；HTML 版如需图形，用内联 SVG 或 CSS 绘制，禁止外链资源。
- 日期与排期数字用 `date_calc` 核算（如不在工具清单则手算并复核）；金额口径与关键指标引用财务交付件原文。

## 输出约定

- 演示页：`docs/<主题>-decks.html`；讲者稿：`docs/<主题>-讲稿.md`。
- 讲稿开头注明：主题色板名、数据出处清单、版本日期。
