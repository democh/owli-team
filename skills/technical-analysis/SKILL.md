# 技术面分析

## 数据底座

- K 线：`fin_kline`（symbol / period / adjust / limit）；关键位与形态先取数再看图，不许目测。
- 指标：`fin_indicator`（MA / MACD / RSI / BOLL / KDJ），服务端确定性计算，参数口径随结论标注。
- 快照：`fin_quote`（实时价 / 涨跌幅 / 量额）。
- 呈现：正文用 ```kline 块（附 annotations 标注关键位）。

## K 线语言

- 实体与影线：长实体 = 单边主导；长上影 = 上方抛压；长下影 = 下方承接；十字星 = 多空平衡。
- 缺口：突破缺口（放量、难回补）、持续缺口（趋势中继）、衰竭缺口（末端、快速回补）——按位置与量能区分，不凭外观。
- 常见形态与可靠性：头肩（需破颈线确认）、三角收敛（末端放量选择方向）、通道（沿边界节奏）；统一标注「未完成 / 已确认 / 已失效」三态。
- 形态失效优先：先写下失效条件（如跌破颈线回抽不过），再看成立路径。

## 趋势结构

- 高点低点序列：高点抬升 + 低点抬升 = 上升结构；失守前低 = 结构破坏。
- 均线系统：MA5 / 10 / 20 / 60 / 120 的多头 / 空头 / 缠绕排列；缠绕期降低结论强度。
- 结构分层：大周期（周 / 月）定方向，中周期（日）定阶段，小周期（60 / 30 分钟）定节奏。

## 指标用法与误区

| 指标 | 常用法 | 误区 |
| --- | --- | --- |
| MA | 排列 / 金叉死叉 / 支撑压力 | 震荡市频繁假信号 |
| MACD | 金叉死叉 / 背离 / 柱体缩放 | 滞后——金叉确认时行情常已过半 |
| RSI | 超买超卖 / 背离 | 强趋势中可长期钝化，高位可以更高 |
| BOLL | 收口（变盘临近）/ 张口（趋势启动） | 触上轨 ≠ 卖点，趋势中沿轨运行 |
| KDJ | 超买超卖 / 钝化 | 高频失效，需配合结构与量能 |

规则：任何指标结论必须带「参数 + 周期 + 误区提示」三件套。

## 量价关系

- 放量突破（有效性高）> 缩量突破（警惕假突破）；缩量回调（健康）> 放量下跌（结构恶化）。
- 天量滞涨 = 分歧加剧信号；地量 = 关注度衰竭，方向需等待催化。

## 支撑压力画法

1. 前高 / 前低（摆动点）；2. 密集成交区（筹码峰）；3. 整数关口；4. 缺口边界；5. 均线动态位。
- 每个位置标注强度依据与失效位（被有效击穿即重估，不硬扛）。

## 多周期共振与输出纪律

- 共振：两个以上周期同向 → 提高置信度；冲突时说明以哪周期为准及理由。
- 输出：条件触发式（「站稳 X 且放量 → 结构转多；跌破 Y → 结构破坏」），不给目标价与买卖指令。
- 结论含置信度（高 / 中 / 低）与证伪条件（什么情况表明本判断已失效）。

## 常见的坑

- **目测读图**：凭印象说支撑位与指标值——先取数（`fin_kline` / `fin_indicator`）再看图；
- **指标机械套用**：金叉就喊多、超买就喊空——每个指标结论带「参数 + 周期 + 误区」三件套；
- **跨周期混用**：用分钟级信号谈周线结论——冲突时显式说明以哪个周期为准；
- **关键位无出处**：支撑压力位凭空给——五个来源按序核查（摆动点 / 筹码峰 / 整数关 / 缺口 / 均线）；
- **给目标价**：预测具体点位——只给结构描述与条件触发；
- **失效条件缺失**：只写成立路径不写失效条件——证伪条件必须与结论同列。
