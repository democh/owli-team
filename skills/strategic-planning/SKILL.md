# 战略规划手册

战略 ≠ 愿望清单。合格的规划每一条都能回答：**基线是什么、目标怎么量、路径为什么是它、放弃了什么**。

## 规划六步

1. **现状诊断**：把事实与判断分开列。事实（带数据）+ 内外部环境（SWOT / 竞争对比表）；判断必须标注是谁的判断、依据什么。
2. **定目标**：用 OKR 结构——O 一句方向（不含数字），KR 2–4 条且每条含「指标 + 基线 + 目标值 + 期限」。
3. **出路径**：每个 KR 给 1–2 条路径假设（做什么、谁来做、花什么），并写明「为什么是它」。
4. **排优先级**：候选动作按 ICE（影响 × 确定性 ÷ 成本）打分，明确写下被否决的选项与否决理由。
5. **资源与节奏**：按季度排里程碑（`::: timeline`）；标注关键依赖与决策点（谁在何时需要拍板什么）。
6. **风险与预案**：前 3 大风险各给「信号 + 预案」；信号要可观测（指标阈值或事件）。

## 目标写法对照

| 不合格 | 合格 |
| --- | --- |
| 提升品牌影响力 | 季度内行业媒体主动报道 ≥ 3 次（基线 0） |
| 优化客户体验 | NPS 从 32 提到 45；首响时间从 8h 降到 2h |
| 快速增长 | 月付费用户从 120 到 300（月均 +25%） |

规则：**没有基线的目标不立项**；基线拿不到就先立「测量」为该季 KR。

## 竞争分析对照表

维度固定为：定位一句话 / 目标客户 / 价格带 / 核心功能差异 / 渠道打法 / 明显短板。每格必须有来源（官网 / 财报 / 实测）与日期；猜测标注「推断」。

## 检查清单

- [ ] 事实与判断分列；每个数字有来源
- [ ] 每条 KR 有基线、目标值、期限
- [ ] 每条路径写了「为什么是它」，且列出了被放弃的替代路径
- [ ] 里程碑含决策点与责任人
- [ ] 前 3 大风险有可观测信号与预案
- [ ] 全文无「赋能 / 抓手 / 打法升级」类空词

## 工具用法

- `calc` 算增长率 / 目标缺口；`csv_analyze` 分析现有经营数据（如可用）。
- `web_search` / `web_fetch` 收集外部信息，标注来源与日期；图表用 chart / mermaid 代码块。
- 呈现：`::: kpi`（关键指标）、`::: timeline`（季度节奏）、`::: option`（路径对比与推荐）。

## 输出约定

- 规划文档：`docs/战略规划-<周期>.md`；一页版摘要放文首（O + KR 表）。
- 附录：数据出处清单 + 被否决方案记录（防止半年后重复讨论）。
