# 舆情与公告分析

## 数据底座

- `fin_news`（新闻列表，含来源与信源等级）；外部核实用 `web_search` / `web_fetch`（如可用）。
- 时间对齐用 `date_calc`；比例与幅度计算用 `calc`。

## 事件分级（四级）

| 级别 | 示例 | 影响路径 |
| --- | --- | --- |
| 政策级 | 行业监管 / 补贴 / 利率 | 全行业估值与预期 |
| 业绩级 | 业绩预告 / 快报 / 年报 | 盈利预期修正 |
| 事件级 | 重组 / 增减持 / 回购 / 问询 | 治理与流动性 |
| 情绪级 | 热点话题 / 社区讨论 | 关注度与波动 |

分级看「影响路径 + 确定性」两个维度：路径清晰 + 确定性高 = 高优先级。

## 预期差框架

- 超预期 / 符合 / 低于——必须给出对照基准：上期数据、市场一致预期（如有）、历史同期。
- 无基准不给方向判断；「感觉超预期」不算预期差。

## 公告类型影响速查

| 公告 | 常见解读方向 | 注意 |
| --- | --- | --- |
| 业绩预告 | 与预告区间上 / 下限对照 | 看扣非口径 |
| 股东增减持 | 减持 = 供给增加信号 | 关注比例与节奏 |
| 回购 | 信心信号 | 看是否注销与执行进度 |
| 重大重组 | 预期重构 | 不确定性极高，标注「未落地」 |
| 问询函 / 处罚 | 风险信号 | 看回复内容与整改进展 |

## 信源等级与核实

- 官方公告 > 权威媒体 > 一般媒体 > 自媒体；重要信息至少两源交叉。
- 单一自媒体来源统一标注「未核实」；需要登录 / 付费的内容不抓取，如实说明获取限制。

## 情绪极值识别

- 热度极高 + 信息已充分扩散 = 利好可能已被定价（「利好出尽」结构）；
- 情绪极度悲观 + 基本面未恶化 = 关注「错杀」与后续验证信号。
- 区分情绪驱动与基本面驱动：结合成交结构与信息流强度判断。

## 输出纪律

- 事件时间线（公告 → 跟进 → 市场反应）；每条信息标注时间 / 来源 / 等级 / 是否已核实。
- 不给「利好 / 利空」操作结论；给影响路径、预期差方向、待观察信号。
- 未核实清单单列，不混入结论区。
