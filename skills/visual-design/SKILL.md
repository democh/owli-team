# 视觉稿手册

两步走：**先写设计哲学（怎么表达），再做画面（表达什么）**。产出为自包含 HTML 单文件——浏览器打开即见，可截图、可打印。

## 第一步：设计哲学（3–5 段，先落盘）

1. **命名一个方向**（1–2 个词）：「混凝土诗」「色域语言」「静默几何」。
2. 用 4–5 段说清造型语言：空间与形、色彩与材质、尺度与节奏、构图与平衡、文字的角色。
3. **文字是视觉元素，不是正文**：页面文字只保留核心短语（标题 + 1–2 个标签），信息靠构图传达。
4. 哲学要给出「可执行的选择」：主色、留白比例、元素重复方式——供第二步直接照做。

## 第二步：画面（HTML 单文件）

- **版式**：先定一个主构图（网格 / 对角 / 中心放射），全图只用一个；元素按统一模数对齐。
- **色彩**：从哲学规定的色域取值；一色主导，accent 只出现 1–2 处。
- **留白**：边缘留白不小于画布 6%；元素之间最小间距 ≥ 画布宽度的 2%。
- **重复与图案**：用重复元素（点阵 / 线条 / 形状）建立秩序，但重复要成系统，不能随意散落。
- **字体**：最多两个家族（一个承担标题、一个承担标签）；字号层级悬殊（大极大、小极小）。
- **响应式下限**：至少在 1280 宽与移动端两档不破版。

## 硬性约束

- 任何元素不得越出画布、不得互相重叠、不得贴边；文字必须有呼吸空间。
- 文本对比度可读（正文 ≥ 4.5:1）；不使用「浅底浅字」的花活。
- 单文件、零外链（无 CDN / 无外部字体）；图形用 CSS / 内联 SVG 绘制。
- 不直接临摹现有艺术家作品或竞品视觉；参考只取结构思路。

## 自检：像不像外行做的

- 删掉一个装饰元素（「出门前摘掉一件配饰」），画面是否更整？是则删。
- 缩小到 25% 看：主次关系还在吗？还在说明构图成立。
- 打印成黑白看：明度层级是否仍可辨？
- 找一处「最弱元素」删掉：删完更好即执行。

## 检查清单

- [ ] 哲学文档先落盘，画面能从哲学逐条对照
- [ ] 无越界 / 重叠 / 贴边；留白达标
- [ ] 文字量 ≤ 全图 10%；无大段正文
- [ ] 单文件可离线打开；打印样式正常
- [ ] 色彩来源哲学规定；对比度达标
- [ ] 无临摹他人作品

## 工具用法

- `write_file` 落盘 HTML 与哲学说明；改版用 `edit_file` 微调具体元素。
- 需要真实素材时用 `::: cols` 排对照说明；示意图形自行绘制，禁止外链图片。
- 品牌项目先读 `docs/品牌规范.md`（无则先走 `brand-system`）。

## 输出约定

- 稿：`docs/brand/<物料名>-<日期>.html`；哲学说明：同目录 `<物料名>-设计说明.md`（含色值与字号表）。
- 交付时注明：画布尺寸、适用场景（投屏 / 打印 / 社媒）、版本。

## 常见的坑

- **风格堆砌**：把多个流派元素塞进一张物料——方向只有一个，混搭即失焦；
- **哲学挂墙**：设计说明写了五段，物料里一个细节都对不上——说明必须能指导具体选择；
- **对比度不达标**：浅灰文字配浅底——正文对比度 ≥4.5:1 是底线；
- **外链素材**：引用在线图片 / 字体——单文件必须离线可开；
- **临摹撞车**：照着某个热门作品改色——原创性红线；
- **信息过载**：一屏塞十组信息——先砍到三组主信息再排版。
