# 数据表达手册

图表只服务一个目的：**让读者更快拿到结论**。先写结论句，再选图，最后才画。

## 使用步骤

1. **写结论**：一句话说清这组数据说明了什么（含方向与幅度），图表标题直接用它。
2. **选图**：按表达任务对号入座（见下表）；拿不准就退回「表 + 结论句」，不要硬画。
3. **标口径**：单位、样本量、时间范围、来源——缺一不可，写在图题或注释里。
4. **画**：用 Markdown 扩展的 `chart` 代码块（ECharts）或 `mermaid` 代码块；两者在界面中直接渲染。
5. **自检**：对照下方清单；图表数量超过 5 张时砍掉重复信息的那几张。

## 选图对照

| 表达任务 | 首选 | 避免 |
| --- | --- | --- |
| 趋势（时间序列） | 折线图；≤ 5 条线 | 多指标塞一张图 |
| 对比（类别间） | 横向条形图（长标签） | 饼图比大小 |
| 构成（占比） | 堆叠条 / 环形图（≤ 6 项） | 多环嵌套 |
| 分布 | 直方图 / 箱线 | 只用平均数概括 |
| 进度 / 达成 | KPI 卡（::: kpi 容器） | 仪表盘堆叠 |
| 流程 / 关系 | mermaid 流程图、时间线（::: timeline） | 装饰性插图 |

## 图表纪律

- **一图一结论**：标题即结论句（「投放在 8 月转正：ROAS 由 1.2 升至 2.1」），不写「投放数据图」。
- **坐标轴不截断**：纵轴从 0 起，除非差异小于 5% 且已在注释说明；不靠视觉误导放大差异。
- **颜色有意义**：同维度同色、跨图一致；重点系列用强调色，其余灰化。
- **标注关键点**：极值、拐点、异常点直接在图内打标（数据标签 / 注释）。
- **口径一致**：同页多图必须同口径；不同口径的分开呈现并在标题标明。
- **少即是多**：去网格线、去背景色块、去 3D、去阴影——保留数据墨水。

## chart 代码块示例

````markdown
```chart
{
  "title": { "text": "月度投放 ROAS（来源：投放台账.csv，2026-07 至 2026-09）" },
  "xAxis": { "type": "category", "data": ["7月", "8月", "9月"] },
  "yAxis": { "type": "value", "name": "ROAS" },
  "series": [{ "type": "line", "data": [1.2, 1.8, 2.1], "markPoint": { "data": [{ "type": "max" }] } }]
}
```
````

## 检查清单

- [ ] 每张图有结论式标题 + 口径注释
- [ ] 图形类型与表达任务匹配；无色觉误导
- [ ] 数据与统计来源标注（文件 / 工具 / 日期）
- [ ] 图表数量 ≤ 5；删掉信息重复的
- [ ] 图内文本在深浅两套主题下都可读（用语义色）

## 工具用法

- 渲染载体：Markdown 扩展的 `chart`（ECharts）与 `mermaid` 代码块；KPI 卡与时间线用 `::: kpi` / `::: timeline` 容器。
- 数据来源：有 CSV 且 `csv_analyze` 可用时，先汇总再作图；计算经 `calc`（如可用）。
- 报告型交付件中，图与结论句相邻放置，先结论后图。

## 输出约定

- 图表作为报告的组成部分（`docs/<主题>-分析.md`），不单独交付无上下文的图文件。
- 数据分析类报告的结尾附「数据与口径附录」：来源文件、样本量、统计窗口。
