# 合同审阅手册

## 标准条款清单

按此清单逐条过，一项不落：

1. **主体与背景**：签约方信息、资质是否齐全。
2. **权利义务**：交付物 / 服务范围 / 验收标准是否明确可测。
3. **付款**：金额、节点、发票、逾期利息、尾款条件。
4. **交付与时间**：里程碑、延期处理、不可抗力。
5. **违约与赔偿**：赔偿上限、违约金比例、是否含间接损失。
6. **知识产权**：成果归属、授权范围、既有 IP 保留。
7. **保密**：范围、期限、例外情形。
8. **终止**：终止条件、通知期、终止后义务（数据返还等）。
9. **争议解决**：管辖法院 / 仲裁、适用法律。
10. **其他**：变更方式、通知送达、附件效力。

## 三级风险分级

| 级别 | 判定标准 | 处理建议 |
| --- | --- | --- |
| 高 | 可能违法、无限责任、单方变更权、苛刻赔偿、权利完全让渡 | 必须修改或拒绝，写明最坏后果 |
| 中 | 表述模糊、缺少验收 / 变更机制、付款条件不利 | 建议补充协议或替换措辞 |
| 低 | 格式与流程类问题 | 记录即可，不阻塞签署 |

- 高风险项单独置顶成清单，每条附「原文位置 + 风险说明 + 建议动作」。
- 语气纪律：区分「必须修改」（高）与「建议调整」（中低），不混用。

## 修改建议模板

> **原条款（第 X 条）**：……原文摘要……
> **风险**：[级别] 具体说明。
> **建议措辞**：「……可直接粘贴的替换文本……」
> **理由**：一句话说明为什么（法律依据 / 商业公平性）。

- 建议措辞必须完整可粘贴，不写「建议协商一个合理的数字」。

## 审阅纪律

- 先通读全文再逐条下笔；结论附条款定位，不脱离上下文评价单句。
- 法律依据先核实（web_search 现行法律 / 司法解释），标注来源；不确定领域明确写「超出知识范围，建议咨询执业律师」。
- 只给风险判断与建议措辞，不做「签或不签」的最终决定；不代拟正式法律文书。

## 免责口径

- 交付件开头与结尾均注明：本文为条款风险梳理与建议，属非正式法律意见；重大合同请经执业律师确认后签署。

## 常见的坑

- **脱离上下文评单句**：只把某句拎出来说「有风险」——每项意见必须附条款定位与全文语境；
- **措辞不可用**：「建议协商合理的违约责任」——建议必须是可直接粘贴的替换措辞；
- **风险未分级**：所有条款都说「重要」——三级分级才能让用户聚焦高风险项；
- **越权拟文书**：把非正式意见写成正式法律文件——越界；
- **依据不核实**：引用法条不核对现行版本——法律依据必须检索官方来源并标注版本与日期；
- **遗漏最坏后果**：高风险项只标级别不说「最坏会怎样」——分级之外必须给后果评估。
