## 1. 产品定位

Owli Team 是一个**本地 / 私有服务器自部署**的多角色 AI 协作应用。它不是"一个聊天框里换个提示词"，而是一整套**团队协作基础设施**：

- **虚拟团队**：41 大场景（研发团队 / 商业战略 / 深度研究 / 投资研究 / 市场增长 / 财务法务 / 玄学文化 / 生活消费…）共 163 位角色资产，同一会话内自由混搭、共享上下文；
- **自主协作**：角色之间通过 `@某角色` 或结构化 `handoff(target, reason, expected_output)` 工具自主转交任务，形成接力链；同一角色还能挂载多套「灵魂」人格变体（甚至多魂同台）；
- **真实交付**：内置 55+ 工具（文件读写 / apply_patch / Git 六件套 / 联网检索 / 浏览器操控 / 数据库查询 / 绘图…），高风险动作（git_commit、run_command、覆盖写）触发**人在回路审批**；
- **可控可证**：每次运行（Run）的波次调度、工具调用、token 消耗、成本、压缩事件全量落库，提供 Trace 轨迹、指标面板与评测回归门禁；
- **多用户协作平台**：账号体系、会话共享（editor/viewer）、通知中心、在线状态、素材库与技能库等平台治理能力齐备。

![主界面：三栏工作台](intro-shots/01-main-home.png)
*主界面：左侧会话/联系人区、中间消息流、右侧团队面板，顶栏是全局导航与账号区*

## 2. 快速开始

**环境要求**：Node.js 22.5+（推荐 24，持久化依赖内置 `node:sqlite`）；系统 `git`（仅 repo / worktree 模式需要）。

```bash
npm install
cp .env.example .env    # 必填：填入 LLM_API_KEY（未配置时服务拒绝启动）
npm run dev             # 同时启动 server(8787) + client(5173)
```

打开 http://localhost:5173 ，在左栏「新建会话」进入**组队台**：选来源（快速组队 / 按场景）→ 角色池增减成员 → 编制与灵魂微调 → 创建。发送消息即可看到接力链实时推进；`@`多位成员可触发并行波次。

常用命令：

| 命令 | 说明 |
| --- | --- |
| `npm run dev` | 双端开发模式（Vite HMR + tsx watch） |
| `npm run build` / `npm start` | 生产构建 / 单端口生产托管（默认 8787） |
| `npm run test` | 全量测试（server + client vitest） |
| `npm run eval` | mock 基线评测（64 个任务 + 回归门禁） |
| `npm run e2e` | Playwright E2E（63 个 spec / 145 条用例） |
| `npm run check:agents` | 校验 Agent 资产包（六段骨架 + 质量报告，CI strict 门禁） |
| `npm run llm:ping` | 探测真实模型连通性 |

离线体验（零网络、无需 Key）：在 `.env` 中设 `LLM_MOCK=true`（仅演示 / 测试，生产勿开）。

## 3. 核心特点

### 3.1 组队台：41 场景 × 163 角色任你组队

新建会话不再需要逐页向导——**一屏完成组队**：左侧选来源（空场景 / 快速组队预设 / 按场景筛选），中间角色池搜索增减，右侧实时编制与灵魂微调。顶部场景分类实时统计（研发团队 13、商业战略 4、深度研究 4…），角色卡片带有场景徽章、灵魂标记与能力标签。

「**快速组队**」预设把常见任务编成模板：周经营例会、内容营销战役、产品发布冲刺、报税合规检查、融资冲刺、多空对决、外包与招聘……一键以推荐编制开局，也可「自由组合」从零挑人。

### 3.2 接力与编排：一场对话里的团队流水线

用户只需一句话点名，团队就会**自主接力**：被 @ 的角色出场作答，需要下游协同时通过 `handoff` 工具把任务交棒给下一位（附「期望产出」），层层推进直到交还用户。

- **交接条**将每次接力可视化：`费利 → 艾达`（点击接手者头像=一键接棒）；
- **接力链**在右侧「接力」视图按时间轴复盘：谁把什么交给了谁、附带了哪些交付件与工具次数；
- **循环检测**（波次签名序列 + 内容 3-gram）在团队空转时自动收尾交还用户，不刷屏；
- **动态成员**：运行中可随时邀请 / 移出成员（落系统事件条，不进 LLM 窗口），加人从下一回合即时生效；
- **平台路由（PRS）**：未 @ 的消息由引擎以结构化决策自动「召集 + 派发」，召集与派发全程可在 Trace 审计。

### 3.3 并行波次：多人同时开工，波末统一收敛

这是 Owli Team 区别于"轮流发言"式多 Agent 的关键机制：

- **显式触发**：消息中 `@` ≥2 位成员、`handoff` 多目标（≤4 = fan-out），或场景声明 `parallel: true`；
- **波内隔离**：同波成员相互不可见对方当前输出，统一基于「波前历史」生成——避免鸡同鸭讲，保证观点独立；
- **fan-in 收敛**：波末把各成员的转交意向合并裁决为下一波队列，统一收敛；
- **会话开关**：会话级「串行执行」开关（默认开启：逐位出场便于跟进；关闭后同场景成员并行成波，推进更快）。

### 3.4 能真干活：55+ 工具与人在回路审批

角色不是只会"说"，而是能真正**操作工程环境**：

- **55+ 内置工具**（21 常驻 + 34 延迟加载）：文件读写 / glob / grep / apply_patch、Git 六件套、web_search（四级降级链）与 web_fetch、待办 write_todos、记忆 remember、Skill 加载、handoff 转交、浏览器操控、数据库查询、金融行情 `fin_*` 等；
- **只读并行 + 写类串行**：同类工具的调用被引擎自动分流，60s 幂等缓存、超时与取消真中断（无遗留副作用）；
- **沙箱**：工具沙箱以会话隔离的 `workspace/` 为根，敏感文件（`.env` / `.ssh` / `*.pem`）默认拒绝；`run_command` 白名单；
- **HITL 审批**：高风险动作（`git_commit` / `run_command` / 覆盖写）触发**审批卡**并挂起 Run，批准 / 拒绝 / 超时都会回灌模型继续推理；
- **交付件体系**：角色写出的产物自动登记为版本化交付件（可 Diff、可签收、可提意见），K 线快照等二进制同样入列；
- **停止与插话**：运行中可随时「停止」；再发消息即**插话**（回合边界注入，不打断当前生成）。

### 3.5 可控可证：全链路 Trace、指标与成本

每一次运行都是"可审计事件流"，而不是黑盒：

- **运行轨迹（Trace）**：逐条记录 Run 开始 / 波次开始（含 `parallel` 标记）/ 回合开始结束（耗时、token）/ 调度决策（谁交给谁、上下限、下一棒）/ 工具调用 / 记忆入库 / 循环抑制——毫秒级时间轴；
- **指标面板**：24h / 7d / 全时段聚合——运行数、回合数、平均回合耗时、输入/输出 token、费用、工具调用次数与失败率、工具排行、**调度健康**（路由 / 波次 / 并行数 / 循环抑制 / 写冲突）、用量拆分；
- **成本可见**：每条消息组页脚显示「本 Run $0.0319」等实时费用；
- **评测闭环**：`npm run eval` 64 个任务（56 golden + 8 真实模式探针 + 回归门禁）保障 prompt 与引擎改动质量；
- **持久化与恢复**：消息 / 运行 / 任务 / 记忆 / 摘要 / usage / 交付件版本 / 工具指标全量落库；崩溃重启后未完成 Run 标记 `interrupted`，支持「从断点继续」。

### 3.6 上下文工程：五层装配 + 滚动摘要

长期协作不失忆，源于一套完整的上下文体系：

- **五层装配**：L0 协作协议 → L1 记忆 → L1.5 语义召回 → L2 历史摘要 → L3 半静态（含运行时上下文）→ L4 最近回合 → L5 工具结果，分层配额装配；
- **滚动摘要压缩**：超过预算 × 0.7 自动按「回合组」压缩为结构化摘要并增量合并，压缩事件进 Trace；
- **运行时上下文全角色注入**：当前日期 / 星期 / 时区 / 运行环境自动进 system 尾段（天级稳定护前缀缓存）；
- **向量记忆（可选）**：四层关联（会话 / 角色 / 项目 / 全局）的语义记忆，混合评分召回注入 L1.5，未配置即模块休眠；
- **上下文电池**：输入区右下角实时显示占用百分比（如 `9% · 18.4K / 200K tokens`），点开可查看分层明细与摘要。

### 3.9 平台治理：素材库 / 技能库 / MCP / 连接中心 / 多用户

- **素材库**：图片 / 视频 / 音频集中管理（缩略图网格、拖拽上传），供角色在画布与对话中引用；
- **技能库（Skill）**：72 个技能文档按职能分组（研发 / 设计 / 数据 / 研究 / 营销 / 客服 / 财务法务 / 投资研究 / 运营 / 战略 / 玄学 / 生活等），角色显式预载或按需加载（`skill` 工具），生产级质量门禁（资产校验通过徽章）；

## 6. 技术架构

```
共享层      shared/            协议单一事实源（Session / ChatMessage / RunEvent / NotifyEvent / Artifact…）
资产层      agents/ skills/    41 场景 163 角色资产包 + 72 技能文档
服务端      server/            Express + ws
  ├─ orchestration/            parser（@解析）→ scheduler（波次规划/转交裁决/循环检测）→ engine（波次循环 + 工具循环 + 审批挂起）
  ├─ context/                  tokenizer / 五层装配器 / 滚动摘要压缩器
  ├─ llm/                      OpenAI 兼容 provider + 韧性层（重试退避 / 超时分层 / 并发信号量）
  ├─ tools/                    工具注册表（只读并行 / 写类串行 / 幂等缓存）+ 55+ 内置工具 + MCP 适配层
  ├─ routes/                   agents / sessions / runs / artifacts / context / settings / metrics / finance / shares…
  ├─ store/                    持久化（当前 SQLite node:sqlite + sqlite-vec，WAL + 迁移器；PostgreSQL 迁移设计中，见 docs/pg-redis-migration-design.md）
  └─ ws.ts                     NotifyHub（订阅 / 心跳 / 环形重放）+ 鉴权握手
前端        client/            React 18 + Vite + Tailwind
  ├─ stores/                   zustand（agent / session / run / task / ws / ui，byId+order O(1) 订阅）
  └─ components/               三栏布局 / 虚拟消息列表 / 审批卡 / Diff / 上下文电池 / 组队台 / 协作图谱 / 画布 / 实况…
评测        evals/             64 任务评测 + baseline 回归门禁
E2E         e2e/               Playwright 63 spec / 145 用例（mock 模式）
```

**技术栈**：React 18 · TypeScript 5 · Vite · Tailwind · shadcn/ui（Radix）· zustand · react-markdown · shiki · @tanstack/react-virtual · React Flow · Express · ws · zod · openai · js-tiktoken · pino · SQLite（node:sqlite + sqlite-vec）· vitest · Playwright。

**运行形态**：本地 `npm run dev`；Docker 一键部署（`docker compose up -d --build`，内置 AUTH_TOKEN 强制鉴权）；亦可单端口生产托管（`npm run build && npm start`）。
