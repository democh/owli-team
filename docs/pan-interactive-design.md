## 1. 背景与目标

### 1.1 现状与用户诉求

用户原话：**「不要只是简单的表格，可以增加交互和游戏性，让用户参与感更强」**。

M53 交付后的四张盘面卡信息已专业化（八字 11 字段 + 大运 8 + 流年 10；紫微 6 字段 + 12 宫；
星盘 3 字段 + 38 条目；卦 8–9 字段 + 六爻），但呈现方式仍是**静态行渲染**——阅读是单向的：

- `PanCard`（聊天卡）：字段行 / 条目行，零交互；
- `PanBoard`（chartboard 面板）：多盘 tabs + 「看解读」，本体仍是静态行。

关键机会：盘面数据已**全量在卡内**（黄经与度数、干支、大限年龄、世应动变、六爻数……），
且卡格式已被契约测试（`m53-pan-card`）锁定——**交互化可以做到纯前端派生、零工具、零协议变更**。

### 1.2 设计目标（验收导向）

| 目标 | 验收信号 |
| --- | --- |
| 表格 → 可玩 | 四张盘各有专属视图（装卦剧场 / 人生时间轴 / 十二宫巡游 / 黄道轮盘）；点击、悬停、拖动、键盘均可操作 |
| 参与感 | 可「亲手摇卦」「报数起卦」并把结果作为草稿提问；盘面档案可收藏对照；八字×紫微时间轴合参 |
| 零契约变更 | server 工具与卡格式一行不改；agents 仅 M54-C 微调 metaphysics 协议 1 条（用户自带种子须工具复算） |
| 最差等于今天 | 任何解析失败 / chunk 加载失败 / 流式未成形 → 回退到今天的静态表；「表格」视图永不删除 |
| 不增主包 | 全部新增走按需 chunk（`React.lazy`）；主包 gzip 持平（ADR 0112 既有欠账不扩大） |
| 合规 | 无吉凶评分 / 每日运势 / 签到排行 / 恐吓话术；参与 = 研习与仪式（§5.6 红线表） |

## 2. 总体设计：可玩盘面（Playable Pan）

### 2.1 三层架构

```
┌ 参与层 Participation ── 亲手摇卦 · 报数起卦 · 盘面档案/对照 · 时间轴合参 · 研习足迹
│        （把你放进盘里）    产出=草稿回填（ADR 0064：用户确认后发送）
├ 交互层 Exploration ── 点宫位看三方四正 · 悬停行星亮相位弦 · 拖动大运 scrub · 键盘
│        （盘面会回应你）    全部本地态（sessionStorage ma:pn:*），不落库
└ 呈现层 Presentation ─ 装卦剧场 · 人生时间轴 · 4×4 宫格 · 黄道轮盘
         （表格变成盘）    数据 = 卡内 fields/items 纯前端派生（零新增数据）
```

### 2.2 立盘五原则

1. **卡仍是唯一权威**：不做数据新增或改写，只把已有行重组为空间结构；「先盘后论」契约不变，
   盘面视图与表格视图同源同数据。
2. **纯前端派生**：全部交互数据可由卡格式确定性推导（§3 逐条给出解析规则），不调工具、不改协议。
3. **表盘并存**：任何视图都可一键回「表格」（完整原卡内容，无信息损失）；表格也是回退终点。
4. **参与即草稿**：全部参与产出（摇卦、报数、请教宫位……）一律写入 Composer 草稿，用户可编辑、
   确认后发送（同 ChoiceCard / ADR 0064 语义）。
5. **仪式而非赌博**：随机性透明可复现（种子显式展示）；无分值、无连击、无排行、无奖励。

## 3. 数据派生层（零契约变更的解析与换算）

新模块 `client/src/components/chat/md-ext/pan/`，**纯函数、无 DOM、无 React**，
输入即 `PanCard.parsePanRows` 解析出的 `PanRowData[]`（fields / items），可直接单测。

### 3.1 通用换算

| 派生项 | 规则 | 来源示例 |
| --- | --- | --- |
| 星座度数 | `金牛 21.2°` → sign=金牛（signIndex=1）、deg=21.2；黄经 = signIndex×30 + deg | 行星 / 宫头 |
| 括号黄经 | `（51.24°）` → 精确黄经（存在时优先） | 行星 |
| 干支拆解 | 两字：天干 + 地支（`壬午` → 壬 / 午） | 四柱 / 宫干支 / 大运 |
| 五行计数 | `木3 火3 土2 金2 水2` → {木:3, 火:3, 土:2, 金:2, 水:2} | 八字「五行」字段 |
| 数字区间 | `9-18 岁` → [9,18]；`1998-2007` → [1998,2007] | 大运条目 |
| 当前标记 | 尾部 ` · 当前大运` / ` · 当前` | 大运 / 流年 / 大限 |
| 全角分段 | 值内按全角 `｜` 切段后逐段 trim（段数不定，按关键词定位，不按位置） | 紫微 / 星盘条目值 |

### 3.2 八字（bazi）派生

卡：`::: pan bazi 四柱 庚午 辛巳 丁丑 丁未`；字段 11；条目 = 8 大运 + 10 流年（当前大运内）。

| 目标模型 | 解析规则 | 示例 → 结果（实测见 A.1） |
| --- | --- | --- |
| `pillars[4]` | 字段「四柱」按空格切词、过滤干支词（2 字）；尾部 `（男）` 类非干支词忽略 | `庚午 辛巳 丁丑 丁未` → [{庚,午},{辛,巳},{丁,丑},{丁,未}] |
| 五行色 | 天干五行表（甲乙木…壬癸水）+ 地支五行表（内置常量，口径同 `server/src/pan/types.ts`） | 庚→金、午→火 |
| 日主 | 字段「五行」尾段 `/日主 (\S)（(.+?)）/` | 丁 · 阴火（可选，缺失不阻断） |
| 十神 | 字段「十神」按空格取 4 词（与四柱对齐；日柱位固定为 `日主`） | `正财 偏财 日主 比肩` |
| 起运 | 字段「起运」`8 年 2 月 20 日 ｜ 1998-08-01 交运 ｜ 大运顺行` → 交运日期 + 顺逆行 | 时间轴起点 1998-08-01（可选） |
| 大运 | 条目 `- 大运 甲申 \| 29-38 岁 ｜ 2018-2027 · 当前大运` | {ganZhi:'甲申', ages:[29,38], years:[2018,2027], current} |
| 流年 | 条目 `- 流年 2026 丙午 \| 37 岁 · 当前` | {year:2026, ganZhi:'丙午', age:37, current} |
| 柱详情 | 字段「藏干 / 纳音 / 空亡 / 地势」原样保留（不拆解，popover 直显 label:value） | `午(丁己) 巳(丙庚戊)…` |

必需：四柱 = 4 干支词 + 五行 = 5 键 + ≥1 大运条目且全部大运行可解析；任一不满足 → 回退表格。

### 3.3 紫微（ziwei）派生

卡：`::: pan ziwei 紫微 土五局 ｜ 命宫 丙戌`；条目 = 12 宫。

| 目标模型 | 解析规则 | 示例 |
| --- | --- | --- |
| 宫（label） | `命宫 丙戌 [身宫]` → 宫名 + 干支（第 2 词）+ 可选身宫标 | 命宫 / 丙戌 |
| 主星（值段） | 值按 `｜` 切段并锚定 `长生` / `大限` 段后，剩余段依序：第 1 段 = 主星段（`太阴(旺)科` → {name, brightness, mutagen}；空格分隔多星；`（空宫）` → []）、第 2 段 = 辅星段、`杂 ` 前缀段 = 杂曜段；段数不定 | 太阴(旺)科 → 太阴·旺·科 |
| 辅星 / 杂曜 | 辅星段 / 杂曜段原样保留（宫详情直显，不进高亮逻辑） | 铃星(庙) · 杂 解神 龙池 华盖 旬空 |
| 长生 | 含 `长生 ` 段 → 第 2 词（十二长生） | 长生 冠带 → 冠带 |
| 大限 | 含 `大限 ` 段 → `35-44 · 当前` → {range:[35,44], current}；非当前无尾注 | 巡游 / 合参（当前 = 田宅 己丑） |
| 格位 | 地支固定映射（下表） | 4×4 定位 |
| 三方四正 | 地支序号 n（子=0…亥=11）：三合 = n±4、对宫 = n+6 | 高亮组 4 宫 |
| 中宫 | 字段「五行局 / 命身宫 / 来因宫 / 生年四化」；生年四化按 `禄 太阳 ｜ 权 武曲 ｜ 科 太阴 ｜ 忌 天同` 拆 chips | 命主 禄存 · 身主 火星 · 来因宫 迁移 庚辰 |
| 四化色 | mutagen ∈ 禄/权/科/忌 → 4 固定语义色 + 文字双编码 | 星名色签 |

传统 4×4 盘式（地支固定位置，行 0 为顶行）：

```
   巳  午  未  申
   辰          酉
   卯          戌
   寅  丑  子  亥
```

必需：12 条目、每条可切出「宫名 + 2 字干支」且含 `大限 ` 段、12 地支无重复；任一失败 → 回退表格
（宁可回表，不摆错格）。注：**条目顺序自寅宫起（盘序），格位一律按干支的地支映射**，禁止按条目序摆放。

### 3.4 星盘（natal）派生

卡：条目 = 10 行星 + 12 宫头 + 16 相位。

| 目标模型 | 解析规则 | 示例 |
| --- | --- | --- |
| 行星 | `- 太阳 \| 金牛 21.2°（51.24°）｜ 9 宫` / `- 水星 \| 金牛 8.8°（38.79°）｜ 8 宫 ｜ 逆行` | {name:'太阳', sign:'金牛', deg:21.2, lon:51.24, house:9, retro:false} |
| 宫头 | `- 宫头 1 \| 处女 16.0°`（无括号值） | {house:1, lon: 5×30+16.0 = 166.0}（黄经 = signIndex×30 + deg） |
| 相位 | `- 太阳-土星 \| 拱相 4.1°` | {a:'太阳', b:'土星', type:'拱相', orb:4.1} |
| 相位类型 | 合相 0° / 六合 60° / 刑相 90° / 拱相 120° / 对分 180°（与 `server/src/pan/natal.ts` ASPECT_DEFS 同源） | 弦角与线型 |
| 四轴 | 字段「宫制」中 `ASC 处女 16.0°` → 轮盘置左基准（MC / DSC / IC 同段可选）；缺 → 0° 白羊置左 | 旋转偏移 |
| 元素 / 模式 | 字段「元素」`火2 土5 风0 水3 ｜ 模式：基本5 固定3 变动2` | 底条 |

必需：≥1 行星且黄经可解析（否则回退表格）；宫头**恰 12 条且全可解析 → 全轮盘**，
否则精简轮（只画星座环 + 行星，不摆错宫）。

### 3.5 卦盘（gua）派生

卡：`::: pan gua 天雷无妄 → 天火同人`；条目 = 6 爻（**上→下**，渲染时反转）。

| 目标模型 | 解析规则 | 示例 |
| --- | --- | --- |
| 爻（label） | `六三 动` / `九四（世）` → 爻题 + 可选（世/应）+ 可选 ` 动` | pos=3 · 阴 · 动；pos=4 · 阳 · 世 |
| 爻题→位/性 | 初/二/三/四/五/上 → 位 1-6；九=阳、六=阴 | 上九 → 第 6 爻·阳 |
| 爻（值） | `勾陈 妻财 庚辰 土 → 己亥 水 父母` → 六神 + 六亲 + 干支 + 五行 + [空亡] + [→ 变爻] | 六神 勾陈 · 六亲 妻财 · 庚辰 · 土 · 变 己亥水父母 |
| 空亡 | 值尾段 ` 空亡` → 空亡星标（虚线角标） | `白虎 官鬼 壬申 金 空亡` → 九五 空亡 |
| 变爻 | `→ 己亥 水 父母` → {ganZhi, wuxing, liuQin}；有 → 该爻即动爻 | 变卦剧场 |
| 变卦全图 | 本卦六爻模式 + 动爻取反 = 变卦模式；变卦名取标题 `→` 右侧（`互卦：… ｜ 变卦：X（…）` 可交叉校验） | 天火同人 |
| 六爻数 | 字段「六爻数」`初7 二8 三8 四8 五9 上6`（coin 卡专有） | 摇卦对照 |
| 错 / 综卦 | 字段「错卦」「综卦」名称（卡内已给） | 小图预览 |
| 装卦回放 | 条目已含全部展示数据，回放仅是时间轴表演 | 无额外计算 |

必需：恰 6 条爻条目、位/性可解析且 pos 覆盖 1..6 各一次；失败 → 回退表格。

### 3.6 摇卦复现（与工具逐位同源）

「亲手摇卦」的结果必须与 `gua_pan(method=coin, seed)` 完全一致——算法（`server/src/pan/gua.ts`）：
`mulberry32(seed)`；每爻 3 枚铜钱 `rand() < 0.5 ? 2 : 3`（字=2、背=3）；6 爻自初爻起；
和 6=老阴（动）、7=少阳、8=少阴、9=老阳（动）。

客户端移植：

- `pan/coin.ts`：mulberry32 + 摇卦逐爻生成（与 server 逐字一致）；
- `pan/hex.ts`：64 卦名表（自 server `HEX_NAMES` 原样移植；bits 键 = 初→上），
  用于即时显示「你摇出了《天雷无妄》之《天火同人》」。

对齐保障：server 侧（既有 golden 覆盖）+ client 侧单测对同一组固定种子断言 6 爻数序列；
64 卦名表两侧对 8 个经典卦（乾为天 / 坤为地 / 水雷屯 / 山水蒙…）逐一断言同源。

已验向量（2026-09-19 脚本级复现，与 `gua_pan(method=coin, seed=12345)` 逐位一致）：

```
seed 12345 → 六爻数：初7 二8 三8 四8 五9 上6
           → bits 100010 → 本卦《水雷屯》· 动爻 九五、上六 → 变卦《山雷颐》
```

### 3.7 容错与降级链

```
派生成功 → 盘面视图（默认）
派生失败（必需段缺失）→ 静态表（今天形态），无任何新 UI 噪音
chunk 加载失败 → 静态表（Suspense fallback / ErrorBoundary 兜底）
流式进行中 → 静态表冻结（盘面卡仅在闭标记后才可能成形；成形于流式中的按冻结处理）
浏览器不支持（无 sessionStorage 等）→ 全部本地态静默失效，盘面仍可看（只读）
```

### 3.8 精确解析规格（实现即此表，全部由实测样本回推）

统一前置：值先按全角 `｜` 切段并逐段 trim（段数不定，**按关键词 / 正则定位，不按下标**）；
展示沿用原串精度，计算用 `parseFloat`。

**八字（bazi）**

| 目标 | 规则（对 label 或 value） |
| --- | --- |
| 四柱 | 先剥离 `（…）` 括注（`丁未（男）` 等尾注），再 `split(/\s+/)` 过滤干支词 `/^[甲乙丙丁戊己庚辛壬癸][子丑寅卯辰巳午未申酉戌亥]$/`；有效词 ≠ 4 → null |
| 十神 | 同法取 4 词（可选项；与四柱对齐，日柱位恒为 `日主`） |
| 五行 | 五键计数（任一顺序可容）；缺键 → null |
| 日主 | `/日主 (\S)（(.+?)）/` → {gan, yinYang}（可选项） |
| 起运 | `/(\d{4}-\d{2}-\d{2}) 交运 ｜ 大运(顺行\|逆行)/` → {date, direction}（可选项） |
| 大运 | label `/^大运 (\S{2})$/`；value `/^(\d{1,3})-(\d{1,3}) 岁 ｜ (\d{4})-(\d{4})( · 当前大运)?$/`；label 命中而 value 不命中 → **整个派生 null**（宁回表） |
| 流年 | label `/^流年 (\d{4}) (\S{2})$/`；value `/^(\d{1,3}) 岁( · 当前)?$/`；0..N 条（当前大运内一般为 10 条） |

必需门（任一失败 → 表格）：四柱 = 4 且五行 = 5 键 且 大运 ≥1 且全部大运行命中。

**紫微（ziwei）**

| 目标 | 规则 |
| --- | --- |
| 宫 | label `/^(\S+) (\S{2})( 身宫)?$/` → 宫名 + 干支 + 身宫标 |
| 值段 | 按 `｜` 切段后锚定：`长生 X` → 长生段；`大限 A-B[ · 当前]` → 大限段；`杂 …` → 杂曜段；其余依序：首个未占用段 = 主星段（`（空宫）` → 空）、次个 = 辅星段 |
| 主星 | 主星段按空格切 → `星名[(亮度)][禄\|权\|科\|忌]` |
| 四化 | 中宫（生年四化）`/^(禄\|权\|科\|忌) (\S+)$/` 逐段 |
| 格位 | 干支第 2 字 = 地支 → 固定 4×4 格位（§3.3 图）；**不得**按条目序摆放 |

必需门：恰 12 条宫条目且 label 全命中、每条含 `大限 ` 段、地支 12 支无重复。

**星盘（natal）**

| 目标 | 规则 |
| --- | --- |
| 行星 | label 非 `宫头 N`、不含 `-`，且 value 命中 `/^(\S+) (\d+(?:\.\d+)?)°（(\d+(?:\.\d+)?)°）(?: ｜ (\d{1,2}) 宫)?(?: ｜ 逆行)?$/` |
| 宫头 | label `/^宫头 (\d{1,2})$/`；value `/^(\S+) (\d+(?:\.\d+)?)°$/` → lon = signIndex×30 + deg |
| 相位 | label 含 `-` 且 value `/^(合相\|六合\|刑相\|拱相\|对分) (\d+(?:\.\d+)?)°$/` |
| 四轴 | 「宫制」value `/ASC (\S+) (\d+(?:\.\d+)?)°/` → 左基准（缺 → 0° 白羊） |

必需门：≥1 行星且黄经可解析；宫头恰 12 条全可解析 → 全轮盘，否则精简轮。

**卦（gua）**

| 目标 | 规则 |
| --- | --- |
| 爻 label | 爻题枚举 `/^(初九\|初六\|九二\|六二\|九三\|六三\|九四\|六四\|九五\|六五\|上九\|上六)(（(世\|应)）)?( 动)?$/`（通行书法：初 / 上 位名在前，二~五 九六在前）→ pos / 阴阳 / 世应 / 动 |
| 爻 value | `/^(青龙\|朱雀\|勾陈\|腾蛇\|白虎\|玄武) (父母\|兄弟\|子孙\|妻财\|官鬼) (\S{2}) (\S+?)( 空亡)?( → (\S{2}) (\S+?) (父母\|兄弟\|子孙\|妻财\|官鬼))?$/` |
| 六爻数 | 字段逐词 `/^(初\|二\|三\|四\|五\|上)([6789])$/`（coin 卡专有） |
| 卦名 | 本卦名取「本卦」字段第 1 段；变卦名取标题 `→` 右侧（缺 → 由 6 爻 + 动爻取反自行推演，与卡内 `变卦：X` 交叉校验） |

必需门：爻条目恰 6、pos 覆盖 1..6 各一次。

## 5. 参与层与游戏化

游戏化的对象是**研习与仪式**，不是分数与奖励。机制总览：

| 机制 | 玩法 | 产出 | 期 |
| --- | --- | --- | --- |
| 亲手摇卦 | 逐爻摇（6 次点击/空格），三枚铜钱翻转成爻 | 即时应卦 + 草稿（种子） | C |
| 报数起卦 | 输入两数（1-99） | 草稿 | C |
| 盘面档案 | 任意盘「存为档案」 | 本地档案列表，可回看 | C |
| 盘面对照 | 两张同型盘并排 | 差异高亮 | C |
| 时间轴合参 | 会话内八字 × 紫微 | 统一年龄轴双泳道 | C |
| 研习足迹 | 自动累计（本地） | 页脚小字 | C |

### 5.1 亲手摇卦（核心仪式）

1. **入口**：GuaBoard 底部「亲手摇卦」；chartboard 面板头部同按钮（无卦盘也可摇）。
   面板内已有卦盘 → 摇完自动进入**对照模式**（并排显示盘面卡六爻与你所摇六爻）。
2. **摇卦**：开始生成种子 `crypto.getRandomValues(new Uint32Array(1))[0]`（页脚持续显示 `种子 <十进制>`）；
   每爻点击「摇」（或空格）→ 三枚铜钱翻转 600ms → 停定显示 `字 字 背` → 铭牌行入列
   `三爻 少阴 ▬ ▬`；每步铜钱结果由 `mulberry32(种子)` 确定性推演（§3.6），**与工具逐位一致**。
3. **成卦**：六爻毕 → 大字揭晓 `本卦 ｜ 变卦`（本地 64 卦表映射）+ 六爻图；
   对照模式逐爻标点「一致 / 不一致」。
4. **请解**：主按钮「以此卦请解」→ 草稿（§6 模板 1）。
5. **断言纪律**（M54-C 协议微调）：Agent 必须以 `gua_pan` 复算结果为准，禁止直接采信草稿中
   的卦名与动爻结论；复述本卦 / 动爻 / 世应后再解读。
6. **reduced-motion**：跳过翻转动画，点击后直接出结果行；quiet-mode 同。

> **实施补记（v3.3）**：① 面板头部入口实现为 `.pn-toss-enter`「亲手摇卦」，与「合参」toggle 同排右对齐（独立类名——免与 `.pn-alm-toggle` 单元素定位冲突）；对照基线 = 面板内首个可派生卦盘（`derivePan('gua')`），无卦盘 → `compare = null` 直接摇；② 摇卦台宿主为 **AppLayout 级全局单例**（`PanTossHost`，请求经 `ui-store.panToss` 下发）——弹窗不随消息行回收 / 面板卸载消失（消息卡 / 面板内卡 / 面板头部三入口共用同一宿主）；成卦 / 请教程由宿主落账（研习足迹），页脚经 `subscribeTrail` 订阅刷新；③ 焦点约束：Tab 在台内首尾环回弹（尾 → 首 / 首 → 尾，焦点在台外拉入），`focusin` 逃逸自动拉回面板（轻量 trap，配合遮罩点击 / Escape 关闭）。

### 5.2 报数起卦

摇卦台内切换「报数」页签：两数输入（1-99，回车确认）→ 草稿（§6 模板 2）。
不本地预测卦名——数字映射规则不在卡格式内，交工具复算（诚实边界）。

### 5.3 盘面档案与对照

- 「存为档案」：PanCard 头部 ⭐ / PanBoard tab 内按钮；存 `{kind,title,fields,items,raw,savedAt}`
  至 `ma:pn:archive:<sessionId>`（上限 20，FIFO，溢出提示）。
- 档案区：chartboard 面板底部抽屉「档案（n）」；点击即以盘面视图回看。
- 对照：选 2 张同 kind 盘 → 并排 + 差异高亮（八字：逐柱差异框标；紫微：主星集合差异星标；
  卦：爻模式差异行；星盘：行星度数差）。异 kind → 仅并排，不做差异。

### 5.4 时间轴合参（跨盘）

- 触发：会话内同时存在 bazi + ziwei 盘 → chartboard 面板顶部「合参」toggle。
- 视图：统一年龄 / 年份轴（最早出生年 → 最晚终限），两条泳道：
  八字泳道 = 8 段大运（干支 + 年龄区间，当前段 ●；当前大运内标 10 个流年点）；
  紫微泳道 = 12 段大限（宫名 + 年龄区间，当前段 ●）。
- 年份换算：出生年（取自盘内「命造」字段公历日期）+ 年龄；缺出生年 → 该盘泳道只显年龄。
- 交互：点击任一段 → 双泳道重叠段联动高亮；窄屏（<900px）纵向堆叠。
- 边界：**绝不虚构行运数据、不推测应期**；两条泳道之外不添加第三类源。

### 5.5 研习足迹（本地私密）

- `ma:pn:trail:<sessionId>`：`{chartsViewed, palacesTapped, palacesCovered, yaoThrown, linksAsked, lastAt}`
- 展示：盘面页脚只读小字，如 `本次研习：看过 4 张盘 · 十二宫已游历 7/12 · 摇卦 2 次`；
- **明确不做**：连续签到、成就徽章、排行、分享分（防成瘾 + 合规）。

### 5.6 合规红线（对照命理占星协议，实施批次逐条自检）

| 禁止 | 理由 | 本设计的替代 |
| --- | --- | --- |
| 吉凶评分 / 运势分 | 预测承诺 | 只呈现盘面结构与口径说明 |
| 每日运势 / 抽签 | 迷信诱导 | 不提供 |
| 签到 / 连击 / 排行 | 成瘾机制 | 足迹（本地、只读、无奖励、无提醒） |
| 恐吓话术 / 付费化解暗示 | 协议红线 | 术语白话 + 参考区间（不变） |
| 把随机包装为「神谕」 | 记录真实性 | 明示算法与种子可复现 |
| 自动发送参与结果 | ADR 0064 | 一律草稿，用户确认 |

### 5.7 摇卦台状态机（TsToss 实现规格）

```
idle ──开始（新种子）──▶ tossing(i = 0..5) ──第 6 爻定──▶ complete ──重摇全卦（新种子）──▶ idle
  ▲                                                        │
  └───────────────── 关闭 / 刷新（保留进度，可续）────────────┘
```

| 状态 | UI | `ma:pn:toss`（session） |
| --- | --- | --- |
| idle | 开始 + 所问输入（可选） | `{ seed: null }` |
| tossing(i) | 三枚铜钱 + 已定 i 爻铭牌；种子常显 | `{ seed, question, done: i, startedAt }` |
| complete | 本卦 / 变卦大字 + 六爻图 + 对照标点 | `{ seed, question, done: 6, startedAt }` |

- 只存**种子与进度**，不存逐爻结果（结果恒由 `mulberry32(seed)` 现推，杜绝漂移与篡改）；
- 动效：单爻三枚铜钱翻转 600ms（80ms 错峰）→ 定爻入列 → 六爻毕揭晓 900ms；
  `prefers-reduced-motion` / quiet-mode 直出终态；
- 刷新恢复：`0 < done < 6` → 回 tossing(done) 并按种子重放已完成爻（逐位一致）；
- 键盘：空格 / 回车 = 摇下一爻；仅「重摇全卦」（新种子），**无单爻撤销**（保仪式一致性）；
- `aria-live="polite"` 逐爻播报「三爻 少阴 ▬ ▬」；对照模式额外播报一致 / 不一致。
- 渲染：Portal 直挂 `document.body`（遮罩 z 85 直参与根上下文）——消息虚拟列表行的 `transform` 会创建 stacking context 封层，非 Portal 化将被波次条 / 「回到最新」盖过并劫持点击（走查实证：命中栈 mask 置顶）。

### 7.5 流式 / 缓存 / 动效收敛

- 流式：pan 卡仅在闭标记后成形；成形中的卡按 M52「流式冻结」语义（禁用交互、回放不自动播）；

  quiet-mode 保留结构、去除装饰与位移；
- 缓存安全：视图态全在 React state + sessionStorage，不参与 Markdown 缓存键（虚拟列表回收后可恢复）。

### 7.6 无障碍

爻行 / 宫格 / 行星点 = `<button>` + 完整 `aria-label`（如「命宫 丙戌，查看三方四正」）；
宫格与矩阵支持方向键；轮盘 `role="img"` + 汇总 label，矩阵为轮盘的等价可读形态；

### A.6 派生回归要点（由实测回推）

1. 八字条目 label 自带前缀词（`大运 ` / `流年 `），正则须含前缀；「当前大运 / 当前」尾注仅在当前项出现；
2. 紫微条目顺序自**寅**宫起（盘序 ≠ 地支序）：格位一律按 label 干支的地支定位，禁止按条目序摆放；
3. 紫微值段数不定（3–5 段）：`长生 …` 与 `大限 …` 恒存在；空宫写作 `（空宫）` 且其后仍可有辅星段；
4. 星盘「宫头」value 无括号黄经（黄经 = signIndex×30 + deg）；行星恒有括号黄经优先取用；逆行旗标为后置段；
5. 卦：世 / 应与 ` 动` 均写在 label（`九四（世）`、`九五（应） 动`、`六三 动`）；value = 六神 六亲 干支 五行（+ ` 空亡` / ` → 变爻`）；数字起卦卡无「六爻数」、摇卦卡无「所问 / 体用」；
6. 旧 fixture（`m51-md-pan.test.tsx` 等）与实测形状不同 → 派生失败 → 表格回退（即 §7.2 零回归路径本身）。
