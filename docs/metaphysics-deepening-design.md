### 1.2 缺口全景（四类，全部有代码实证）

**A. 占星工具刚性缺口（违反自身协议红线）**
`star transit`（星移）职责「行运盘并与本命对照」、`synastry`（合璧）职责「合盘 / 组合盘」——但 `natal_pan` 只能排**单时刻单盘**：
- 行运星 × 本命星 / 四轴的 cross-aspects **无工具计算** → 落在模型心算区；
- 双盘 cross-aspects（A 星 × B 星）同理 **无工具计算**；
- 两个角色的 AGENT.md 均写明「盘面数据一律来自 `natal_pan`……禁止心算排盘」——**纪律与能力冲突**（当前只能靠排两张单盘让模型自拼，偏离「唯一口径」原则）。

**B. 术数三角色空手（二期立项在案）**
`daliuren`（溯机）/ `qimen`（奇正）/ `qizheng`（步天）无排盘工具——协议「未工具化门类声明」v1 权宜之计；`scene-expansion-design.md §6` 已记「二期评估自研」。

**C. 既有盘面数据欠深（专家级语义缺口）**
- `bazi_pan`：无神煞、无柱间关系（合 / 冲 / 刑 / 害 / 会）、无流月、无小运——八字研判的三块核心证据缺位；
- `ziwei_pan`：无流年层（流年四化 / 流年命宫）——紫微推运最常用的手段未落盘（`iztro` 已内置 `horoscope()`，能力现成）；
- `gua_pan`：基线主体完整（六亲六神世应动变体用），但六爻专业断卦三块核心要素缺位——**伏神**（用神不上卦时的本宫伏神）、**月建日辰对爻关系**（月破 / 日破 / 暗动）、**动变回头生克**（变爻对动爻的回头生 / 回头克标注）。

**D. 前端交互留白（被数据锁死的部分 + 可独立增强的部分）**
- 行运叠加轮盘 / 合盘对照视图 / 时点扫描时间轴——依赖 A；
- 紫微流年层 / 八字神煞与柱间关系标注 / 流月展开——依赖 C；
- 六壬天地盘 / 奇门九宫盘 / 七政宫位盘——依赖 B；
- 独立可做：传统点缀视觉（印章 / 朱砂令牌）、合参泳道扩展、档案对照通用化。

## 2. 总体设计（五层深化）

```
┌ L5 资产层 agents/skills ── 协议工具纪律 · 11 角色 tools/职责 · 两技能手册 · eval 任务 · mock 剧本
├ L4 参与层 ── 时点关注（行运）· 流月补算 · 用神请教（奇门）· 合盘知情声明 · 档案对照通用化
├ L3 盘面层 ── 5 个新视图组件（TransitWheel / SynastryBoard / DaliurenBoard / QimenBoard / QizhengBoard）+ 既有 4 盘深化（bazi · ziwei · gua · natal）（§5；全部懒加载、回退表格、键盘可达）
├ L2 派生层 ── derive.ts 扩展 5 新 kind + 旧卡可选字段解析（必需门不依赖新增项，零回归）
└ L1 数据层 server/pan ── 8 件套：bazi v2 / ziwei v2 / gua v2 / transit / synastry / daliuren / qimen / qizheng
```

### 2.1 六条深化原则

1. **工具唯一口径，全域遵守**：凡盘面数据（含 cross-aspects、神煞、课传、局盘）必须出自工具；模型只做解读推演——本设计最核心的一条，直接响应 A 类缺口。
2. **追加不重写**：旧工具只做「参数触发式追加」（新字段行 / 新条目），旧调用行为等价；旧卡解析路径零改动（必需门不引用新增项）。
3. **口径是一门语言**：每个门类在卡面与工具输出中显式声明算法口径（月将法 / 拆补法 / 四余近似 / 相位 orb 阈值）；有争议处给参数预留（枚举加值即可，不破坏契约）。
4. **新盘 = 新 kind**：六壬 / 奇门 / 七政 / 行运 / 合盘一律新 kind，不挤进旧 kind（前端白名单 `PAN_KINDS` 未知即回退，天然兼容）。
5. **传统是点缀不是布景**：视觉深化只加「印记 / 朱砂 / 墨色 / 竖排标题块」四类令牌，全部可退化（quiet-mode 与 reduced-motion 下只剩结构）。
6. **参与即草稿**（延续 ADR 0064）：时点关注、流月补算、用神请教、合盘备注——一切参与产出落 Composer 草稿，用户确认后发送。

## 3. 工具详设（8 件套增强与新增）

新增/增强全部落入 `server/src/pan/` 计算层（纯函数，golden 直调）+ `server/src/tools/pan.ts` 工具层（deferred、只读、结构化错误）。

### 3.1 `bazi_pan` v2——神煞 · 柱间关系 · 流月 · 小运

**输入新增（全部可选，缺省行为与 v1 等价）**：

| 参数 | 说明 |
| --- | --- |
| `liuYueOf` | 流年标识（如 `2026`）——输出该年 12 流月条目（v1 缺省不输出） |

**输出追加（字段行 + 参数触发条目）**：

| 追加项 | 形式 | 口径 |
| --- | --- | --- |
| 神煞 | 字段行 `神煞：天乙贵人（日干）· 桃花（年支）· 驿马（日支）…` | v1 表 18 种（附录 A.1）；以年支 / 日干 / 月支起，逐柱标注 |
| 柱间关系 | 字段行 `柱间：天干 戊癸合（年时）｜ 地支 午未合（年时）、丑未冲（日时）…` | 干：五合 / 相冲；支：六合 / 三合 / 三会 / 半合 / 六冲 / 相刑 / 相害 / 相破（附录 A.1） |
| 小运 | 字段行 `小运：戊申（37）｜ 己酉（38）｜ …（当前大运 10 步）` | `lunar-typescript` `DaYun.getXiaoYun()`（与既有 Yun 同源，零新依赖） |
| 流月 | `liuYueOf` 触发：12 条条目 `- 流月 丙寅 \| 正月 ｜ 立春后 …` | `lunar-typescript` `LiuYue`（节气分月，随流年干支） |

**纪律**：神煞与柱间关系均附带「起法标注」（在字段值内以括号注明所依据的柱 / 干），保证「可指认盘面依据」协议条款；不确定的口径（如晚子时换日规则）沿用既有 `sect` 缺省并标注。

### 3.2 `ziwei_pan` v2——流年层

**输入新增**：

| 参数 | 说明 |
| --- | --- |
| `horoscopeYear` | 公历年份（如 `2026`）——输出该流年层（缺省不输出，v1 等价） |

**输出追加**：

| 追加项 | 形式 | 口径 |
| --- | --- | --- |
| 流年 | 字段行 `流年：2026 丙午 ｜ 流年命宫 官禄 ｜ 流年四化 禄 天同 ｜ 权 天机 ｜ 科 文昌 ｜ 忌 廉贞` | `iztro` `astrolabe.horoscope(date)`（`yearly` 域；与生年四化 / 大限同库同源）；流年十二宫**不在卡内**——由「流年命宫」单一数据在前端逆布推得（固定宫序），零冗余 |

**前端派生口径（写死进 derive 规格）**：流年十二宫 = 自流年命宫起，按「命 / 兄 / 夫 / 子 / 财 / 疾 / 迁 / 仆 / 官 / 田 / 福 / 父」逆时针落本命十二宫。此映射为固定规则，不属盘面数据（无需工具），实现于 `derive.ts`。

### 3.3 `transit_pan`（新增）——行运盘与相位时点扫描

**定位**：星移（transit）唯一口径；行运行星 + 行运对本命的 cross-aspects + 精确时点扫描。

**输入**：

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `birth` / `timezone` / `latitude` / `longitude` | ✅ | 本命数据（时区必填，同 `natal_pan`） |
| `at` | ✅ | 行运时刻 `YYYY-MM-DD HH:mm`（当地钟表时间） |
| `scanFrom` / `scanTo` | ○ | 扫描窗口（如 `2026-01` ~ `2026-12`）——给出即输出时点扫描 |
| `houseSystem` | ○ | 本命宫位制（默认 placidus，高纬降级 equal 告警） |

**输出**：

| 区块 | 形式 | 口径 |
| --- | --- | --- |
| 行运行星 | 10 行 `- 行运土星 \| 双鱼 21.3°（351.30°）｜ 10 宫 ｜ 逆行` | 与本命行星同算法（astronomy-engine 同源） |
| Cross-aspects | 条目 `- 行运土星-本命月亮 \| 对分 0.8°` | 行运行星 → 本命 10 星 + 四轴（共 14 目标）；仅主相位（合 / 六合 / 刑 / 拱 / 对分），orb ≤ 6°（收紧于本命盘 8° 口径——行运关注精确触发）；按 orb 升序 |
| 时点扫描 | `scanFrom/To` 触发：条目 `- 行运土星-本命月亮 \| 对分 \| 精确 2026-11-05 14:20 ｜ 影响窗 ±2 周` | 步进扫描（1 天步长） + 二分细化到分钟；限「外行星（木 / 土 / 天 / 海 / 冥）× 本命星 / 四轴」+「内行星 × 本命四轴」两类标准行运重点（避免条目爆炸）；同相位进出窗口合并 |

**卡**：`::: pan transit 行运 2026-11-05`（详式见附录 B.1）。
**纪律**：扫描只输出**时点与窗口**（参考区间），不输出任何事件断言——表述归协议红线。

### 3.4 `synastry_pan`（新增）——合盘与组合盘

**定位**：合璧（synastry）唯一口径；双盘 cross-aspects + 组合盘中点盘。

**输入**：

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `a` / `b` | ✅ | 双方 `{ birth, timezone, latitude, longitude }`（各自完整四参；时区必填） |
| `mode` | ○ | `cross`（默认：交角矩阵）｜ `composite`（追加组合盘中点行星） |

**输出**：

| 区块 | 形式 | 口径 |

### A.5 六爻 v2（伏神 / 月日关系 / 回头生克）

- **伏神**：本宫首卦（八宫各一：乾为天、坎为水、艮为山、震为雷、巽为风、离为火、坤为地、兑为泽）的六亲配置即本宫六亲序列；缺失之亲伏于本宫对应爻位——输出伏神六亲 + 该爻位本宫干支（与飞神同爻位）；
- **月建 / 日辰**：占月干支（月建）、占日干支（日辰）——与既有「卦气」字段同源；
- **月破**：爻支与月建相冲（子午 / 丑未 / 寅申 / 卯酉 / 辰戌 / 巳亥）；
- **日破 / 暗动**：静爻与日辰相冲——旺相者标「暗动」、衰囚者标「日破」；
- **旺相休囚**：按月建五行四时档位（当令者旺、令生者相、生令者休、克令者囚、令克者死）——输出简档（旺 / 相 / 休 / 囚 / 死）；
- **回头生克**：变爻五行对动爻五行——生我为「回头生」、克我为「回头克」、我生为「回头泄」（泄只标注不输出吉凶）。

### A.6 transit / synastry 相位常量

- 相位定义与 orb 阈值与 `natal.ts` 同源（合 0° / 六合 60° / 刑 90° / 拱 120° / 对分 180°）；
- transit cross-aspects：默认 orb ≤ 6°（行运收紧）；扫描相位集：外行星（木土天海冥）×本命十星 + 四轴、内行星（日月水金火）×本命四轴；步长 1 天、二分细化至分钟（收敛容差 0.01°）；
- synastry cross-aspects：默认 orb ≤ 8°；对称去重（键 = 双方星排序对）；组合盘 = 各对黄经短弧中点（跨 0° 取模）。
