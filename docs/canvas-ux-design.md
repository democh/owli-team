# 画布交互与效果深化——对标专业无限画布（M31 修订设计）

> **状态**：已实施（2026-09-19）——A 能力门控 ✅ · B 专业手感 ✅（滚轮平移 / ⌘滚轮缩放 / H·V 工具 / 缩放指示器 / 快捷键）· C 效果与反馈 ✅（拖拽抬升 / 框选样式 / 关联边高亮 / 光标）· D 网格吸附 ✅
> **关联**：M31 画布内核（design.md §49 / ADR 0059）· ADR 0093（点击/拖动/选中交互修订）· M36 画布输入平权（§51 / ADR 0061）· M56 媒体连接全局化（§76 / ADR 0124）
> **修订**：v1 初稿（2026-09-19）· v2 收口（同日）：按实际实施回写验收信号

## 1. 背景与目标

M31 画布已具备完整的编辑内核（框选 / 多选拖动 / 连线 / 剪贴板 / 撤销重做 / 对齐吸附 / 脑图 / 媒体生成），
但当用户带着 Figma / Miro / tldraw / Excalidraw 的手感进入时，仍有三个层级的落差：

1. **能力门控缺失**——未配置媒体生成连接时，「媒体生成」按钮、右键「生成变体 / 设为首尾帧」、
   空画布「创作台 / 分镜台」模板、图片 / 视频节点空态文案仍然展示生成话术，用户点了才被引导去设置；
2. **导航手感非专业范式**——滚轮=缩放（而非主流画布的滚轮=平移、⌘滚轮=缩放）；
   缺少手型工具（H）、缩放百分比指示器与「缩放到选区」；缺网格吸附；
3. **反馈层次薄**——拖拽中的节点无抬升、框选框未主题化、选中节点与相连边无联动高亮、
   平移时无光标状态变化。

目标：**未配置的能力不出现；已配置的能力手感对标专业无限画布**。零新增依赖、零服务端变更、
零画布文档契约变更（不新增持久化字段）。

## 3. A · 能力门控（未配置即不出现）

### 3.1 原则

- **配置面常驻、消费面门控**：设置页「媒体生成」分组始终可见（配置入口）；画布是消费面——
  providers 为空（或尚未加载完成）时，一切**生成语义**的入口、模板与话术全部不渲染；
- **粒度按能力拆分**：`canImage`（text2image / image2image）与 `canVideo`（text2video / image2video /
  firstlast2video）分别判定，只配置生图时视频相关入口同样不出现；
- **加载完成前宁可晚出现**：`providersLoaded=false` 时按「无能力」渲染，杜绝门控元素闪现。

### 3.2 判定源与同步

- `media-store` 增加 `providersLoaded` 标记与 `ensureProviders()`（幂等；进行中去重）；
- `CanvasView` 挂载即 `ensureProviders()`——进入画布自动获取全局可用能力（不依赖打开生成面板）；
- 「设置 → 媒体生成」保存 / 启停 / 删除后调用 `refreshProviders()`，回到画布即生效；
- 派生 hook `useMediaCapabilities()` 返回 `{ providers, providersLoaded, canGenerate, canImage, canVideo }`。

### 3.3 门控矩阵（修订后）

| 界面面 | 条件 | 未满足时 |
| --- | --- | --- |
| 工具栏「媒体生成」按钮 | `canGenerate` | 隐藏（整钮不渲染） |
| 节点右键「用作生成输入 / 生成变体」 | `canImage` | 隐藏 |
| 节点右键「设为首帧 / 设为尾帧（视频）」 | `canVideo` | 隐藏（四项全隐时整段与分隔线不渲染） |
| 空画布模板「创作台 studio」 | `canImage` | 隐藏 |
| 空画布模板「分镜台 storyboard」 | `canVideo` | 隐藏 |
| 空画布模板「素材墙 wall / 脑图工坊 mind」 | 恒显 | —（素材墙不依赖生成：拖入 / 交付件引用） |
| 创建菜单「提示词节点」hint | `canGenerate` | 文案降级「记录可复用的指令」 |
| 图片节点空态文案 | `canImage` | 「拖入图片，或从交付件送上画布」 |
| 视频节点空态文案 | `canVideo` | 「拖入视频，或从交付件送上画布」 |
| 生成面板（打开后） | — | 面板不可达（按钮已隐藏）；空 provider 引导保留兜底 |
| Agent 工具 media_generate / media_video | — | 服务端既有最小权限引导不变 |

## 4. B · 专业手感（导航与工具）

### 4.1 平移（Pan）

- **滚轮 / 触摸板双指 = 平移**（`panOnScroll`，speed 0.8），与 Figma / tldraw / Excalidraw 一致；
- **⌘（macOS）/ Ctrl（其余平台）+ 滚轮 = 缩放**（`zoomActivationKeyCode` 平台默认）；
- **双指捏合 = 缩放**（zoomOnPinch 保持）；
- **中键拖拽 = 平移**（select 模式保留 `panOnDrag=[1]`）；
- **Space 按住 = 临时平移**（保持）；按住期间 pane 光标 `grab`，拖动中 `grabbing`；
- 节点内 `nowheel` 区域（K 线图表等）不受影响——手势仍归节点自身。

### 4.2 工具模式（H / V）

- `H` → 手型：`panOnDrag=true`（左键拖拽平移）、框选关闭、pane 光标 `grab`；
- `V` / `Escape` → 选择：左键拖拽框选（保持现状）、中键平移；
- 工具栏新增手型切换钮（`active` 随模式）；模式为**会话内瞬时态**，不持久化（同 Miro 回默认选择工具）；
- 双键仅在无输入控件聚焦时生效（与既有画布键盘纪律一致）。

### 4.3 缩放指示器（右下角）

- pill 常驻显示当前缩放百分比（`useViewport` 实时）；
- 「− / +」按钮步进缩放（zoomOut / zoomIn）；
- 点击百分比展开菜单：**缩放到 100%** / **适应视野** / **缩放到选区**（无选区时禁用）；
- 窄屏（<768px）隐藏（让位底部指令条；缩放仍可滚轮 / 捏合 / Controls）。

### 4.4 快捷键（画布内，输入控件聚焦时不拦截）

| 键 | 行为 |
| --- | --- |
| ⇧0 | 缩放到 100%（zoomTo(1)，保持视口中心） |
| ⇧1 | 适应视野（全部节点，FIT_MAX_ZOOM=1 口径） |
| ⇧2 | 缩放到选区（选中节点填充视口） |
| H / V | 手型 / 选择工具 |
| Space（按住） | 临时平移 |
| Esc | 手型 → 选择；关闭浮层（既有） |

采用 Figma 范式 ⇧0 / ⇧1 / ⇧2（**不采用 ⌘0 / ⌘1**：浏览器保留键不可拦截，与项目「Alt+1..9 切换会话」同一避让纪律）；
按 `e.code`（Digit0/1/2）判定不受 ⇧ 符号映射影响；检查 `e.repeat` 防长按连发。
缩放 / 适应 / 选区三动作全部走 300ms 平滑过渡（`duration`），与「适应视野」按钮口径一致。

### 4.5 网格吸附（10px）

- 「整理与对齐」下拉新增「对齐网格」开关：开启后拖动位置取整到 10px 网格（React Flow `snapToGrid`）；
- 开启时智能对齐参考线让位（两者互斥），关闭时回到智能参考线（默认）；
- 不落画布文档、不落设置——会话内工具态。

## 5. C · 效果与反馈

### 5.1 选中与关联

- **关联边高亮**：选中节点时，与之相连的边增强（主色实线加粗 / 虚线边提亮 + 透明度提升），
  一眼看清「选中对象接在什么链路上」；实现走受控边 data.related 标记（视图层派生，不落文档）；
- 悬停节点保持既有边框反馈（hover:border）。

### 5.2 拖拽

- 拖拽中的节点抬升：`.react-flow__node.dragging` 下节点外壳投影加深 + 轻微放大（1.01），
  松手回弹（纯 CSS 过渡，120ms）；
- 拖动结束的位置回写、对齐参考线、画框收纳逻辑不变（ADR 0093 纪律保持）。

### 5.3 框选与光标

- 框选框主题化：主色半透明填充 + 1px 主色描边（替换默认蓝色）；
- 光标反馈：手型 / Space 时 `grab`，平移中 `grabbing`；框选 `crosshair` 由浏览器默认行为保持；
- Controls（左下）主题化：圆角 / 卡片底 / 阴影 / hover 与全局视觉语言一致。

### 5.4 动效纪律

- 新增动效全部为过渡（transition）或复用既有 `canvas-node-pop`；
- 持续动画类（如未来新增）必须同步加入 `.quiet-mode` 禁用清单（本批无新增 keyframes）。

## 6. D · 被否决与延后

| 项 | 决策 | 理由 |
| --- | --- | --- |
| 小地图恢复 | ✗ | M36 已移除（画布即全景）；ADR 61 决策不复议 |
| 滚轮缩放（Miro 式） | ✗ | 触摸板时代 Figma / tldraw / Excalidraw 范式更主流；⌘滚轮缩放保留鼠标用户习惯 |
| ⌥ 拖拽复制（Figma） | 延后 | React Flow v12 需在拖拽生命周期中接管 altKey，与受控回写叠加风险高，收益中等 |
| onlyRenderVisibleElements | 延后 | 当前画布节点量级（<100）收益小、受控重建 + 视口裁剪存在 measured 抖动风险（ADR 93 纪律）；大画布档位预留 |
| 导出 PNG | ✗ | 需新增依赖（html-to-image），违零新增依赖纪律 |
| 多选包围盒整体缩放 | ✗ | 节点尺寸语义独立（非设计稿缩放语义）；对齐 / 分布 / 网格整理已覆盖布局诉求 |
| 橡皮筋二次连线 / 重连（reconnect） | 延后 | 连线矩阵与去重在上游守卫，重连属编辑内核扩展，另立批次 |
