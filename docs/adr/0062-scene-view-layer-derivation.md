# ADR 0062：场景差异化限定于视图层派生（Scene Differentiation as View-Layer Derivation）

- 状态：Accepted
- 引入：M37
- 相关：[design.md §52](../design.md)、ADR 9（流式纪律）、ADR 25（前端性能架构：byId+order / 虚拟列表 / 节流）、ADR 28（agents/ 包化与场景分组）、ADR 31（场景协议分层与技能包绑定）、ADR 63（场景资产扩展走 _group.yaml）、ADR 64（交互卡片回填语义）、ADR 65（波次分隔与定位）

## 背景

- 17 个场景组在对话区几乎同构：差异只有空态文案（3 条内置）、主题色、并行组；场景协议（发散/收敛、事实/推断/观点、止血/复盘）在对话区没有任何承接；
- 用户诉求：场景可辨识、有交互、有仪式感（对应验收表「场景可辨识 / 有交互 / 有仪式感 / 零回归」）；
- 硬约束：
  1. **线性主干不变**：一切场景化体验不得为视觉分叉消息数据层（可回放 / 可追溯 / 可导出建立在消息序列上）；
  2. **流式纪律（ADR 9）**：新增卡片流式期间降级纯文本，完成态才挂载重组件；
  3. **结构键契约**：虚拟行派生（`deriveRows`）只依赖 `role~runId~turnIndex` 结构键——任何依赖内容的聚合不得做成独立虚拟行；
  4. **可静默降级**：无标记 / 解析失败一律回退原文，不报错、不空白。

## 决策

1. **场景体验 = 视图层派生**：全部场景增强（空态议程 / 波次分隔 / 交互容器 / 收尾卡 / 导航条）纯前端从既有消息字段（role / runId / turnIndex / mentions / toolCalls / artifacts）与资产（`_group.yaml`）派生；**不引入结构化消息 payload、不动消息协议、不落新库表**；
2. **内容聚合的落点纪律**：跨消息聚合（后续里程碑的点子池 / 证据链 / 决议时间线）只挂波次组完成态，不做独立虚拟行；
3. **本地互动态**：交互状态（勾选 / 点选 / 点亮）存 sessionStorage（`ma:*` 键），不落库、不进导出；
4. **协议的承接方式**：Agent 语汇以自描述 `:::` 容器输出（fail-safe / 可回放 / 与流式纪律天然兼容），渲染侧按容器名路由——协议增补是渲染契约的配套，而不是数据层改造；
5. **统一回填语义**：一切交互输出只写 Composer 草稿（composerInsert），由用户确认发送（ADR 64）。

## 理由

- **消息序列是唯一事实源**：Run 恢复 / fork / 压缩 / 导出 / 回放均建立在消息序列上；为视觉分叉数据层会级联破坏这些语义，收益（渲染便利）与风险不对称；
- **既有先例充分**：WaveGroup 分组、协作图谱、战力榜均为纯派生（零后端改动）——本专项延续同一路线，M37 全部交付物零后端改动（mock 仅新增测试触发分支）；
- **结构键契约保护性能**：虚拟列表只按结构键重派生，流式 delta 不触发行结构变化（ADR 25 的 byId+order 订阅模型）；
- **容器语法可回放**：`:::` 容器是消息文本的一部分（原文可导出 / 可回溯），接受「模型不输出容器 → 静默降级原文」的代价换取零协议破坏。

## 被否决的方案

- **结构化消息 payload（新增 message.kind / cards 字段）**：级联改动持久化 / SSE / 导出 / fork / 压缩全链路，且把「渲染选择」固化为「数据事实」——收益不抵成本；未来若互动统计需要持久化（M45 条件性）再单独评估；
- **正文正则聚合（从自然语言中解析编号 / 表格）**：脆弱且不可回放；容器语法（自描述）为其超集；
- **独立虚拟行承载内容聚合**：击穿结构键契约（虚拟行数随内容变化 → 重派生风暴，见风险登记）；
- **每个场景独立消息组件树**：17 场景 × 渲染分支的维护成本不可接受；容器 / 派生层共享，场景差异经资产与路由表达。

## 适用与失效条件

- 适用：本地单用户部署；场景增强以「渲染语汇」为主（不做协作协议本体扩展）；
- 失效条件：
  - **互动统计落库**（跨会话聚合 / 审计）：本地互动态边界失效，需评估 `interactions` 表（M45 条件性，触发后再立 ADR）；
  - **消息 payload 化重构**：若未来导出 / 回放需要承载交互结果（勾选态随导出走），则「交互态不进导出」的边界需重新裁决；
  - **多端同步**（手机 / 桌面同会话）：sessionStorage 本地态需要改为服务端 / 账号级存储。
