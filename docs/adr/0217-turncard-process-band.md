# ADR 0217：过程叙述通道与 TurnCard 过程区（::: process）

- 状态：已采纳（2026-09-23）
- 相关：`docs/turn-card-process-design.md`（详细设计）· M19 Markdown 扩展（ADR 0034）· `agents/_protocol.md` 四通道契约 · check:agents 三段协议门禁 · E2E `m81-turncard-process`

## 背景

用户实测「Agent 对话太啰嗦」（陪谈类场景截图）：content 通道混装「对用户的话」与**过程叙述**（动作预告 / 记录与检索说明 / 进度自述 / 方法论旁白），而既有折叠机制只覆盖 reasoning（ReasoningBlock）与 toolCalls（ToolCallsPanel）——过程文本只能逐段铺开。关键约束：这些段落**不是** reasoning 通道内容（折叠不到），且渲染端无法在不误伤陪谈复述等核心内容的前提下做启发式识别；陪谈类声纹「开口先复述」进一步放大多轮重复。

## 决策

1. **语义容器 `::: process`**：新增专用容器（与 `::: details` 分工：details = 通用展开，process = 过程叙述），走既有 remark 容器管线（**单一解析实现**）；fail-safe 三则——未闭合内容展开回正文 / 代码块内不解析 / 空块不渲染。
2. **顶层上提**：解析收尾把顶层 `mdProcess` 按原序上提到消息头部（嵌套块就地渲染），与思考、工具组成固定序「过程区」；正文成为唯一主角。
3. **折叠范式统一**：流式展开跟随 / 回合结束折叠一次 / 用户手动切换后不再干预（与 ReasoningBlock、ToolCallsPanel 同构）；完成态默认收起为一行「过程 · N 字」（字数由 remark 侧 data-chars 预算，缓存安全）。
4. **两侧位置调整**：工具调用面板移至正文之前（并入过程区）；评审判定卡移至正文之后（结论件归位，抬头评审徽章语义不丢）。
5. **源头降噪（全量 40 场景 / 161 角色）**：`_protocol.md` 三通道 → **四通道**（过程叙述收进容器、≤3 句、放发言末尾、容器内不写 @；复述确认仅对新增信息、同一事实不重复；安全合规提示与交付落盘声明禁止折叠）；40 份场景协议统一铺设「## 过程叙述约定（界面承接）」段（**A/B/C 三型**——A 型 32 场景标准段；B 型 4 场景加方法性复述豁免：philosophy / metaphysics / moot-court / brainstorm；C 型 4 场景加复述去重 + 危机红线置顶：wellness-mind / personal / care / relationship）；tarot 条目 11 对齐 `::: process`；角色级 **3 改 1 免**（emotion-companion / coach / rel-coach 实改；socratic-host 场景豁免，机制先例）。
6. **门禁防漂移**：check:agents `PROTOCOL_SECTIONS` 增第三段「## 过程叙述约定」；CI 常驻 `QUALITY_STRICT=1`，门禁与 40 份铺设**同批落地**；此后新增场景协议自动强制。

## 被否决的备选

- **前端启发式识别叙述段（句式 / 段落特征自动折叠）**：误伤陪谈场景核心复述内容，规则脆弱不可控；
- **独立消息字段（message.process）**：需服务端对同一条流做增量拆分流，schema / WS / 迁移成本大，收益等同容器方案；
- **字符串级二次扫描器（提取段落到底部聚合）**：违背单一解析实现，与 mdast 语义漂移；
- **单行聚合「过程 · 思考/工具/过程」总行**：破坏既有文案（「已深度思考 · N 字」「工具调用 · N」）与断言，可辨性下降；
- **复用 `::: details` 作过程语义**：无字数统计 / 无流式跟随 / 语义混用（保留为模型误用时的可接受降级）；
- **过程内容彻底不渲染（仅入库）**：信息不可回溯。

## 后果

- 完成态消息默认收敛为「过程区（一行行摘要，可展开）+ 正文」；陪谈类复述去重从源头减少重复；危机与合规提示仍强制正文置顶（红线入协议）；
- 协议 token 增量约 +300 token / 角色 / 回合（位于稳定前缀，prompt cache 命中）；context 预算夹具随资产扩容 16k → 17k（实测 16.3k±，夹具注释内登记）；
- 后续（v2 候选）：过程占比内容级 eval 断言、技能库「长内容折叠」语义核对、其余场景按需追加 pointed 约定。
