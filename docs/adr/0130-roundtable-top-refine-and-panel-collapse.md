# ADR 0130：roundtable 顶区重设计与汇聚板收起——俯视圆桌 · 横向步骤条 · 折叠 / 关闭

- 状态：Accepted
- 引入：M59
- 相关：[design.md §82](../design.md)、ADR 0128（席位环几何修正与议程清单化——本 ADR 修订其议程形态与环面部分）、ADR 0112（场景工作区体系）、ADR 0127（就绪判定与标题合行——收起口径复用）、[client/src/components/scene/RoundtableStage.tsx](../../client/src/components/scene/RoundtableStage.tsx)、[client/src/components/scene/parts/SeatRing.tsx](../../client/src/components/scene/parts/SeatRing.tsx)、[client/src/components/scene/parts/AgendaTrack.tsx](../../client/src/components/scene/parts/AgendaTrack.tsx)、[client/src/components/scene/persist.ts](../../client/src/components/scene/persist.ts)、[client/src/index.css](../../client/src/index.css)

## 背景

- 用户实测截图反馈（三处红框：顶区席位环 + 议程清单 / 含状态字区域 / 议程列表特写）——roundtable 顶区「太丑了，专业的角度设计下」，明确否决 M52-H（ADR 0128 / v51）的纵向议程清单（「不要用这个列表」）；并质疑空面板（「还有空的面板？可以展示和收起」）；
- 「空面板」经核为 M58（v50 / ADR 0127）前的版本形态：就绪判定已保证无数据不渲染（roundtable 无产物不渲染汇聚板）；同时确认 roundtable 汇聚板缺失收起能力（折叠 / 关闭此前仅 dock 具备）——本批补全；
- 浏览器实测甄别两项实现缺陷：
  - ① `nameDir` 方位整体偏 90°——落位公式 `rotate(θ) translateY(−R)` 使 θ=−90 落位在正左（而非正上），页面方位角实为 `θ − 90°`；
  - ② 连线被标签空白切断呈「短划线」——step 宽由标签撑开（> 节点间距），间隙段未与节点半线拼接。
- 同日二轮反馈（原话「居中是不是更好，然后现在不能收起展开」）续修订：顶区内容组整体居中；顶区补收起 / 展开（经实测汇聚板折叠 / 展开 / 关闭 / 恢复全链正常，判定为顶区缺收起能力）。

## 决策

1. **顶区卡片带化**：`.scene-rt-top` 由透明条带改浅灰圆角卡片带（`hsl(var(--muted) / 0.4)` + `border-radius 0.8rem` + 外留白 + `align-items: center`）——席位环与议程步骤条同行居中，内容由卡片边界收束、与消息流分层；窄屏（column）沿用降级。
2. **席位环俯视圆桌化（SeatRing v3，重写）**：头像 `26px` / 环半径 `40px` / 实心桌面 `56px`（inset 描边）；名字**径向朝外四向锚定**（`data-dir = up / right / down / left`，按落位角就近取；CSS 属性选择器定位，**无底色**）——消除名字与桌面、头像的交叉及「贴纸」感；发言席主色描边 + 外光环；席位盒 = 头像盒口径延续（M52-H）；`nameDir` 按页面方位角（`θ − 90°`）归一取向。
3. **议程横向步骤条（AgendaTrack v3）**：纵向清单（v51 形态）整体替换——节点三态（done 实心 / doing 实心 + 光环 / todo 空心描边）+ 连线（随前步着色）+ 标签；**状态字删除**（语义由节点 / 标签 / 连线着色承担）；摘要贴卡片带右端（`margin-left: auto` + 省略），不再逐行重复、不再铺满余宽；连线 = 节点两侧半线 + 相邻步骤间隙段 `.scene-ag-link` 拼接（连续轨道；done 段三段同色）。
4. **汇聚板折叠 / 关闭 / 恢复**：口径同 dock（ADR 0127）——chrome 注入标题行（折叠 ChevronRight / 关闭 X；窄屏抽屉不注入）；折叠 → 34px rail（展开钮 + 竖标「汇聚板」）；关闭 → 浮动恢复胶囊（`.scene-rt-reopen`）；偏好 `ma:sc:rt`（`RtPref {collapsed, closed}`）localStorage 全局记忆（与 `ma:sc:dock` 同族）。
5. **顶区居中与收起（续修订）**：① 顶区内容组整体居中——`justify-content: center`；议程 `flex: 1 → 0 1 auto`（不撑满）、摘要 `margin-left: auto → 0` 跟随步骤条构成连续居中组；窄屏保持原排布（flex-start + agenda `flex: 1` + heading `margin-left: auto`）；② 摘要让位优先级 `flex-shrink: 99` + 步骤条轨道 `overflow: hidden` 兜底——修复中等宽度（1280）「摘要与末步标签重叠」（轨道被压缩后固定宽 step 溢出绘制所致）；③ 顶区收起 / 展开——展开态右上角悬浮收起钮（ChevronUp）→ 单行迷你条（小头像堆叠 + 摘要 + 展开钮；席位环 / 席位条与议程卸载、摘要保留）；`RtPref.topMini` 落 `ma:sc:rt`（旧值向后兼容）；窄屏迷你条保持单行；reduced-motion 登记 `.scene-rt-top-toggle`。

## 理由

- **卡片带收束**：顶区与消息流视觉分层（一条内容带而非全宽空排布），宽屏不再留白失衡；
- **名字径向朝外 + 无底色**：名字恒在头像外侧、与桌面零交叉；底色（「贴纸感」来源）删除后俯视圆桌隐喻完整；四向锚定与角度解耦——任意人数 / 任意角度均取最近正向（纯 CSS 属性选择器，零 JS 布局分支），名字宽度受四向 `max-width` 约束（省略保护）；
- **横向 stepper**：议程推进在顶区承担「进度表达」——节点 / 连线 / 着色三位一体，信息密度高于逐行清单（删除重复状态字）；与席位环同行后顶区仍紧凑；
- **半线拼接连线**：连线在标签空白区仍连续（轨道观感），不依赖 step 等宽或固定节点间距（标签保持自适应宽度）；
- **收起口径同 dock**：用户在一处学会的收起交互可迁移（rail / 胶囊形态一致）；localStorage 全局记忆与 `ma:sc:dock` 同族；
- **顶区居中**：内容组（环 + 步骤条 + 摘要）连续居中、两侧留白对称（实测 1600 留白 72 = 72 / 1280 16 = 16）——卡片带内不再左密集右空旷；
- **顶区可收起**：顶区承载席位环 + 议程（环容器 176 × 138 + 卡片内衬），长会话让位消息流的诉求明确（用户二轮反馈）；迷你条保留头像堆叠（识别）与摘要（进度）——收起不丢上下文、恢复入口常驻（口径同 dock rail）。

## 被否决的方案

- **保留纵向议程清单（v51 形态）**：用户明确否决（「不要用这个列表」）；
- **名字保留底色**（M52-H 防跨背景不可读方案）：径向朝外后名字恒在卡片带背景上（无跨桌面场景），底色即「贴纸感」来源，直接删除；
- **名字按角度两向锚定（仅上下 / 仅左右）**：四向锚定覆盖所有落位角且实现为纯 CSS 属性选择器（无 JS 布局分支）；
- **连线等宽化（step 定宽 + 标签截断）**：定宽截断伤害标签可读性；半线拼接保持标签自适应宽度；
- **汇聚板沿用无收起（仅依赖就绪判定）**：有数据后宽屏用户可能希望让位给消息流（用户诉求「可以展示和收起」），收起能力独立于就绪判定；
- **折叠 / 关闭偏好入服务端**：纯前端视觉偏好，localStorage 足矣（口径同 dock）；
- **顶区收起后完全隐藏**：识别性与恢复入口丢失（迷你条保留头像堆叠 + 摘要 + 展开钮）；
- **摘要刚性占位（不收缩）**：中等宽度（1280）与末步标签重叠（改 `flex-shrink: 99` 让位优先 + 轨道 `overflow: hidden` 兜底）；
- **居中时议程仍撑满余宽**：摘要贴右端使内容组不连续（居中组断裂），改 `flex: 0 1 auto` 跟随步骤条。

## 适用与失效条件

- 适用：roundtable 形态顶区与汇聚板（society / brainstorm / research / strategy 四场景）；AgendaTrack 元件当前唯一使用方为 roundtable 顶区（dock 顶区未启用该元件）；
- 失效条件：① 席位数量 > 8 时环半径 / 头像 / 名字四向参数需重估（名字互相挤压）；② 议程步骤数过多（> 6）时横向步骤条需换行 / 横向滚动策略（当前单行省略）；
- 已知边界：窄屏（SeatStrip + 抽屉）不注入 chrome（抽屉自带收起）；`ma:sc:rt` 与 `ma:sc:dock` 独立记忆（不同形态偏好互不串扰）；顶区收起（`topMini`）与汇聚板折叠 / 关闭（`collapsed` / `closed`）相互独立（可任意组合；窄屏迷你条同样可用、保持单行）。
