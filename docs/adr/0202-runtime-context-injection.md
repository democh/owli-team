# ADR 0202：运行时上下文注入——时间 / 系统两级注入（全角色）

- 状态：Accepted
- 引入：运行时上下文批（2026-09-20）
- 相关：[server/src/context/assembler.ts](../../server/src/context/assembler.ts)、[server/src/context/service.ts](../../server/src/context/service.ts)、ADR 0019

## 背景

- agent 对「现在」零感知：system 提示不含日期 / 时区 / 运行环境；`date_calc` 虽支持「今天」缺省，但 agent 不知道今天是几号——「今天 / 本周」相对日期、时效性判断（价格 / 政策 / 新闻 / 版本）与排期核对缺统一依据；
- 各场景角色（排期 / 日报 / 命理排盘 / 行情时效 / 定时任务）对当前时间有共性依赖，宜平台级统一注入而非逐角色改资产（164+ 资产维护成本）。

## 决策

1. **两级注入**（护前缀缓存）：日期 / 星期 / 时区 / 运行环境进 system L3 尾段 `<runtime_context>`——**天级稳定**（同一天内字节级一致，既有 prompt cache 承诺不破坏）；精确时刻（HH:mm）进**回合指令**（每回合天然新建的最后一条 user 消息），分钟级变化零额外缓存损失；
2. **全角色 / 全场景通用**：注入在 `buildSystemPrompt` / `buildTurnInstruction` 装配必经路径实现，AGENT.md / 协议资产零改动；
3. **内容口径**：`当前日期：YYYY-MM-DD（周X）；时区：IANA 名（UTC±N）`、`运行环境：macOS / Windows / Linux（arch）`，并附纪律句（相对日期一律以此为准、时效信息不凭训练记忆臆断）；`now` 可注入（缺省当前时刻，单测固定断言）；
4. **展示口径**：runtime 计入 L3（上下文抽屉 label 更新为「技能 / 工作区 / 运行时」）。

## 理由

- 拆两级而非全部进 system：时刻分钟级变化若进 system，会让「system + 历史窗口」整段前缀缓存每回合失效（长会话成本显著上升）；回合指令位于窗口尾部、每回合重写，是时刻信息的零成本载体；
- 放 L3 尾段而非 L0：L0 契约是「会话内字节级稳定」，日期日更会破坏其语义；L3 为半静态层，尾段是 system 内最靠后的变化点（跨天仅尾段缓存块失效）。

## 被否决的方案

- **时刻也进 system**：分钟级抖动击穿前缀缓存，每回合全量 miss；
- **日期进 L0**：违反 L0「会话内稳定」的显式契约（ADR 0019）；
- **逐角色资产手写时间**：静态文本不随会话时间流动，且 164+ 资产维护成本；
- **仅靠 date_calc 工具披露**：信息藏在工具结果里，未调用工具时模型仍不知「今天是几号」。

## 影响

- system token +约 70（L3）；回合指令 +约 20 token；
- 跨天时 system 仅尾段变化一次；同一天内多回合 system 完全一致；
- 单测 `server/tests/runtime-context.test.ts` 8 例守护（含「同日不同时刻字节级一致」的缓存友好性断言与跨角色集成）；
