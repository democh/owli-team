# ADR 0172：打卡与 streak 本地口径——按天记录 · 本地日期切算 · 仅本地可信（HL-1）

- 状态：Accepted
- 引入：M40 陪跑渲染包（2026-09-19）
- 相关：[design.md §104](../design.md)、[docs/scene-chat-design.md §8](../scene-chat-design.md)（M40 原案；决策项「打卡 / streak 本地持久化」落位）、ADR 0068（本地互动态存储先说）、ADR 0173（陪跑容器族）、[client/src/lib/habit.ts](../../client/src/lib/habit.ts)、[client/src/components/chat/md-ext/TracksCard.tsx](../../client/src/components/chat/md-ext/TracksCard.tsx)

## 背景

- M40 原案 HL-1 三轨打卡卡：三轨勾选 + 周进度环 + streak 徽章；决策项：「打卡 / streak 本地持久化口径——localStorage 按天记录；跨天本地日期切算 streak；会话删除清理；不进导出；仅本地可信」（对照被否决：落库 / 跨设备同步）；
- 现有打卡先例：coach 面板 `CheckGrid` 为 sessionStorage「会话内勾选」（M37-4 / ADR 0068）——**按次勾选、关闭标签即清**，不满足「跨天 streak / 周网格」语义；
- 打卡是**跨天时间序列**（连续性即意义），时间序列必须持久——这是与「会话内勾选」的本质差异。

## 决策

1. **存储**：localStorage `ma:habit:<sessionId>` —— `{ [轨道]: ['YYYY-MM-DD', …] }`（按天日期集合；空集合清键；读写容错：非法 JSON / 非日期项过滤，隐私模式静默忽略）。
2. **日期口径**：一律**本地日期**（`localDateOf` 不依赖 UTC）；`shiftDate` / `weekDatesOf`（周一锚定的 7 日窗口）为纯函数；跨天无需任何「切算任务」——读取时按当天动态计算。
3. **streak 语义**：从今天往前数连续天数；**今天未打卡则从昨天起算**（当天尚未到「晚上」不视为断签）——标准习惯口径；断签（昨天与今天都未打卡）归零。
4. **交互**：周网格任意日格可点（**今日突出 + 可补记历史**）；切换即落盘（不可变更新）；流式期间禁点。
5. **边界（不进导出 / 不落库 / 仅本地）**：打卡与 streak 为个人本地记录（不随会话导出、不作协作事实）；「三轨」轨道名由容器内容决定（训练 / 饮食 / 睡眠为主，未命中不加色标）。

## 理由

- **localStorage 而非 sessionStorage**：打卡价值在跨天连续（streak / 周网格）——sessionStorage 关标签即清、无法承载时间序列；
- **按天集合而非计数器**：集合可支持「补记 / 取消任意一天」，计数器（+1/-1）无法表达幂等修正；
- **今天未打卡不断签（从昨天起算）**：习惯类产品通行口径——早上的用户不应看到「连续 0 天」的挫败感；
- **本地日期而非 UTC**：跨时区 / 跨午夜场景下，用户认知的「今天」是本机日期——UTC 会导致晚间打卡计入「明天」。

## 被否决的方案

- **落库（服务端打卡表）**：本地记录的信任级足够（个人打卡非协作事实）；落库引出多设备合并 / 时区归属 / 隐私面；原案列表已否决；
- **复用 sessionStorage 勾选先例（CheckGrid）**：会话内勾选支持不了跨天 streak（语义不匹配，两套机制并存且各司其职）；
- **计数器式 streak（存「连续 N 天」字段）**：无法处理补记 / 取消后的重算——派生（从集合计算）永远一致；
- **把打卡态写进消息 / 容器**：改消息协议成本高且污染会话事实；本地视图态与消息内容分离（M37 视图层派生原则）。

## 边界与失效条件

- 键含 sessionId（会话隔离）；会话删除后残留键不构成数据泄漏（仅本地日期集合）；「会话删除清理」随浏览器存储策略（如需主动清理可在会话删除处扩展——本 ADR 不承诺）；
- `data-tracks-card / data-track / data-day-dot / data-streak` 为测试锚点；
- 若未来需要跨设备同步打卡（真实使用证明），按 ADR 0082 条件性路径另立（服务端表 + 合并策略），本地口径同时退役。
