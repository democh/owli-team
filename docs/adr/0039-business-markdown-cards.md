# ADR 0039：业务 Markdown 卡——kpi / timeline / mail / option 容器

- 状态：Accepted
- 引入：M21
- 相关：[design.md §33](../design.md)、ADR 34（Markdown 渲染扩展）、ADR 9（delta 渲染）、ADR 37（OPC 业务场景编制）

## 背景

业务角色的高频产出形态与研发文档不同：经营 / 增长指标快照（数值 + 涨跌 + 目标）、内容日历与发布排期（日期 + 事项 + 负责人）、客户跟进邮件草稿（头部字段 + 正文 + 可复制）、方案对比与决策纪要（推荐 / 备选 / 否决状态）。纯文本 Markdown 呈现这些内容可读性差，且「复制正文」「今天高亮」「涨跌着色」等真实使用动作无处附着。

既有约束：Markdown 管线已有容器体系（§30，自写 remark 插件 + fail-safe + 流式纪律）；零新增依赖（含前端渲染）；产物 ≤ 50 文件、主包 gzip ≤ 150KB。

## 决策

**在既有容器体系上新增 4 个业务容器，纯前端渲染、零后端改动**：

- `::: kpi [标题]`，条目 `- 名称 | 值 | 变化 | 目标`：数值卡组；涨跌色（+ 绿 / − 红，HSL 变量）；有目标时进度条；点击数值复制；hover 显示原始行；
- `::: timeline [标题]`，条目 `- 日期 | 事项 | 负责人`：竖向时间轴；日期 chip + 负责人 chip；「今天」高亮支持 `2026-07-01` / `07-01` / `7月1日` 三种形态（仅展示提示，不校验日期合法性）；
- `::: mail [主题]` + `收件人: / 抄送: / 主题:` 头部行 + 正文：邮件卡（字段块 + 正文）+「复制正文」按钮（复用 CopyButton，1.6s 状态复位）；
- `::: option [推荐|备选|否决|待定] 标题`：方案卡 + 状态徽标（绿 / 蓝 / 红 / 灰）；状态词未命中白名单时降级为中性标题卡（标题为整段参数）。

实现路径与既有容器同构：

- `remark-ext.ts` 新增 4 个 builder + finalize 结构化转换：kpi / timeline 的列表项按 `|` 拆为 `data-*` 纯属性节点（展示完全由组件按属性渲染）、mail 头部行转字段节点、option 解析状态参数；
- `Markdown.tsx` 按 `data-kpi / data-timeline / data-mail / data-option` 路由到 KpiGroup / Timeline / MailCard / OptionCard；
- fail-safe 完全复用：未闭合展开保内容 / 未知容器保持原文 / 游离闭标记不误吞 / MAX_DEPTH 8；四类容器为轻结构渲染，流式期间直接渲染（不进纯文本降级名单）；
- `index.css` 新增约 200 行（卡组网格 / 涨跌色变量 / 进度条 / 时间轴线 / 邮件头 / 徽标色），零依赖纯 CSS。

## 理由

- **语法锚定 GFM 列表而非自定义 JSON**：模型输出列表的稳定性远高于自定义结构；`|` 分隔在业务语义（表格行）上直觉一致，且列表项在没有任何扩展时也是合法 Markdown（降级可读）；
- **数据属性驱动组件**：条目信息落在 `data-*` 上，组件是纯展示函数，便于单测（jsdom 断言属性）与 E2E 断言（稳定 selector），也为未来导出 / 复制复用同一数据源；
- **「今天」高亮做在展示层**：日期格式混乱是模型输出的常态，三种形态容错 + 不校验合法性，避免「昨天是今天」类误判的复杂化；
- **option 未知状态降级**：模型可能输出未定义状态词，降级中性卡保证不丢信息也不误着色；
- **零依赖纯 CSS 与零后端改动**：延续 M19 的包体与流式纪律，业务卡不引入任何新产物文件；E2E 实测主包 gzip 仍在门槛内（见 §33）。

## 被否决的方案

- **markdown 内嵌 HTML（`<div class="kpi">`）**：与 react-markdown 白名单冲突，且模型 HTML 输出不可控；
- **后端预渲染结构化 JSON 卡片**：破坏「消息即纯文本」的单一事实源，流式渲染与导出 / 复制路径全部要分叉；
- **remark-directive 等第三方容器插件**：额外依赖 + 未知节点映射不稳定（M19 已否决，本轮沿用）；
- **为「今天」引入日期解析库**：为一种展示提示引入依赖不成立，三形态正则共 30 行；
- **把 kpi / timeline 渲染为图片 / 图表**：信息不可选中复制，与「点数值复制」的真实动作冲突。
