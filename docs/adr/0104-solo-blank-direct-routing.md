# ADR 0104：单助手直通路由——编制恰为 `[general]` 时跳过平台路由（M50）

- 状态：Accepted
- 引入：M50
- 相关：[design.md §60](../design.md)、[docs/blank-scene-design.md](../blank-scene-design.md)、[server/src/orchestration/engine.ts](../../server/src/orchestration/engine.ts)、[shared/src/types.ts](../../shared/src/types.ts)（`BLANK_SCENE_ID`）、ADR 0101（平台路由步 PRS / 空编制创建语义）、ADR 0103（空场景资产）

## 背景

- M48 平台路由（PRS）语义：未 @ 消息与空编制开场由引擎结构化决策「召集 + 派发」——对全部会话生效；
- 空场景的「单 Agent 模式」若走 PRS，将付出一次额外 LLM 调用与首响延迟，且语义上「单助手直聊」本无路由需求；
- 判定不能宽泛化：「编制恰为 1 人」会误伤单成员业务会话（如 `[pm]`）——它们应保持 PRS 语义不变。

## 决策

1. **直通判定**：会话满足「场景 `group === 'blank'`（经 `BLANK_SCENE_ID` 常量）且编制恰为 `[general]`」双条件时，未 @ 消息**直达 `general`**——`launch()` 返回 `queue: ['general']`、`queued: false`，零 PRS 请求、零 `routing:dispatched` trace；
2. **实时派生**：判定每次消息发送时基于**当前编制**重新计算——编制增为 `[general, pm]`（手动邀请）即退出直通、恢复 PRS；移除至其他形态同理；无需任何持久化标记；
3. **@ 语义不变**：显式 @ 消息在所有会话（含空场景）照常走 @ 直达分支，与直通分支互不干扰；
4. **共享常量**：`BLANK_SCENE_ID = 'blank'` 落于 `shared` 包（server / client 双侧同源，避免字符串散落）；
5. **保守边界**：单成员业务会话（`[pm]` 等非 blank 场景）行为零变化——回归用例显式覆盖；空编制（0 人）会话仍走 PRS（「交给平台组队」语义不变）。

## 理由

- **零路由开销**：单 Agent 模式不应为「路由到唯一成员」付 LLM 调用；直通把首响延迟压到与业务单成员会话相同；
- **编制 + 场景 id 判定直接表达用户意图**：「在空场景里只有通用助手」即用户明示的单聊状态；比「无 handoff 工具」等资产细节信号（脆弱、可被控制台编辑）稳固；
- **实时派生天然正确**：不落库任何「单助手模式」标记——用户加人 / 换人后语义即时切换，无迁移、无失效状态；
- **双通道验证口径**：单测以「请求流无 `platform_route` 响应格式调用（调用未发生）+ trace 无 `routing:dispatched`（决策未产出）」判定「未触发 PRS」，防单侧漏判。

## 被否决的方案

- **PRS 内识别 blank 场景并派给 general**：多一次 LLM 调用与首响延迟；「单 Agent 模式」不该为路由付任何开销；
- **仅按「编制人数 = 1」判定直通**：1 人业务会话（`[pm]`）语义是「先让 PM 接」而非「单助手直聊」；误直通会跳过 PM 的澄清 / 组队判断（场景 group 双条件排除此风险）；
- **持久化 `soloBlank: true` 会话字段**：静态标记无法跟上编制编辑（加人后仍直通 → 语义错误），且引入迁移与失效面；实时派生零成本；
- **空场景会话禁止加人 / 锁定编制**：违背资产型与用户自由度；实时派生已保证加人后语义正确（自动恢复 PRS）；
- **在客户端（前端）判定直通**：路由决策属引擎职责；客户端只做入口与展示（ADR 0106），不承载行为语义。

## 适用与失效条件

- 适用：全部消息发送入口（Composer / 命令面板 / 重放）作用于 `blank` 场景单成员会话；对既有会话零影响（判定恒不成立）；
- 失效条件：`blank` 资产被删除或 `group` 改名（`BLANK_SCENE_ID` 失配 → 直通不成立，退化为 PRS，功能安全降级）；「编制恰为 1」判定语义若未来引入「多会话模板」类机制，需复核本判定的适用范围——**不得**改为资产特例字段承载；
- 测试镜像面：`server/tests/m50-blank.test.ts`（直通 `queue` / 双通道零 PRS / 加人退出 / 收尾 `run:end completed`）；e2e `m50-blank.spec.ts`（反向断言「平台 召集了 …」不可见）；`m48-routing.spec.ts` 对照回归（PRS 路径零变化）。
