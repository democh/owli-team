# ADR 0106：空场景入口形态——组队台独立卡与场景列表过滤（M50）

- 状态：Accepted
- 引入：M50
- 相关：[design.md §60](../design.md)、[design.md §59](../design.md)（组队台，入口承载容器）、[docs/blank-scene-design.md](../blank-scene-design.md)、[client/src/components/sessions/CreateSessionDialog.tsx](../../client/src/components/sessions/CreateSessionDialog.tsx)、ADR 0102（建会话组队台）、ADR 0103（空场景资产）

## 背景

- 空场景需要一个建会话入口。设计期（两步向导时代）方案是「step 0 置顶独立卡」；实施期组队台（ADR 0102，M50）已把建会话重构为三栏「来源 / 角色池 / 编制」——入口落点随之对齐为组队台「来源」栏；
- 双入口风险：`blank` 是普通资产，会自然出现在「按场景组队」列表中——与独立卡并存会造成同一场景两个入口（列表行 = 普通场景语义，独立卡 = 单 Agent 语义），用户的预期不一致；
- 命令面板 / @ 列表 / 成员选择器是既有全量场景派生面，不应为空场景做任何特判（资产型原则的延伸）。

## 决策

1. **独立卡（主入口）**：「来源」栏滚动容器**顶部**渲染「空场景」独立卡（置顶、微标「单 Agent · 1 位成员」、场景色主题、选中态勾选）——点击 = `pickSource({kind:'scene', id: BLANK_SCENE_ID})`，与普通来源行同语义（`chain: [general]` 预选 1 人），零新增代码路径；
2. **列表过滤（去双入口）**：「按场景组队」列表 `groupList` 过滤 `BLANK_SCENE_ID`——搜索命中 / 不命中 / 全空态均由 `blankHit` 与过滤后列表共同决定（搜索「空场景」时独立卡保留、列表恒不含它）；
3. **零特判面**：命令面板（`requestCreate('scene','blank')` → `pendingCreate` 通道 → 组队台初始来源预置）、Composer @ 列表（order 1 自然居首）、成员选择器、控制台——全部自然生效，不写空场景特例；
4. **空态联动**：全空态提示的显示条件加入 `!(blankGroup && blankHit)`——独立卡在场时不出现「无匹配」误导。

## 理由

- **单 Agent 语义需要独立视觉位**：独立卡承载「不引入任何角色」的定位（微标 / 描述），列表行只是「一个场景」——这是文案与预期的正确性，不只是美观；
- **过滤避免选择歧义**：两处出现同一场景，用户会疑惑「点哪个」；过滤后入口唯一，命令面板等派生面仍可达（无功能损失）；
- **落点对齐组队台是必然修订**：组队终结了两步向导，原设计的「step 0 独立卡」已不存在——本 ADR 记录**实施对齐**（语义与交互同原设计：独立入口 + 列表去重）；
- **零新机制**：独立卡复用 `pickSource` 与 `CreateSource` 类型；过滤是一行 `.filter`——没有新状态、没有新通道。

## 被否决的方案

- **坚持原 SessionList「step 0 独立卡」落点**：两步向导已被组队台取代（ADR 0102），该容器不复存在；为历史方案保留死代码违背「落点对齐」；
- **`blank` 作为「按场景组队」普通行（不加独立卡）**：单 Agent 语义被淹没在场景列表中，与业务场景无异；且用户需求明确「单 agent 模式」应有独立的入口感知；
- **独立卡 + 列表行并存（双入口）**：同一场景两个入口 → 选择歧义；列表行点击后语义与独立卡重复（都走 `pickSource`），无并存价值；
- **前端按会话硬编码空态文案**：`guide` / `agenda` 已由 blank 资产驱动（M37 机制），硬编码引入第二事实源；
- **为空场景单独建「空白模式」对话框**：与组队台重复建设；来源 / 编制 / 标题 / 灵魂等交互完全同构，独立卡是同构入口的最简表达。

## 适用与失效条件

- 适用：全部建会话入口（左栏新建按钮 / 空态按钮 / 命令面板 `pendingCreate`）；窄屏三页签布局下独立卡同样位于「来源」页顶部；
- 失效条件：组队台结构再次重构时，独立卡的容器位置与锚点（`aria-label="组队来源：空场景"`）需同步迁移；`CreateSource` 类型扩展时独立卡的选中态判定（`source?.kind === 'scene' && source.id === blankGroup.id`）需复核；
- 测试镜像面：`client/tests/m50-blank-frontend.test.tsx`（独立卡唯一 / 徽标 / 点击预选 / 列表过滤 / 搜索与空态 / 提交 body / 命令面板 / `pendingCreate` 消费，5 例）；`e2e/m50-blank.spec.ts`（独立卡 → 已选 1 位 → 创建 → 直聊全链）。
