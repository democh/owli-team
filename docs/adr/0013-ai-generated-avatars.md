# ADR 0013：头像方案——AI 生图卡通形象照

- 状态：Accepted
- 引入：v1
- 相关：[design.md §19](../design.md)

## 背景

每个角色需要视觉标识。备选：程序化像素头像（代码绘制）、第三方头像库、AI 生图卡通形象照。

## 决策

**AI 生图卡通形象照**：每个角色一张 1:1 3D 卡通（动画电影质感）纯白底半身像（`client/public/avatars/<id>.png`，512px），造型与道具一一对应人设（如 QA 诺娃持放大镜与缺陷标记）；front-matter `avatar.image` 引用。

- 多级尺寸（16–96px）统一 `object-cover` + 调用方圆角裁切；
- 状态经角标表达（thinking 省略号 / done 星星 / error 闪电；`animated=false` 时关闭）；
- **回退方案**：未配置图片或加载失败（`onError`）自动回退「渐变 + lucide 图标」（`ICON_REGISTRY` 未命中回退 `User`）；
- 预览工具 `npm run avatar:preview` 展示「全部角色 × 尺寸 × 状态角标」+ 回退演示。

## 理由

- 程序化像素头像（首版方案）辨识度不足、气质与「专业研发团队」定位不符；
- 生图资产表现力强，且与角色人设的对应关系可经提示词精确控制；
- 保留渐变图标回退，资产缺失不影响功能。

## 被否决的方案

- **程序化像素头像**：已实装后废弃（辨识度不足），相关代码、测试与 CSS 动画已移除；
- **第三方头像库**：风格不可控，无法与人设道具对应。

## 影响

- 人设文档新增 `avatar.image` 字段；资产目录 `client/public/avatars/`；
- AgentAvatar 组件统一处理尺寸 / 回退 / 状态角标，全站复用（消息流 / 会话列表 / 职责卡 / 交付件作者标识）。

## 修订（v2，2026-09-17）：全量重设计为风格化 3D 卡通

- **动因**：初版后续批次新增角色之间面部同模（同一「大眼 + 光滑脸 + 微笑」模板），用户反馈「很多脸都长的一样」，要求更卡通、更可辨；
- **风格**：从「准写实 3D（次表面散射皮肤 / 发丝细节）」升级为「风格化 3D 卡通」——成人比例（约 1:4 头身，非 Q 版 / 幼态）、五官圆润简化、眼神略夸张、哑光黏土质感、色彩明快；构图统一为「头部占画面高约 55%」，保障 16–96px 小尺寸可辨识性；
- **差异化**：以「年龄 × 性别 × 脸型 × 发色发型 × 眼镜 / 胡须 × 肤色 × 职业道具」七维设定逐一区分（68 角色设定表见 design.md §19.3）；西式命名角色欧美面孔、中文命名角色东亚面孔；
- **覆盖与资产**：17 场景 68 张全量替换（512×512 PNG，`agents/<场景>/<id>/avatar.png` 自动发现机制不变）；旧资产备份于 `data/avatar-backup-2026-09-17/`（本仓无 Git，替换不可逆）；
- **不变项**：回退链（渐变 + lucide 图标）、状态角标、`/api/agents/:id/avatar` 直出 + ETag 缓存、零运行时开销。
