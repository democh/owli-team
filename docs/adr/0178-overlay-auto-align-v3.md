# ADR 0178：叠图自动找正 v3——指北交互 · 快照识别（GridOverlay v3）

- 状态：Accepted
- 引入：M66 v3 续完善（2026-09-19）
- 相关：docs/design-studio-design.md（§10.3 九宫叠图）· ADR 0171（v1 固定正北）· ADR 0175（v2 旋转对齐）· [client/src/components/chat/md-ext/pan/GridOverlay.tsx](../../client/src/components/chat/md-ext/pan/GridOverlay.tsx)

## 背景

ADR 0175 留「自动识别图纸朝向列 v3 评估」。评估结论：**从户型图像素级自动识别北向需要 CV/OCR 依赖**（找"北"字 / 指北针图标），与「零依赖 + 确定性可测」的组件纪律冲突——**不做像素识别**；转而做**交互式找正**（专业图纸工具的通用做法：不在图上找北，而是让用户指北）+ **来源识别**（Studio 快照天然北向上）。另：v2 重构对齐 bar 时 note 行丢失（无外部影响），本批补回并升级为动态提示。

## 决策

1. **指北模式（单点交互）**：工具条「指北」按钮切换模式 → stage 显示提示「点击图纸上的北向标记（从图心指向该点）」+ 十字光标；点击后按**相对图心的方位角**计算旋转角 `atan2(nx, −ny)`（北 = 上 = 0° / 东 = 90° / 南 = 180° / 西 = 270°），四舍五入到 1° 设为 `rot` 并自动退出模式。语义：旋转后**网格的「北格」指向用户所点方向**（与滑条旋转同一几何，无缝互用）。
2. **与滑条联动**：指北设值后滑条同步显示、可继续 ±微调；「复位」归零逻辑不变。
3. **快照识别（唯一自动分支）**：底图来源为 `design/snapshot-*`（工作台快照，Studio 产物天然北向上）→ 提示条显示「工作台快照（已按北向上）」；其余来源显示操作引导「图纸有偏转时：点「指北」或拖动「对齐」」。
4. **防误触**：指北模式下网格 `<g>` 设 `pointerEvents: none`（格点击让位——避免一次点击同时触发宫位询问与指北）；`rect` 尺寸为 0（未布局 / jsdom）时防护不计算。
5. **不做**：CV/OCR 像素级找北（重依赖 + 不确定）；多点拖拽（单点定北已足，滑条微调兜底）；自动识别设计文档里的「北」字（同 CV 理由）。

## 理由

- **交互式找正比自动识别更诚实**：图纸的北向本质是语义标注（不是视觉特征），让用户指北是信息最充分的通道；且实现纯交互、jsdom 可测、零依赖；
- **快照分支零成本**：Studio 快照已知北向上，识别 path 前缀即得——把「何时不需要对齐」这个真问题自动化（比找北更常见）；
- 单点（图心 → 点击）与滑条旋转共用同一 `rot` 状态与几何，机制收敛不引入第二套坐标系。
