# ADR 0016：前端主题——仅浅色

- 状态：Superseded → [ADR 0024](0024-dark-theme.md)
- 引入：v1
- 相关：[design.md §10](../design.md)

## 背景

v1 的前端视觉方案是否包含深色主题？备选：仅浅色（控制范围）或双主题（明暗切换）。

## 决策（历史）

**仅浅色主题**：Tailwind 语义 token 只定义浅色值，不做 `dark:` 变体与切换入口。

## 理由（当时）

- v1 聚焦功能链路（接力 / 流式 / 交付件），主题切换是纯增量 UI 工作；
- 双主题要求每个语义 token 都有 `dark` 值并逐组件校对，测试成本翻倍；
- 用户群体（本地开发者）对浅色无强投诉。

## 被否决的方案（当时）

- **双主题**：v1 阶段判定为「可延后」，记录为边界（design.md 旧 §17）。

## 影响与取代原因

- 实际使用中深色需求明确（长时间编码场景），且语义 token 体系已有，补齐 `dark` 值的边际成本低于预期；
- **M8 起由 ADR 24 取代**：`darkMode: 'class'` + 语义 token 补 `dark` 值 + 顶栏切换（浅色仍为默认）。
