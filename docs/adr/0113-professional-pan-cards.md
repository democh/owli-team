# ADR 0113：专业排盘卡——四张盘面卡结构化重写 · 契约测试 · 协议记录红线（M53）

- 状态：Accepted
- 引入：M53
- 相关：[design.md §68](../design.md)、[design.md §65](../design.md)（排盘四件套与 `::: pan` 容器）、[server/src/tools/pan.ts](../../server/src/tools/pan.ts)、[server/tests/m53-pan-card.test.ts](../../server/tests/m53-pan-card.test.ts)、ADR 0111（M51-E，工具与容器先例）

## 背景

- M51-E 交付排盘四件套与 `::: pan` 容器后，盘面卡信息单薄（紫微 tab 仅命宫 3 行、八字 tab 仅 5 行），未达「专业命理师」盘面参考的丰富度——术数解读的可信度来自盘面要素齐全（旬空 / 长生 / 四化 / 卦气等均为推理依据）与透明可复查；
- 盘面卡无标题：卡头 `::: pan <kind>` 缺标题时 ChartboardPanel tab 回退显示 kind 文本，两个同类盘（两个卦盘）无法区分（用户实测「重复的卦」）；
- 模型行为两处纪律缺口：正文仿写 `[工具调用]` 日志 / 编造工具结果；声称报告「已生成」而实际未落盘。

## 决策

1. **计算层字段扩展（零新增依赖）**：四模块按「专业盘面要素」清单补齐——bazi 旬空 / 地势（十二长生）/ 胎元 · 胎息 · 命宫 · 身宫（含纳音）/ 生肖星座 / 起运交运日期 / 大运流年当前标记；ziwei 四柱干支 / 生肖星座 / 来因宫 / 生年四化 / 十二长生 / 杂曜 / 当前大限；natal 元素与模式分布；gua 卦气（起卦四柱 / 日辰旬空 / 农历）/ 错卦综卦 / 卦体上下卦五行 / 旬空爻 / 动爻变爻（干支五行与六亲）；
2. **卡头标题化**：四类卡头一律带标题（`四柱 <干支>` / `紫微 <五行局> ｜ 命宫 <干支>` / `本命盘 <时刻>` / `<本卦> → <变卦>`）——标题兼作盘面板 tab 区分键与用户指认锚点；
3. **卡体结构与解析同源**：`键：值` 字段行在前 + 单一连续条目列表（finalizePan 只消费第一个 list；字段键 ≤16 字符；值内分隔用全角 ｜）；契约测试与 remark-ext 正则同文复刻，防服务端与客户端规则漂移；
4. **整卡复制纪律**：引导句「盘面卡（复制到回复渲染，整卡原样保留、勿增删字段）」+ 两场景协议 8 号硬约束（含卡头标题，勿增删字段与条目）；
5. **卡面复用纪律**（12 号）：同参数不重复起卦 / 排盘，先查会话历史直接引用已有盘面卡；多成员同波先声明各自盘面分工（治理重复盘根因）；
6. **记录真实性红线**：全局 tool_policy + 两场景 13 号——`[工具调用]` 区块为系统注入的真实执行记录，禁仿写日志 / 编造结果 / 虚假落盘声明。

## 理由

- 盘面数据必须工具化（M51-E 已立「禁心算」）；本批把「盘面够专业」变为可验收不变量：契约测试锁定字段与条目基线（八字 11 字段 + 大运 8 + 流年 10；紫微 6 字段 + 12 宫；星盘 3 字段 + 10 行星 + 12 宫头 + 16 相位；卦 9 字段 + 6 爻），模型复制时字段漂移可直接被测试拦住；
- 标题放卡头而非正文引导句：remark-ext builder 与 ChartboardPanel 两处解析共用卡头行，一次投入两处受益（tab 区分 / 用户指认 / 卡面复用检索）；
- 协议条款只增不改：追加两条（12 / 13）与 8 号句尾扩展，不动既有编号与语义——m21 协议断言（关键词包含）与既有角色行为零回归。

## 被否决的方案

- **detail 里改为多张分段卡**：finalizePan 只消费第一个 list，多卡增加模型复制出错面且收益为零；单卡信息密度提升更稳；
- **卡面改用表格 / HTML**：`::: pan` 契约（M51-E）已定（字段行 + 条目行），改表格破坏 chartboard 与 m51-md-pan 既有测试；
- **标题放引导句**：chartboard tab 读取卡头 title，放引导句对 tab 区分无效；
- **为未工具化门类（大六壬 / 奇门）补排盘**：超本批范围（协议已要求显式声明精度边界）；
- **客户端侧做 tab 去重（同名 tab 自动编号）**：治标不治本——盘面卡缺标题同时损害用户指认与卡面复用检索，标题化是根因修复。

## 适用与失效条件

- 适用：四类盘面卡后续字段扩展（须同步 m53 契约测试基线数字）；协议 8 / 12 / 13 条款适用于 metaphysics / astrology 全部角色；卡头标题格式可作多盘面板的通用约定（后续新增盘类型沿用 `::: pan <kind> <标题>`）；
- 失效条件：pan 容器解析规则（remark-ext `PAN_FIELD_RE` / takeList / finalizePan）变更时须同步 m53 契约测试；卡头格式变更须同步 ChartboardPanel 与 m51-md-pan / m53-pan-card 两处测试；引导句文案变更须同步协议 8 号与两处测试关键词。
