# ADR 0222：M83 批 E 收口——Monaco 策略工作室不立项 · 实时盯盘暂缓

- 状态：Accepted（2026-09-25，经产品侧确认）
- 关联：M83（ADR 0219 / docs/kline-analysis-dsl-design.md 批 E 余项）・ADR 0221（批 E-1 划线圈）・ADR 0098（行情面板撤除）・design.md §126

## 背景

M83 批 E 余项仅剩两项：Monaco 策略工作室（人工编辑 DSL）与实时盯盘（图表增量更新）。两项的落地前提与现状冲突、收益不足，现将决策记录如下，批 E 正式收口。

## 决策

### 1. Monaco 策略工作室：不立项

- **Agent 闭环已完整**：`strategy-dsl` 技能（YAML 语法 / 白名单 / lint→run→回测工作流 / 错误修正表）+ `fin_strategy`（lint 错误回注 Agent 自我修正）+ `fin_backtest template=dsl`（同口径回测）+ 信号 / 分析落图；DSL 源码以代码块呈现且自带复制按钮（CodeBlock + CopyButton）——「生成 / 校验 / 执行 / 查看 / 复制」全链已可用（GET /api/finance/strategy/meta 路由保留，供未来或外部消费）。
- **人工手改场景走对话**：微调参数（如「止损改 92 再回测」）由用户对 Agent 提出，改动留痕在消息流，比引入独立编辑器更符合本产品「对话驱动」的交互形态。
- **成本不成立**：monaco-editor + worker（独立 chunk、数百 KB gzip）、编辑器 / lint 标记 / 回测预览 / 工作区保存（approval 链）整套 UI、E2E 不可测——为低频人工编辑付出高维护面。
- 兜底路径：若未来出现明确的人工编辑需求，先落「零依赖轻量替代」（textarea + 服务端 lint 标记 + run 预览），再评估是否升级。

### 2. 实时盯盘：暂缓（保持快照式）

- **缺宿主（形态未定）**：图表现状为静态快照（entry DataLoader 一次性回填）；两个载体均非盯盘语义——消息块是历史归档（不应持续跳动 / 刷新）、画布节点是笔记层（无订阅生命周期与统一频控）；原天然宿主（主区「行情」Tab）已按 ADR 0098 撤除。
- **数据通道未备**：网关 kline 为快照接口（带缓存）；实时需增量通道（轮询 / SSE-WS）+ 频控 + 未启用网关的降级矩阵，属独立设计。
- **替代路径已可用**：需要最新数据时切周期重拉或让 Agent 重新取数（`fin_kline` / `fin_analyze`）。
- 重启条件：出现明确的多标盯盘产品诉求时，按「画布节点实时开关（节点级订阅，生命周期随节点、页面隐藏暂停、网关未启用降级提示）」最小形态另立专项。

## 被否决

- 为「批 E 完整性」而实现 Monaco（无真实需求支撑，违反最小依赖纪律）；
- 把盯盘硬塞进消息块 / 画布节点既有语义（破坏归档 / 笔记定位，且无生命周期与频控设计）。

## 验收

批 E 全量收口：E-1 划线圈已交付（ADR 0221 / design.md §126 / client m85 13 例 + E2E m85 1/1）；E 余项由本 ADR 记录不立项 / 暂缓。`docs/kline-analysis-dsl-design.md` 状态行与批表、design.md §126、`docs/adr/README.md` 索引同步。
