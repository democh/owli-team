# ADR 0132：头像统一圆角——组件内置 25% 等比圆角 · 全站调用方去显式类

- 状态：Accepted
- 引入：头像统一批（2026-09-19）
- 相关：[design.md §19](../design.md)（角色形象系统）、ADR 0013（头像方案：AI 生图卡通形象照——本 ADR 修订其「调用方圆角裁切」口径）、[client/src/components/agents/AgentAvatar.tsx](../../client/src/components/agents/AgentAvatar.tsx)、[client/src/index.css](../../client/src/index.css)

## 背景

- 用户实测截图反馈（红框：未选择会话的欢迎页头像行，原话「**用圆角，所有的头像展示都需要用圆角**」）——欢迎页头像行（34 / 44px）呈直角方形；
- 全量盘点 37 个文件 62 处头像调用确认现状漂移：ADR 0013 / design.md §19 的「调用方圆角裁切」口径在实践中长出六种形态——**两处无圆角**（欢迎页头像行、roundtable 迷你席位）、`rounded`（4px，约 15 处）、`rounded-md`（8px，约 10 处）、`rounded-lg`（10px，约 6 处）、`rounded-xl`（12px，1 处）、`rounded-full`（全圆，约 24 处）；另有 CSS 场景席位 `border-radius: 999px`（`.scene-sr-avatar` / `.scene-rt-mini-seat`）——圆角值随调用方随意漂移，新增调用可能再度遗漏（欢迎页即为此类缺失）；
- 相近尺寸邻位混排时形态不一致可见（如 Composer 内 22px 四角候选 + 18px 全圆成员条、系统事件 22px 全圆 + 任务视图 12–16px 4px 圆角），"所有头像展示"缺乏统一口径。

## 决策

1. **组件内置统一圆角（单一来源）**：`AgentAvatar` 根节点默认类内置 `rounded-[25%]`（等比圆角，相对自身尺寸计算）——所有头像展示天然圆角；内部三层渲染（img / 渐变 / 中性底）沿用 `rounded-[inherit]` 继承；调用方 className 仍可覆盖（tailwind-merge 后者胜出）。
2. **调用方全量去显式类**：62 处调用（37 个文件）移除全部显式圆角类（`rounded` / `rounded-md` / `rounded-lg` / `rounded-xl` / `rounded-full`）；其余装饰类保留（`ring-*` 描边、`shrink-0`、动画类等）——圆角口径回归组件单一来源。
3. **场景席位 CSS 对齐**：`.scene-sr-avatar`（圆桌席位环）与 `.scene-rt-mini-seat`（迷你席位条）`border-radius: 999px → 25%`，并入统一口径（注释互相引用，改比例需两处同改）。
4. **25% 等比圆角的尺寸表现**：12px → 3px / 16px → 4px / 22px → 5.5px / 26px → 6.5px / 34px → 8.5px / 64px → 16px / 96px → 24px——任意尺寸视觉圆润度一致（与 iOS 图标圆率 ≈ 22.4% 同量级）。

## 理由

- **等比圆角是「统一」的最强实现**：固定值（如全站 10px）在 ≤20px 小尺寸被浏览器钳制为 50%（视觉全圆）、在 96px 仅 10%（近直角）——同一数值下观感两极；25% 比例圆角在任意尺寸下保持同一圆润度；
- **单一来源 + 默认兜底是回归防护**：圆角从「每个调用方的自觉」改为「组件默认事实」——欢迎页等遗漏类缺陷在结构上不再可能复现；未来调用方若需特例形态仍可 className 覆盖；
- **形态基调延续用户措辞**：用户明确要求「圆角」（未要求圆形）——原 `rounded-full` 的 24 处均为 13–26px 小尺寸，改 25% 后为 3.25–6.5px 圆角，与全圆视觉接近且与全局口径严格一致；64 / 96px 大图（预览页 / 名录页）由 10px 增至 16 / 24px，圆润更明显；
- **纯前端批次**：零协议、零服务端、零 agents 资产变更；62 处调用 + 2 处 CSS 内联收口；TS 类型检查零错误，client 测试 876/876 全绿。

## 被否决的方案

- **仅补两处缺圆角（最小修复）**：4 / 8 / 10 / 12 / 全圆五种显式值继续并存，「所有头像展示统一」未达成（相近尺寸邻位混排形态不一）；
- **统一固定值（全站 `rounded-lg` 等）**：小尺寸钳制为全圆、大尺寸近乎直角，尺寸漂移不可控（见理由）；
- **统一 `rounded-full`（全圆）**：用户措辞为「圆角」而非「圆形」；且 64 / 96px 大图变圆超出诉求、大面积改变既有形态；
- **保留 `rounded-full` 于 chips / 堆叠场景（只统一非全圆）**：相近尺寸仍存在「圆 vs 圆角矩形」双轨（Composer 22px 候选 + 18px 成员条等），"所有"不成立；
- **内联 `style.borderRadius` 按 size 计算**：内联 style 优先级高于 className，调用方再无法覆盖（丧失可覆盖性）；
- **在调用方逐处显式写 `rounded-[25%]`**：62 处重复、新增调用仍可能遗漏，违背单一来源。

## 适用与失效条件

- 适用：全部头像展示面（消息流 / 欢迎页 / 会话列表 / 团队面板 / 协作图谱 / 场景席位与面板 / 控制台 / 头像预览页 / 命令面板 / 交付件 / 画布输入条等 37 个文件）；
- 失效条件：① 若设计要求特定形态（如全圆）——调用方 className 传 `rounded-full` 即可覆盖组件默认，无需改组件；② CSS 席位类（`.scene-sr-avatar` / `.scene-rt-mini-seat`）与组件默认值需同步维护（改比例时三处同改）；
- 已知边界：`rounded-[25%]` 依赖 Tailwind 任意值语法（构建产物为 `border-radius: 25%`）；`-space-x` 负边距堆叠与 `ring-*` 描边在圆角下正常（box-shadow 随 border-radius 形状绘制）；头像容器恒为正方形（宽 = 高 = size），比例圆角四角一致。
