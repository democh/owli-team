# ADR 0061：画布输入平权、设置主区页与媒体配置专业化（Canvas Input Parity & Settings View）

- 状态：Accepted
- 引入：M36
- 相关：[design.md §51](../design.md)、ADR 19（上下文工程：五层装配 + 压缩 + 记忆）、ADR 20（会话级互斥 + 插话）、ADR 25（前端性能架构：byId+order / 虚拟列表 / 节流）、ADR 42（连接中心与 CDP 浏览器接入：凭据加密 / 会话绑定）、ADR 47（向量记忆：连接中心凭据 / L1.5 语义召回）、ADR 50（资产控制台：ActivityRail + 主区视图形态）、ADR 59（无限画布与媒体创作工作台）

## 背景

- 画布（M31）已与「对话 / 交付件 / 数据库 / 终端」并列为主区 Tab，但输入能力只存在于对话 Tab：用户在画布上工作时（媒体生成 / 脑图 / 素材摆放）必须先切回对话才能说话，工作流被打断。用户反馈：**「画布怎么没有输入框等功能，是与 chat 同等级的，不是对 chat 的补充」**——诉求是输入平权，而非给画布附送一个聊天小窗。
- 画布右下角 MiniMap 在无限画布 + 无限脑图形态下收益低且与生成面板 / 浮层视觉冲突。用户反馈：**「不需要右下方的缩略图」**。
- 配置面存在三处已积累的短板，用户要求 **「api 等相关的配置详细设计，重构当前的设计页面，包含所有可配置内容，专业化」**：
  1. 设置是模态弹窗（SettingsDialog）：仅 22 字段（缺 M34 金融投研 4 项），无资源概览与系统信息；与连接中心 / 资产控制台等主区视图形态不一致；
  2. 媒体连接表单：能力多选裸露（可选到适配器不支持的能力，运行时才失败）；工作流 JSON 无校验无格式化；三段式模板无链路预览；测试按钮的行为差异无说明；
  3. 画布生成面板与连接中心之间没有直达通道（配置错的连接要手动切换视图再翻找）。
- 硬约束：
  1. **不复制消息流**：画布指令条不引入第二份完整聊天历史（双份渲染成本 + 双份状态，违背 ADR 25 的前端性能纪律）；
  2. **互斥与插话语义零改动**：画布输入复用既有 `send(content, mode)` / 插话通道（ADR 20），服务端不新增执行路径；
  3. **设置字段单一事实源**：字段集必须与 server `RuntimeSettingsSchema` 26 项白名单一一对应（新增字段需同步三处：schema / 表单 FIELDS / FALLBACK 默认值）；
  4. **凭据纪律不变**：媒体配置的 apiKey 只写不读 / 测试探活 / 凭据加密全部留在连接中心（ADR 42），画布只留直达入口。

## 决策

1. **画布输入平权：底部固定指令条 `CanvasComposer`（非聊天小窗）**——居中固定于画布底部：Enter 发送 / Shift+Enter 换行；运行中发送自动变为插话（回合边界消费）；输入条上方可展开「最近回复」浮层（运行状态 + 最近 14 条消息窗口 + 待审批提醒）；完整历史仍在对话 Tab。成员快捷条点击插入 `@名字`；范式三态 chip（执行 / 规划 / 评审，ADR 48）仅对下一条消息生效，发送后复位；草稿按会话持久化 `ma:draft:canvas:<sessionId>`，与对话输入框互不干扰。
2. **移除 MiniMap**——画布即全景：适应视野 / 缩放 / 空间记忆已足够；右下角让位给生成面板与指令条浮层。
3. **设置升级为主区视图（`AppView 'settings'`），删除 SettingsDialog**——左侧分类导航 + 右侧专业表单，8 分组覆盖 26 项全量（含金融投研 4 项），附资源概览（连接 / MCP / 角色 / 技能计数 + 直达入口）与系统信息（`/api/health` 回显）；scrollspy 导航、脏标记、`PUT /api/settings` 全量保存即时生效；入口收敛为 ActivityRail 设置钮 + 命令面板（「打开设置」命令与视图组）。
4. **媒体连接表单专业化（连接中心）**——提供方卡片（ComfyUI / SD WebUI / OpenAI 兼容 / 任务模板，含能力摘要）；能力矩阵与适配器能力单一事实源对齐（切换提供方自动收敛已选能力，不支持项禁用虚线）；工作流编辑器（实时解析校验 + 状态徽章 + 一键格式化 + 已解析明细）；模板编辑器（三段式链路预览 `create.method path → poll.method ?? 'GET' path` + 占位符列表）；按提供方的联调探活说明（ComfyUI `/system_stats` / SD WebUI `/sdapi/v1/options` / OpenAI `/models` / 模板静态校验）。
5. **画布 → 连接中心直达编辑**——`connections-store` 增单值通道 `pendingEditId`（`requestEdit` / `consumePendingEdit`）：生成面板铅笔钮写入目标连接 id 并切视图；连接中心在清单就绪后消费（实时 `getState()` 快照防挂载首帧闭包误判），打开该连接编辑表单并滚动置顶；目标不存在（已删除）时丢弃请求不悬挂。

## 理由

- **平权 = 输入可达 + 状态可见，而非历史全量**：用户在画布上的最高频诉求是「说下一句」与「看一眼最近回复」；浮层预览满足后者，历史留在对话 Tab 则零损失。嵌入完整聊天流会挤占画布并引入双份渲染成本。
- **指令条独立草稿**：画布与对话是两个工作现场，草稿互不覆盖（`ma:draft:canvas:<sid>` 与对话草稿键分离），切 Tab 不丢上下文。
- **主区视图而非弹窗**：26 项 + 资源概览 + 系统信息的规模超出模态承载（弹窗滚动体验差、无深链）；主区视图支持命令面板 / rail / 未来深链（`?view=settings&section=memory`），且与 M26 资产控制台形态一致，减少一套模态布局的维护面。
- **能力矩阵与适配器对齐**：能力清单是运行时裁剪入口的依据（生成面板与 `media_generate` / `media_video` 工具按此收敛）；表单侧即时收敛把「保存了不支持的能力」的失败从运行时前移到配置期。
- **编辑器本地实时校验**：工作流 JSON 与三段式模板的错误在粘贴时即可见（状态徽章 + 明细 + 链路预览）；「格式化但解析失败不落盘」防止脏文本覆盖可用配置。
- **直达编辑走 store 单值通道**：跨视图命令天然是「一次性意图」；单值 + 消费语义避免队列堆积与陈旧请求（目标已删除时静默丢弃优于报错悬挂）。
- **金融投研 4 项补齐**：设置页成为唯一配置面板后，M34 金融字段（启用 / 行情刷新间隔 / 最小请求间隔 / Python 桥超时）必须有落点，否则用户只能改 env。

## 被否决的方案

- **画布嵌入完整聊天流（分栏 / 浮动聊天窗）**：挤占画布空间、双份消息渲染与滚动状态管理成本；预览浮层 + 「打开对话」跳转已覆盖需求。
- **保留 MiniMap 折叠态（默认收起）**：无限画布 + 无限脑图下小地图的定位收益趋近于零；保留折叠钮仍是视觉噪声（用户明确不要）。
- **设置维持弹窗并扩字段**：22 → 26 项 + 资源 + 系统信息后内容溢出模态；弹窗与主区两套布局（含窄屏适配）维护成本翻倍。
- **为媒体配置新建独立「媒体中心」页**：凭据加密 / 会话绑定 / 测试 / 审计广播全在连接中心（ADR 42），新建页面会复制整条链路；增强既有表单即达成目标。
- **画布生成面板内联编辑连接（apiKey / 测试）**：违反凭据纪律（apiKey 只写不读、测试探活属连接中心职责）；画布只留直达入口，编辑仍回到连接中心。
- **画布指令条与对话输入框共享草稿**：两个现场的草稿语义互斥（用户可能在两侧写不同内容），共享会造成互相覆盖。
- **「最近回复」浮层展示全量历史**：等价于在画布重造消息流（虚拟列表 / 滚动锚定 / 流式渲染全量需求），与「不复制消息流」约束冲突。
- **设置页自建字段元数据（脱离 RuntimeSettingsSchema）**：会造成双事实源漂移；字段集固定为白名单 26 项的一一映射。

## 适用与失效条件

- 适用：本地单用户 + 桌面浏览器；窄屏画布 Tab 仍可用（指令条为紧凑布局）；设置字段集与 `RuntimeSettingsSchema` 保持同步（新增字段需更新 schema / SettingsView FIELDS / FALLBACK 三处）。
- 失效条件：
  - **多用户 / 多租户权限分面**：设置页需按角色裁剪字段可见性（当前为单用户全量）；
  - **画布多人实时协作**：指令条需引入在场语义（谁在输入 / 冲突仲裁），当前为单用户形态；
  - **设置规模数倍增长**（>60 项或嵌套子配置）：需引入分组子页路由与字段搜索；
  - **媒体提供方形态变化**（能力矩阵与适配器注册表解耦）：能力清单需改为从服务端 `GET /media/providers` 动态拉取而非前端常量表。
