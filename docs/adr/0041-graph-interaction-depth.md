# ADR 0041：图谱交互深化——悬停预览 / 键盘导航 / 接力链追踪 / 时间轴回放

- 状态：Accepted
- 引入：M22
- 相关：[design.md §28.5](../design.md)、ADR 36（接力图谱游戏化）

## 背景

M21 之后图谱能回答「现在的战况」，但四类问题仍要人肉操作或无法回答：

1. **扫视成本高**：了解一个成员近况（状态 / 最近发言 / 战绩）必须先点击打开档案面板，再关闭，来回成本高；
2. **深链回溯难**：7 人全链接力后，想知道「这棒从哪来、往哪去」，需要沿边逐条目视回溯；
3. **过程不可回放**：运行结束后的图谱只呈现「最后一帧」，用户想重新看「接力如何一根根长出来」没有任何入口；
4. **键盘用户无路径**：画布操作全部依赖鼠标（HUD 有快捷键 `F` 的提示，但方向键 / 布局切换键盘不可达）。

约束不变：图谱是消息的纯函数推导物（`buildGraph`），零后端；懒加载独立 chunk；quiet / reduced-motion 必须全量降级。

## 决策

**以「交互手感（A）· 洞察（B）· 时间轴回放（C）」三个包深化图谱，全部留在前端沉浸层，新增能力一律先落纯函数**：

- **A 交互手感**：悬停 280ms 浮现预览卡（`pointer-events: none`，消失仅由 `mouseleave` 驱动，右缘翻转 + 下缘钳制定位）；双击节点 = 开档案 + 居中、双击空白 = `fitView`；方向键按 `nextNodeInDirection`（几何评分：主轴距离 + 2 × 垂直偏移，仅取严格正方向）移动选中，`1`/`2` 切布局、`T` 追踪、`F` 导演镜头，输入区聚焦全量跳过；**Esc 五层收起**（回放 → 追踪 → 固定边 → 全屏 → 选中）；点击接力边固定标签 + replay nonce 一次性流光；`awaitingUser` 从无到有触发全图柔光庆祝脉冲。
- **B 洞察**：`traceFrom(model, id, 3)` 沿接力边双向 BFS ≤ 3 跳 → 成员集 + 边集，追踪口径接管焦点优先级（追踪 > 悬停 > 选中），dock 出「追踪 N 位」胶囊；游离成员 = 接力 ≥ 2 次后仍未接棒（虚线呼吸环 + 提示文案）；档案面板增量：专长 chips（前 4 + `+N`）、灵魂徽标（会话覆盖 > 角色默认）、追踪按钮。
- **C 时间轴回放**：以消息条数为粒度 `slice(0, index) → buildGraph` 重建「当时图」；300ms / 条步进、拖拽定格、到尾自动退出；回放期间用 `REPLAY_LIVE` 空快照屏蔽实时状态，脉冲基线随模式切换静默重置。
- **纯函数落位**：`lib/graph.ts`（`traceFrom` + `isolated` 口径）、`lib/graph-layout.ts`（`nextNodeInDirection`）——组件只做渲染与状态编排。
- **降级**：4 组新动画全部加入 quiet / reduced-motion 禁用清单；状态文案复用 `STATUS_LABEL`。

## 理由

- **悬停延迟 + 指针穿透**：280ms 是「有意停留」与「轻扫而过」的经验分界；`pointer-events: none` 使预览卡完全不参与事件系统——不需要处理卡片自身 `mouseleave`、点击穿透、hover 链断裂等一整类状态对偶问题，消失路径唯一（节点 `mouseleave`）；
- **回放用「消息切片」而非事件录制**：图谱本就是消息的纯函数，切片即得「当时图」——零额外存储、与实时口径永远同构；若录 `RunEvent` 时间线，消息与事件双数据源必然分叉（压缩窗口 / 分页加载后不一致）；
- **脉冲基线随模式切换重置**：回放进出会改变 `buildGraph` 输入（切片），若不复位脉冲基线（prevCounts / nodeFlash / prevAwaiting），退出回放瞬间会把「切片差」误判为新接力而全图爆闪——静默重建基线是正确性要求而非手感优化；
- **追踪用双向 BFS 而非单向链**：用户的问题是「这棒怎么一路传下来」——单向上下游无法回答整体故事；双向 + 3 跳上限保证大图上不失控（15 人编制最坏覆盖也有限）；
- **游离成员用行为口径（≥ 2 次接力仍未接棒）**：编制链缺席口径在新会话初建时全员缺席会全员报警；行为口径天然表达「大家都在跑，TA 还没上过场」；
- **键盘几何导航而非图邻接**：视觉直觉优先——「最顺路的右邻居」是几何概念（主轴距离 + 2×垂直偏移，同行 / 同列优先），图邻接在圆桌布局下无方向语义；纯函数与布局解耦，布局切换后仍然成立；
- **Esc 五层收起**：遮罩式 UI 的状态天然嵌套（回放覆盖追踪、追踪覆盖固定边…），单一 Esc 语义 = 从最外层收起一层，符合用户对「返回」的心智模型。

## 被否决的方案

- **悬停即弹预览卡**：鼠标在画布上移动必然扫过节点，卡片乱闪且遮挡画布；
- **预览卡可交互（pointer-events: auto）**：要从卡片回到节点、卡片内按钮点击、卡片 mouseleave 竞态等一整套状态对偶；预览是「免点击速览」的语义，速览完要看详情就点击开档案；
- **追踪展示单向「上游链 / 下游链」两个胶囊**：回答不了「这棒从哪来往哪去」的整体故事，且两个焦点口径互斥；
- **回放录制 RunEvent 事件流**：双数据源分叉（见理由）；且事件流回放无法保证与 `buildGraph` 口径一致；
- **游离成员用「不在编制链上」口径**：新会话初建时全员缺席 → 全员报警；且自由组合会话没有编制链；
- **方向键用图邻接（上游/下游）导航**：圆桌布局下无方向语义；几何评分同时服务两种布局；
- **预览卡跟随鼠标（tooltip 式）**：与拖动 / 点击手势冲突，且流→屏坐标换算在画布平移缩放时逐帧抖动；
- **回放期间允许打开档案面板**：面板数据来自实时 store（非切片），与「当时图」叙事矛盾——进入回放即收起面板 / 追踪 / 固定边 / 预览。
