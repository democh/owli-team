# ADR 0065：波次分隔与定位（Wave Separator as Virtual Row + Scroll-Derived Floating Strip）

- 状态：Accepted
- 引入：M37
- 相关：[design.md §52](../design.md)、ADR 3 / 33（发言并发度：波次特例 / Run 内并行波次）、ADR 25（前端性能架构：byId+order / 虚拟列表 / 节流）、ADR 62（场景差异化限定于视图层派生）、ADR 64（交互卡片回填语义）

## 背景

- 波次（同一 Run 内 `turnIndex` 相同的一组发言）在对话区不可见：并行场景长会话（如研发链 7 成员 × N 轮）中，用户无法区分「第几轮」、无法快速定位某个波次；
- 候选方案两类：① 波次分隔作为「内容聚合」挂到虚拟列表（风险：击穿结构键契约——虚拟行数随内容变化引发重派生风暴，ADR 62 已否决此形态）；② 用 CSS `position: sticky` 让波次头吸顶（虚拟列表绝对定位 + `transform` 容器下 sticky 不可靠）；
- 硬约束：
  1. **结构键契约**：虚拟行派生只依赖 `role~runId~turnIndex`（流式 delta 不改这些字段，不触发重派生，ADR 25）；
  2. **零额外订阅**：滚动派生只复用虚拟列表已维护的视口窗口 `vp`，不引入逐行 IntersectionObserver（行回收 + 观察器重建成本不可控）；
  3. **安静降级**：单波次 / 无消息不显示；窄屏自然收缩。

## 决策

1. **分隔行 = 普通虚拟行**：`deriveRows`（`client/src/lib/chat-rows.ts`）三遍算法——骨架分段（同 `runId~turnIndex` 连续 ≥2 条成波）→ 波次起点标记（`segKey` 变化）→ 插入 `wave-sep` 行（key `sep-<segKey>`、锚点 `data-wave-sep=<turnIndex>`）；**仅当波次起点数 ≥2 才显示**；行只依赖结构键——流式 delta 中结构键不变，派生缓存命中；
2. **分隔行形态：极轻量细线 + 「第 N 波」**（无头像、无交互；成员头像组由波次组头 / 悬浮条承载——避免同一信息三处堆叠与行高抖动）；
3. **当前波次 = 滚动窗口派生**：`onScroll` 维护 `vp{first,last}` 视口窗口（变化才落 state）；`currentWave` = 首个可见行向后扫描的首个波次；
4. **悬浮阶段条**（`WaveStrip`）：仅「上滑离开底部且有当前波次」时挂载于消息区顶部（锚点 `data-wave-strip=<turnIndex>`）；显示波次号 + 成员头像流 + 名字；点击 → `focusMessage(memberIds[0])` 跳波起点（复用既有定位 + 闪光反馈）；
5. **不用 CSS sticky、不用独立波次面板**。

## 理由

- **结构键零破坏**：分隔行是既定派生模型（`waveOf` / `rail` 同源产出）的自然延伸；流式高频路径零新增计算；
- **滚动窗口是最小信息源**：`vp` 已由虚拟列表维护，`currentWave` 是其纯函数；比逐行观察器少一个数量和生命周期都不确定的观察器集合；
- **点击跳波起点**：把「当前在哪一波」直接变成导航动作（与 M37-7 消息导航条 rail 同源互补：rail 管「条」、悬浮条管「波」）；
- **细线形态**：分隔行密度高（每波一条），重形态（头像组 / 大卡）会与波次组头重复且推高滚动高度。

## 被否决的方案

- **CSS `position: sticky` 波次头**：虚拟列表绝对定位 + transform 容器下行为不可靠（滚动容器 / 浏览器差异），且与行回收冲突；
- **IntersectionObserver 逐行观察当前波次**：观察器随虚拟行挂载 / 卸载重建，成本与实现复杂度都高于滚动窗口扫描；
- **重内容分隔行（头像组 / 摘要卡）**：信息与波次组头重复、行高抖动、滚动定位失真；
- **独立波次面板 / 时间轴侧栏**：与消息导航条（M37-7）职责重复；同类信息由 rail 与悬浮条两处覆盖即可；
- **把「当前波次」写入持久 / 全局状态**：纯视图瞬态，无跨端 / 持久化价值。

## 适用与失效条件

- 适用：虚拟列表渲染（ADR 25）与 `deriveRows` 派生模型；波次语义 = `runId~turnIndex`（ADR 3 / 33）；
- 失效条件：
  - **渲染模型迁移**（改非虚拟列表 / 服务端分页渲染）：滚动窗口派生的挂载点与锚点策略需重新评估；
  - **多视图并存**（回放 / 分屏同时滚动）：`currentWave` 的「跟随哪一视图」需引入焦点概念；
  - **波次形态改变**（跨 Run 合并波次 / 子波嵌套）：`segKey` 与分隔行插入条件的定义需扩展。
